# 지도

지도는 현장을 공간으로 담는 틀입니다. 바탕이 되는 기본 지도 위에 오버레이를 겹치고, 그 위에 대지와 구역을 그리고, 입력·출력을 제자리에 놓습니다. 이 장에서는 현장 A 를 지도에 담고 대시보드에 놓습니다.

지도에는 층이 있습니다. 가장 큰 **대지** 안에 **구역**이 있고, 구역 안에 시설·구획·설비·장치가 놓입니다. 무엇이 어디에 속하는지는 사용자가 그린 위치로 정해집니다.

현장 A 의 지도에서 짚어 보겠습니다. 현장 전체의 경계가 대지이고, 노지를 나눈 3-1 과 3-2 가 구역입니다. 이 안에 시설, 구획, 설비, 장치도 놓입니다. 이것들은 앞으로 하나씩 놓아 가겠습니다.

| 이름 | 뜻 |
|---|---|
| 대지 | 현장 전체의 경계 |
| 구역 | 대지 안을 나눈 땅 |
| 시설 | 온실이나 창고 같은 건물([시설](g07-facility.md)에서 만듭니다) |
| 구획 | 구역이나 시설 안에서 한 대상을 관리하는 자리 |
| 설비 | 펌프와 밸브, 배관 같은 것 |
| 장치 | 입력과 출력, 함수를 지도 위에 놓은 표시 |

지도 위젯을 열면 내 현장 전체가 위에서 한눈에 보입니다. 걸어 다니지 않아도 어디에 무엇이 있는지 알 수 있습니다. 구역이나 시설을 눌러 들어가면 그 안의 값과 장치만 걸러서 볼 수 있어서, 현장이 넓을수록 이렇게 나눠 보는 것이 필요합니다. 장치를 누르면 지금 상태와 값이 바로 나오니, 현장에 가지 않고도 무엇이 어떻게 돌고 있는지 확인할 수 있습니다.

## 이 장을 마치면 { #goal }

- 지도의 세 페이지가 각각 무엇을 하는지 안다
- 바탕 지도(MapTiler)를 등록해 지도 바탕이 보이게 한다
- 현장의 대지와 구역을 그리고, 입력을 지도에 놓는다
- 대시보드에 지도 위젯을 놓고, 지도에서 값을 보고 출력을 조작한다

## 준비 { #prepare }

- 대시보드가 있는 시스템([대시보드](g05-dashboard.md))
- 이메일 주소 하나(MapTiler 가입에 씁니다)
- 필지 경계를 주소로 가져오려면 브이월드 키(한국, 선택)

## 절차 { #steps }

### 1. 지도의 세 페이지 { #step-1 }

지도의 설정은 3개의 페이지로 구성되어 있습니다.

- **지도**(설정 → 지도, 화면 제목은 "공간 디자인 스튜디오"): 지도 위에 대지와 구역을 그리고, 입력과 출력 같은 장치를 배치하는 페이지입니다.
- **시설**(설정 → 시설): 온실이나 창고 같은 건물을 만들고 관리하는 페이지입니다. [다음 장](g07-facility.md)에서 다룹니다.
- **지리 정보 입력**(설정 → 지리 정보 입력, 화면 제목은 "GIS 입력 관리자"): AoT 에서 사용할 다양한 형식의 지리 정보를 관리하는 페이지입니다.

### 2. 기본 지도와 오버레이 { #step-2 }

지리 정보 입력으로 두 가지를 등록합니다.

- **기본 지도**: 바탕이 되는 한 장으로, 도로나 위성 사진 가운데 하나를 고릅니다.
- **오버레이**: 그 위에 겹치는 층으로, 날씨 레이더나 지적도 같은 것을 여러 개 켜고 끌 수 있습니다.

기본 지도를 주는 MapTiler 도 [4장](g04-first-value.md)에서 본 API 이고 순서(설명 → 링크 → 가입해서 키 받기 → 키 저장)가 같습니다. 다만 날씨와 달리, 이번에는 가입해서 받은 키가 꼭 필요합니다.

### 3. MapTiler 키 받기 { #step-3 }

1. [cloud.maptiler.com](https://cloud.maptiler.com/) 에서 이메일로 계정을 만듭니다.
2. 가입하면 키 화면이 나옵니다. 나오지 않으면 로그인해 **API keys** 화면([cloud.maptiler.com/account/keys](https://cloud.maptiler.com/account/keys/))을 여세요.
3. 키 문자열을 복사해 두세요. 키는 [4장](g04-first-value.md)에서 본 신분증과 같으니, 다른 사람에게도 AI 에게도 보여 주지 마세요.

!!! note "무료 사용 조건"
    MapTiler 무료 사용은 테스트나 개인, 비상업 용도가 기준이니 가입할 때 조건을 확인하세요. 한 달 사용량을 넘으면 다음 달까지 지도가 멈춥니다(지도 바탕이 나오지 않음). 사용량은 MapTiler 계정 화면에서 볼 수 있습니다.

### 4. 지리 정보 입력에 MapTiler 추가하기 { #step-4 }

1. **설정 → 지리 정보 입력**을 엽니다.
2. **GIS 서비스 선택** 목록을 열고 `GL: MapTiler Vector` 를 골라 **추가**를 누르세요. 카드와 설정 창은 [첫 번째 데이터](g04-first-value.md)의 입력과 같은 모양입니다.
3. 새 카드의 톱니바퀴를 눌러 설정 창을 열고, 복사해 둔 키를 **MapTiler API 키** 칸에 붙여 넣으세요.
4. **지도 채널 설정**에서 쓸 바탕을 켜세요. 바탕은 도로나 위성처럼 여러 개를 켜 둘 수 있습니다.
5. **저장**한 뒤 카드의 **활성화**를 누르세요. 새로 추가한 입력은 꺼진 채로 만들어지므로 활성화까지 눌러야 지도 바탕이 나옵니다.
6. 지도 페이지를 열면 바탕이 나옵니다. 오른쪽 위의 **레이어** 버튼에서 기본 지도와 오버레이를 바꿉니다.

### 5. 시작 위치 정하기 { #step-5 }

1. 설정 → **지도**를 엽니다. 처음 열면 "My design" 이라는 지도가 하나 만들어져 있습니다(**편집**에서 이름을 바꿀 수 있고, 지도 하나에 대지와 시설을 모두 그려도 됩니다).
2. 지도를 현장 A 가 있는 쪽으로 옮긴 뒤, 오른쪽 위 **설정** → **기본 시작 위치**에서 **위치 가져오기**를 누르고 **저장**하세요.

시작 위치는 **새로 만드는 지도**와 **새로 추가하는 입력·출력의 기본 위치**에 쓰입니다(기본값은 서울). 그래서 이렇게 해 두면 새 지도와 앞으로 추가하는 입력·출력의 기본 위치가 내 현장 근처로 잡힙니다. 이미 있는 지도는 마지막으로 보던 자리에서 열립니다.

### 6. 대지 그리기 { #step-6 }

1. 지도 아래쪽 탭 줄(대지·구역·시설·구획·장비·A)에서 **대지**를 고르세요.
2. 오른쪽 그리기 도구에서 **다각형**을 고르고 현장 A 의 경계를 따라 꼭짓점을 차례로 누르세요. **마우스 오른쪽 버튼**을 누르면 도형이 닫힙니다(마지막 점이 처음 점과 이어집니다. 점을 세 개 이상 찍었다면 두 번 클릭이나 Esc 로도 마칠 수 있고, 잘못 찍은 점은 Backspace 로 지웁니다).
3. 도형 가운데의 이름 글자를 **두 번 눌러** 이름 입력 창을 열고 "현장 A" 라는 이름을 붙이세요. 대지는 가장 큰 단위라서, 이 안에 구역과 시설이 차례로 들어갑니다.

**모양 고치기**: 오른쪽 도구의 **레이어 편집**을 누르고 도형을 고르면 꼭짓점과 변의 가운데에 점이 나타납니다. 꼭짓점은 끌어서 옮기고, 변 가운데 점을 누르면 그 자리에 새 꼭짓점이 생깁니다. 편집 중에는 자동으로 저장되지 않으니 다 고쳤으면 **저장**, 되돌리려면 **취소**를 누르세요.

### 7. 주소로 대지 가져오기(한국) { #step-7 }

직접 그리는 대신, 한국에서는 주소로 필지 경계를 그대로 대지로 만들 수도 있습니다. 필지가 여러 개인 현장에서 특히 빠릅니다. 브이월드 키가 지리 정보 입력에 등록되어 있어야 합니다(키 받는 순서는 MapTiler 와 같습니다).

1. **대지** 탭의 대지 서랍에서 **주소로 추가** 옆의 **검색**을 누르세요. **주소로 대지 가져오기** 창이 열립니다.
2. **주소 입력** 탭에 주소를 넣으세요. 여러 개는 쉼표로 나누거나 **주소 추가**로 입력란을 늘립니다. **검색**을 누르면 찾은 필지의 경계가 지도에 그려지고, 실패한 주소는 이유와 함께 표시됩니다.
3. 필지가 많으면 **CSV 일괄** 탭에서 파일로 한꺼번에 가져오세요. 파일은 첫 번째 열에 주소를 한 줄에 하나씩 적고 제목 줄은 없습니다. **CSV 파일 선택** → **업로드 및 처리**.
4. 찾은 필지는 미리보기에 나옵니다. 미리보기 아래에서 **인접 필지 통합**(기본 꺼짐)을 켜면 맞닿은 필지를 하나의 대지로 합치고, 꺼 두면 필지마다 대지가 하나씩 생깁니다. **대지 이름**을 확인하고 **대지로 저장**을 누르세요.

### 8. 구역 그리기 { #step-8 }

현장 A 는 노지에 구역 둘을 그립니다. **구역** 탭에서 대지와 같은 방법으로 3-1 과 3-2 를 그리고 이름을 붙이세요.

- 구역은 **대지 안쪽에** 그립니다. 어느 대지에 속하는지는 도형 위치로 정해집니다.
- 구역끼리는 **겹치지 않게** 그리세요. 겹친 자리에 놓인 센서는 더 작은 구역의 것으로 처리되어, 사용자가 의도한 것과 다를 수 있습니다.
- 센서나 장치를 두지 않을 땅은 굳이 구역으로 나누지 않아도 됩니다. 현장 A 도 나머지 땅은 나누지 않았습니다.

### 9. 입력을 지도에 놓기 { #step-9 }

1. 탭 줄 끝의 **A** 를 눌러 장치 모드로 바꾸세요.
2. **장치 종류**에서 **입력**을 고르고 **선택 목록**의 **열기**를 누르세요.
3. 현장 A 는 [4장](g04-first-value.md)에서 받은 바깥 날씨 입력을 대지 위에 놓습니다. 목록에서 그 입력의 스위치를 켜면 지도 가운데에 표시가 생기고, 이 표시를 대지 위로 끌어다 놓으면 새 위치가 저절로 저장됩니다.

[4장](g04-first-value.md)에서 말씀드린 것처럼, 여러 장치의 위치는 이 화면에서 한꺼번에 정할 수 있습니다.

### 10. 대시보드에 지도 위젯 놓기 { #step-10 }

1. 대시보드로 돌아가 현장 A 탭에서 **위젯 추가 → AoT 지도**를 고르세요. **지도 선택**에서 방금 만든 지도를 고릅니다(비워 두면 가장 최근에 수정한 지도가 나옵니다).
2. 지도 위젯에는 처음에 **구획 도형**만 켜져 있습니다. 대지와 구역이 보이게 하려면 위젯 설정의 **도형**에서 켜세요. 나머지 설정(라벨 표시, 장치 필터 등)은 처음에는 그대로 두어도 됩니다.
3. 위젯의 도구:
   - 왼쪽: 확대·축소, 전체화면, 주소 검색, 내 위치, **대지 목록**. 대지 목록을 열면 이 지도의 대지가 나옵니다. 대지를 누르면 그 안의 구역이 펼쳐지고, 한 번 더 누르면 그 대지로 이동합니다.
   - 오른쪽: **레이어**, 거리 측정, 노트 추가. 노트 추가는 지도의 그 자리에 노트를 남깁니다. 레이어에서는 기본 지도를 하나 고르고 오버레이와 도형, 라벨을 켜고 끕니다.
   - 위젯 제목 줄의 **지도 잠금**은 지도를 끌거나 확대하지 못하게 고정하고, 대시보드의 잠금과는 따로 동작합니다.
4. 눌러서 보기: 지도에서 현장 A 의 3-1 구역을 누르면 구역 창이 열리고, 현황, 환경·제어, 개요 탭이 있습니다. 현장 A 대지를 누르면 대지 안의 구역 목록이 나옵니다. 시설을 만들면 시설 이름표를 눌러 시설 창도 열 수 있는데, 시설은 [다음 장](g07-facility.md)에서 살펴보겠습니다. 센서 값을 누르면 최근 24시간 그래프와 현재 값이 나오고, 노트도 바로 적을 수 있습니다. 창 위쪽의 **상위로**로 한 단계씩 올라갑니다.
5. 출력 조작(출력은 [출력](g08-output.md)에서 만듭니다): 만든 뒤에는 지도에서 이렇게 조작합니다. 현장 A 의 3-1 밸브 1 을 누르면 창에 제어, 이력, 노트가 차례로 나옵니다. 켜고 끄는 출력은 스위치로, 창문이나 커튼은 닫기·정지·열기 버튼으로, 밝기처럼 세기를 정하는 출력은 슬라이더로 조작합니다.
6. 예약: 3-1 밸브 1 처럼 켜고 끄는 출력의 **설정**을 누르면 시작 시각과 작동 시간을 정해 예약할 수 있습니다. 작동 시간을 00:00 으로 두면 직접 끌 때까지 켜져 있습니다. 예약은 서버에 등록되어 브라우저를 닫아도 예정대로 실행되고, 같은 창에서 확인하고 **지금 끄기**로 멈출 수 있습니다.
7. **지도에서 누른 조작은 바로 실행됩니다.** 승인 단계는 AI 가 올린 요청에만 있으니, 누르기 전에 대상 출력을 꼭 확인하세요. 스위치·슬라이더·예약 버튼은 제어 권한이 있는 사용자에게만 보입니다.
8. 휴대폰에서는 창을 열면 지도가 전체 화면이 됩니다. 창은 세로 화면에서는 아래에서 올라오고, 가로 화면에서는 옆에 붙습니다.

지도 위젯에는 세부 옵션이 다양하니, 매뉴얼을 참고해서 내 현장에 맞게 사용하세요.

## 확인 { #check }

- 지도 페이지와 대시보드 지도 위젯에 바탕 지도가 보인다
- 대지와 구역이 그린 만큼 보이고, 날씨 입력이 대지 위에 놓여 있다
- 이름이 "새 대지", "새 구역" 처럼 처음 이름 그대로 남은 도형이 없다

## 현장 A { #site-a }

현장 A 는 노지가 중심입니다. 현장 전체를 대지 하나("현장 A")로 그리고, 노지를 구역 3-1 과 3-2 로 나눕니다. 나머지 땅은 나누지 않습니다. 바깥 날씨 입력은 대지 위에 놓습니다. 현장 A 의 단동 온실은 다음 장에서 모형으로 세웁니다.

## 현장 B { #site-b }

현장 B 는 시설이 중심이라 [시설](g07-facility.md) 장부터 함께 나옵니다.

## 안 될 때 { #trouble }

지도가 이상하면 아래를 살펴보세요. 특히 지리 정보 입력을 추가만 하고 활성화하지 않았는지, 키가 맞고 이번 달 무료 사용량을 넘지 않았는지, 위젯 설정에서 대지와 구역 도형을 켰는지, 장치를 지도에 놓았는지 네 가지를 먼저 확인하세요.

| 증상 | 확인할 것 |
|---|---|
| 지도에 나라 경계만 보인다 | MapTiler Vector 입력이 없거나, 추가만 하고 **활성화**하지 않았습니다 |
| 지도 바탕이 회색·빈칸이다 | 키가 틀렸거나, 키의 허용 주소에 지금 접속한 주소가 빠졌거나, 이달 무료 사용량을 넘었습니다 |
| 지도 위젯에 대지·구역 도형이 안 보인다 | 위젯 설정의 **도형**에서 대지·구역을 켜세요 |
| 지도 위젯에 장치가 없다 | 장치를 지도에 놓지 않았거나, **장치 필터**에 넣어 숨겼습니다 |
| 그린 도형이 새로고침하면 사라진다 | 선이 교차하는 도형입니다. 다시 그리세요 |
| 다각형이 끝나지 않는다 | 마우스 오른쪽 버튼(또는 두 번 클릭, Esc)으로 마치세요 |
| 주소로 가져오기가 안 된다 | 브이월드 입력이 등록되어 있고 키가 맞는지 확인하세요 |

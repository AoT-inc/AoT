# 출력

밸브·펌프·창·커튼·분무기처럼 AoT 가 켜고 끄거나 움직이는 것을 **출력**이라고 부릅니다. 화면의 버튼 하나로 현장의 장치를 움직이는 기능입니다. 버튼을 누르면 현장에서 밸브가 열리고 펌프가 돌기 시작하고, 측창도 같은 방식으로 움직입니다. 사람이 직접 손을 대지 않아도, 화면에서 누른 것이 그대로 현장으로 이어집니다. 이 장에서는 장치를 움직이는 출력을 만들고, 열기·닫기 두 줄로 움직이는 창과 커튼을 하나로 묶고, 정전 뒤 상태를 정한 다음, 앞에서 만든 지도·시설·대시보드에 연결합니다.

## 이 장을 마치면 { #goal }

- 내 장치에 맞는 출력을 고르고, 가상 출력으로 켜고 꺼 본다
- 열기·닫기 두 출력을 하나로 묶고 이동 시간을 잰다
- 정전·재부팅 뒤 상태를 정한다
- 출력을 지도와 시설, 대시보드에 연결한다

## 준비 { #prepare }

- 시설이 있는 시스템([시설](g07-facility.md))
- 연결할 장치의 정보: 무엇으로 켜고 끄는지(릴레이, LoRaWAN 밸브 컨트롤러, PLC, MQTT), 창·커튼이면 끝에서 끝까지 움직이는 데 걸리는 시간
- 장치 없이 먼저 해 보려면 따로 준비할 것이 없습니다. 가상 출력을 씁니다

!!! warning "처음 연결할 때는 사람이 장비 옆에 있을 때 하세요"
    출력을 저장하거나 다시 시작하면 정한 시작 상태대로 장비에 명령이 나갈 수 있습니다. 펌프·밸브·창이 실제로 움직여도 괜찮은 시간에, 장비를 직접 지켜볼 수 있는 사람이 있을 때 연결하세요.

## 절차 { #steps }

### 1. 출력을 고르는 두 가지 { #step-1 }

출력은 두 가지를 보고 고릅니다.

- **어떻게 이어지나**(연결 방식): 장치가 AoT 와 어떻게 이어지는가입니다. 라즈베리 파이 GPIO 로 직접 잇거나, PLC(Modbus TCP)나 MQTT 로 통신하거나, ChirpStack 을 거쳐 LoRaWAN 무선으로 멀리서 잇습니다.
- **어떻게 움직이나**(작동 방식): 켜고 끄는 것, 세기를 조절하는 것(PWM), 위치를 퍼센트로 다루는 것(열기·닫기를 묶은 출력)이 있습니다.

### 2. 출력 추가하기 { #step-2 }

**설정 → 출력**에서 목록의 종류를 고르고 **추가**를 누릅니다. 카드와 설정 창은 [첫 번째 데이터](g04-first-value.md)의 입력과 같은 모양입니다. 내 장치와 같은 연결 방식을 고르면 나머지 설정이 그에 맞게 나타납니다. 이름에는 어디에 있는 무엇인지 알 수 있게, 현장에서 부르는 이름 그대로 붙이세요. 현장 A 는 "3-1 밸브 1", "측창 좌"처럼 붙입니다. 목록·지도·알림 메일에 모두 이 이름이 나옵니다.

| 무엇으로 켜고 끄나 | 고를 종류 |
|---|---|
| 라즈베리 파이 핀의 릴레이 | Raspberry Pi GPIO |
| LoRaWAN 밸브 컨트롤러 | ChirpStack gRPC |
| PLC | Modbus TCP Coil (PLC) |
| MQTT 로 명령을 받는 기기 | MQTT Publish |
| 장비 없이 연습 | Virtual Single-Channel (가상 출력) |

### 3. 가상 출력으로 연습하기 { #step-3 }

장비가 아직 없어도 가상 출력으로 먼저 연습할 수 있습니다. **Virtual Single-Channel** 을 추가하고 카드의 **켜기**·**끄기**를 눌러 보세요. 화면의 상태가 바뀌는 것을 확인하면, 진짜 장치를 붙였을 때도 같은 방식으로 다룹니다. 진짜 장치는 처음 켜 볼 때 장치 옆에서 사람이 지켜보세요. 몇 초만 켜려면 카드의 톱니바퀴로 출력 설정을 열고 **지속시간**에 초 단위 시간을 넣은 뒤 **보내기**를 누릅니다.

### 4. LoRaWAN 밸브 { #step-4 }

현장 A 의 노지 밸브와 펌프는 무선 LoRaWAN 밸브 컨트롤러에 달려 있어서, **ChirpStack gRPC** 출력으로 만들고 밸브마다 "3-1 밸브 1" 처럼 이름을 붙입니다. LoRaWAN 은 명령이 장치에 닿기까지 시간이 걸립니다. 누르면 **확인 중…** 이 나오고, 응답이 없으면 **응답 없음**이나 **연결 없음**이 나옵니다. 채널 줄에 나오는 표시는 다음과 같습니다.

| 표시 | 뜻 |
|---|---|
| 확인 중… | 명령을 보냈고 장치의 확인을 기다리는 중 |
| 응답 없음 | 정해진 시간 안에 확인이 오지 않음. 카드는 이전 상태로 돌아감 |
| 연결 없음 | 장치와 통신이 안 됨 |

### 5. 열기와 닫기를 하나로 묶기 { #step-5 }

측창·천창·커튼은 보통 모터 하나에 "열기" 릴레이와 "닫기" 릴레이가 따로 있습니다. 현장 B 의 제어반에도 이렇게 열기와 닫기를 따로 켜는 릴레이가 있습니다. 두 릴레이가 동시에 켜지면 안 되는데, 따로 다루면 번거롭고 실수하기 쉽습니다. 그래서 둘을 각각 출력으로 만든 뒤, **Actuator Paired** 출력을 하나 더 만들어 하나의 장치로 묶고 위치로 다룹니다. 열기 출력과 닫기 출력을 골라 묶으면, 위치를 퍼센트로 정하는 장치 하나가 됩니다.

1. **액추에이터 종류**를 고릅니다. 창인지 커튼인지 정하세요(측면 환기창, 지붕 환기창, 보온 커튼, 차광 커튼).
2. **출력: 열기**와 **출력: 닫기**에 두 출력을 고릅니다.
3. 저장한 뒤 카드의 **닫기**를 눌러 완전히 닫힌 상태(0%)에서 시작합니다.

묶은 카드에는 **닫기 / 정지 / 열기** 버튼과 열림 %가 나옵니다. 두 릴레이가 동시에 켜지지 않도록 방향을 바꿀 때는 잠깐 멈추었다가 움직입니다(**역방향 일시정지**, 기본 5초). 묶은 뒤에는 묶은 출력만 쓰세요. 묶는 데 쓴 열기·닫기 출력을 직접 켜면 AoT 가 기억하는 열림 %가 실제와 달라집니다.

### 6. 이동 시간 재기 { #step-6 }

이동 시간은 끝에서 끝까지 움직이는 데 걸리는 시간입니다. AoT 는 이 시간으로 지금 몇 % 열렸는지 계산하니, 재 두어야 합니다. 묶은 출력 설정 아래쪽 **명령**에서 **▶ 캘리브레이션 시작**의 **실행**을 눌러 끝까지 움직인 뒤, 끝에 닿으면 **■ 정지 및 저장**의 **실행**을 누르세요. 걸린 시간이 이동 시간으로 저장됩니다. 창과 커튼마다 걸리는 시간이 다르니 각각 재세요.

### 7. 정전 뒤 상태 정하기 { #step-7 }

전원이 나갔다가 다시 들어왔을 때 이 출력을 켜 둘지 꺼 둘지는, 각 출력의 채널 설정에 있는 **시작 상태**에서 미리 정합니다. 밸브·펌프·분무기는 끔(Off)으로 정하세요. 전기가 돌아왔을 때 물이 저절로 나가지 않습니다. 묶은 창·커튼은 시작 상태가 없고 마지막 위치를 기억합니다. 움직이는 중에 전원이 나가면 위치를 알 수 없게 되고, 기억한 위치가 실제와 다를 수 있습니다. 재시작 뒤에 **닫기**를 눌러 끝까지 닫으면 0% 에서 기준이 다시 잡힙니다.

### 8. 지도에 놓고 조작하기 { #step-8 }

출력을 지도에 놓는 방법은 [6장](g06-map.md)에서 입력을 놓은 것과 같습니다. 탭 줄 끝의 **A**(장치 모드)에서 **장치 종류**를 출력으로 바꾸고, **선택 목록**에서 켠 다음, 현장 A 의 3-1 구역 안으로 표시를 끌어다 놓으세요. 놓고 나면 지도 위젯에서 "3-1 밸브 1" 을 눌러 켜 볼 수 있습니다. 켜고 끄는 조작과 예약은 6장에서 본 그대로입니다.

### 9. 시설에 연결하기 { #step-9 }

[7장](g07-facility.md)에서 세운 시설의 **설비 배치**로 돌아갑니다. **구성요소** 표에서 측창·창호·커튼 행의 **액추에이터** 칸을 열고, 방금 묶은 출력을 고른 뒤 **시설 저장**을 누르세요. 현장 B 는 측창과 천창, 보온 커튼에 각각 연결합니다. 그러면 시설 위젯에서 창과 커튼을 열고 닫을 수 있고, 9장부터는 통합 환경 제어가 이 장치를 움직입니다.

### 10. 대시보드에 타이머 놓기 { #step-10 }

대시보드에는 타이머 위젯으로 출력을 놓습니다. 현장 A 탭에서 **위젯 추가 → AoT 타이머**를 고르고 출력 하나(현장 A 는 "3-1 밸브 1")를 고르세요. 켜고 끄거나, 작동과 휴식을 정한 횟수만큼 반복시킬 수 있습니다. 세부 옵션은 매뉴얼의 위젯 목록을 참고해서 내 현장에 맞게 사용하세요.

!!! warning "안전은 하드웨어에도"
    소프트웨어만 믿지 마세요. 현장에는 비상 정지와 한계 스위치도 함께 두세요. 장치를 처음 연결할 때는 사람이 옆에서 지켜보는 것이 좋습니다.

## 확인 { #check }

각 출력을 직접 켜고 껐을 때 장비가 실제로 움직이고 카드가 바뀌면 연결이 끝난 것입니다.

- 밸브·펌프: 켜기 → 눈으로 확인 → 끄기
- 묶은 창: 닫기(0%) → 열기 50% → 절반쯤 열렸는지 확인 → 닫기
- 다시 시작한 뒤 모든 출력이 정한 시작 상태로 돌아오는지 확인

지금까지 장치를 출력으로 만들고, 지도와 시설과 대시보드에 연결했습니다. 다음 장에서는 이 출력을 언제 움직일지 정하는 함수를 배웁니다.

## 현장 A { #site-a }

현장 A 는 노지 밸브와 펌프를 LoRaWAN 밸브 컨트롤러의 출력으로 만들고, 구역 3-1 과 3-2 에 이름을 붙여 지도에 놓습니다. 단동 온실의 측창 좌·우도 같은 방법으로 열기·닫기를 묶는데, 이때 `Actuator Paired (Shared Bus)` 를 씁니다(두 창이 모터 전원 한 줄을 나눠 쓰기 때문입니다). 이 측창은 구형 개폐기에 릴레이를 연결해 원격으로 여닫는 것이고, 릴레이를 연결하는 방법은 하드웨어 안내에서 다룹니다. 현장 A 의 온실에서 원격으로 조작하는 것은 측창뿐입니다.

## 현장 B { #site-b }

현장 B 는 기존 제어반의 열기·닫기 릴레이를 그대로 쓰고, AoT 에서는 측창·천창·보온 커튼을 각각 `Actuator Paired` 로 묶습니다. 분무기는 켜기·끄기 출력입니다. 기존 설비는 오래된 모터가 명판보다 느린 경우가 많으니 이동 시간을 반드시 다시 재세요.

## 안 될 때 { #trouble }

출력이 마음대로 되지 않으면 다음을 살펴보세요.

| 증상 | 확인할 것 |
|---|---|
| "응답 없음"이 나온다 | 장치 전원과 통신을 살펴보세요. LoRaWAN 이라면 무선 장치와 게이트웨이의 연결, 그 사이의 신호를 확인하세요 |
| 눌러도 반응이 없다 | 연결 방식과 주소·채널이 맞는지 확인하세요 |
| 창이 이상하게 움직인다 | 열기·닫기를 따로 누르지 말고, 묶은 출력으로 조작하는지 확인하세요 |
| 묶은 창이 움직이지 않는다 | **출력: 열기/닫기**를 다시 골라 저장하세요 |
| 열린 정도가 실제와 다르다 | 이동 시간을 다시 재고, 닫기로 0% 를 맞춘 뒤 다시 시도하세요 |
| 재시작하자 밸브가 열렸다 | 그 출력의 시작 상태가 켬(On)인지 확인하세요 |

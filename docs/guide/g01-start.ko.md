# 시작하며

AoT 를 처음 사용하시는 분들을 위한 가이드입니다.
평소에는 컴퓨터를 업무나 개인적인 용도로만 써 왔지만, 이제 내 현장의 값을 보고 장치를 자동으로 움직이고 싶은 분께 이 가이드가 도움이 되기를 바랍니다.
설치하다 막히면 이 페이지 주소와 화면의 오류를 AI 에게 주세요. 자세한 방법은 다음 장([가이드 사용하는 방법](g02-ask-ai.md))에서 설명하겠습니다.

## 이 장을 마치면 { #goal }

- AoT 로 무엇을 할 수 있는지 안다
- 평소에는 알아서 작동하고, 일이 생기면 알림이 온다는 것을 안다
- 설치하기 전에 무엇을 준비해야 하는지 안다
- 가이드의 14장이 어떻게 이어지는지 안다

## 준비 { #prepare }

준비물은 세 가지입니다.

| 준비물 | 설명 |
|---|---|
| 24시간 켜 둘 컴퓨터 | AoT 는 이 컴퓨터에서 쉬지 않고 돕니다. 꺼지거나 잠자기에 들면 자동 제어도 멈춥니다. 컴퓨터를 왜 24시간 켜 두는지는 [설치](g03-install.md)에서 설명하겠습니다 |
| 인터넷 | 설치 파일을 받고, 날씨 같은 외부 데이터를 받습니다 |
| 브라우저 | AoT 화면을 여는 곳입니다(Chrome·Edge·Safari 등) |

**장비가 없어도 됩니다**

센서나 장치가 없어도 끝까지 따라 할 수 있습니다.

| 실제 현장에서는 | 이 가이드에서는 |
|---|---|
| 센서 | 인터넷에서 받아오는 날씨 값([첫 번째 데이터](g04-first-value.md)) |
| 장치 | 켜고 끄는 흉내만 내는 가상 출력([출력](g08-output.md)) |

**어떤 컴퓨터에 어떻게 설치하나**

Windows 와 Mac 은 Docker Desktop 으로 설치합니다. 이 가이드에서는 이 방법을 위주로 설명합니다. 라즈베리 파이와 Linux 는 뒤에서 따로 안내하겠습니다.

| 컴퓨터 | 설치 방법 | 안내 |
|---|---|---|
| Windows·Mac | Docker Desktop(화면으로 설치) | 이 가이드의 [설치](g03-install.md) |
| Linux 서버·미니 PC | Docker | 뒤에서 따로 안내합니다 |
| 라즈베리 파이 | Docker 또는 직접 설치 | 뒤에서 따로 안내합니다. 센서·릴레이를 파이의 핀에 직접 연결할 때는 직접 설치 |

## 절차 { #steps }

### 1. AoT 가 하는 일 { #step-1 }

현장에는 온도와 습도를 재는 센서가 있고, 물을 여닫는 밸브나 바람을 드나들게 하는 창 같은 장치가 있습니다.
AoT 는 이 값과 장치를 한 화면에 모아 보고, 사용자가 설정한 대로 움직이게 합니다.

**공간 위에 쌓습니다**

AoT 는 오픈소스이며, 내 공간 위에 세 가지를 차례로 쌓습니다.

- **지도**: 내 공간을 지도에 담습니다
- **기록과 장치**: 그곳의 기록과 장치를 연결합니다
- **AI**: 그 공간을 AI 가 사람과 함께 보고, 판단하고, 작업할 수 있게 만듭니다

**AI 는 제안하고, 사람이 승인합니다**

AI 는 보고, 판단하고, 제안합니다. 하지만 혼자 장치를 움직이지는 않습니다. 장치를 움직이는 일은 사람이 승인해야 실행됩니다. AI 는 마지막 장에서 다룹니다.

**하나씩 붙여 만듭니다**

처음 설치하면 화면이 비어 있는, **아무것도 없는 뼈대**입니다.
입력을 붙이면 값이 들어오고, 지도를 그리면 현장이 보입니다. 여기에 지도 위젯 같은 위젯을 배치하면 내 현장의 화면, 곧 대시보드가 됩니다.
어떤 위젯을 배치할지, 무엇을 붙일지는 사용자가 정합니다.

값이 오가는 흐름은 이렇습니다. **입력**은 센서나 인터넷에서 값을 받아 오고, **함수**는 그 값을 보고 판단하고, **출력**으로 장치를 켜고 끕니다.

| 붙이는 것 | 하는 일 | 장 |
|---|---|---|
| **입력** | 센서나 인터넷의 API 에서 값을 받아 옵니다 | [첫 번째 데이터](g04-first-value.md) |
| **출력** | 밸브·펌프·창·커튼 같은 장치를 켜고 끄고 움직입니다 | [출력](g08-output.md) |
| **함수** | 입력과 출력을 함께 써서, 값을 보고 판단해 설정한 대로 작동하게 합니다 | 뒤의 함수·자동화 장 |
| **지도·시설** | 현장을 지도에 담고, 온실 같은 건물을 크기와 구조로 만듭니다 | [지도](g06-map.md), [시설](g07-facility.md) |
| **대시보드** | 보고 싶은 것과 자주 누르는 것을 한 화면에 모읍니다 | [대시보드](g05-dashboard.md) |

**매일 들여다보지 않아도 됩니다**

목표는 매일 화면을 들여다보는 것이 아닙니다. 평소에는 AoT 가 알아서 작동합니다.
일이 생기면 알림이 옵니다. 알림이 오면 무엇을 볼지까지, 이 가이드에서 함께 만들겠습니다.

### 2. 가이드의 흐름 { #step-2 }

가이드는 14개의 장으로 구성되어 있습니다. 설치부터 첫 번째 데이터, 대시보드와 지도, 자동화와 설정, 알림과 위기 대응, 그리고 AI 까지 이어집니다.

| 장 | 하는 일 | 끝나면 |
|---|---|---|
| [시작하며](g01-start.md) | 무엇을 할 수 있고 무엇을 준비하는지 본다 | 준비물을 안다 |
| [가이드 사용하는 방법](g02-ask-ai.md) | 가이드를 쓰는 법과, 막혔을 때 AI 에게 무엇을 줄지 익힌다 | 혼자 막혀 있지 않는다 |
| [설치](g03-install.md) | Docker Desktop 으로 설치하고 24시간 돌게 한다 | 브라우저로 로그인된다 |
| [첫 번째 데이터](g04-first-value.md) | 날씨 입력으로 첫 값을 띄우고, 입력·외부 API 쓰는 법을 익힌다 | 값이 들어온다 |
| [대시보드](g05-dashboard.md) | 탭과 위젯으로 내 화면을 만든다 | 첫 값이 위젯으로 보인다 |
| [지도](g06-map.md) | 대지·구역을 그리고 입력을 지도에 놓는다 | 현장이 지도에 보인다 |
| [시설](g07-facility.md) | 온실 같은 건물을 만든다 | 시설이 지도 위에 선다 |
| [출력](g08-output.md) | 장치를 출력으로 붙이고 켜고 끈다 | 화면에서 장치를 움직인다 |
| 함수 | 함수 종류를 알고 하나를 만든다 | 정한 때에 장치가 움직인다 |
| 자동화 | 입력·출력·함수를 이어 하나의 로직을 만든다 | VPD 제어·순차 관수가 돈다 |
| 설정 | 사용자·단위·메일 계정 같은 시스템 규칙을 정한다 | 여러 사람이 쓰고, 메일을 보낼 수 있다 |
| 알림 | 토스트·메일·로그·감사 기록을 읽는다 | 무엇을 알릴지 정한다 |
| 위기 대응 | 이상을 발견하고 원격으로 좁히고, 백업·복구한다 | 문제가 생겨도 되돌릴 수 있다 |
| AI | AI 와 함께 보고, 설정하고, 기록한다 | AI 가 현장을 함께 본다 |

다음 장에서는 가이드를 사용하는 방법을 살펴보겠습니다.

## 확인 { #check }

- 24시간 켜 둘 컴퓨터가 Windows·Mac 인지, Linux·라즈베리 파이인지 안다
- 막히면 이 페이지 주소와 화면의 오류를 AI 에게 준다는 것을 안다(자세한 방법은 [가이드 사용하는 방법](g02-ask-ai.md))

## 현장 A { #site-a }

가이드에는 같은 AoT 를 쓰는 두 현장이 예로 나옵니다. 현장 A 는 노지와 시설을 함께 다루고, 현장 B 는 기존 온실 설비에 연결했습니다.

현장 A 는 **노지와 시설이 함께 있는 현장**입니다. 약 3만㎡ 의 대지에 노지 구역 두 곳과 단동 온실 한 동이 있습니다.

- 센서: 노지 온습도·토양 수분(무선), 바깥 날씨(날씨 API)
- 장치: 노지 밸브 8개와 펌프, 온실 측창 좌·우(구형 개폐기에 릴레이를 연결해 원격으로 여닫습니다)
- 자동 제어: 노지는 요일·시간대별 순차 관수. 온실은 자동 제어 없이, 필요할 때 사람이 측창만 원격으로 조작합니다

## 현장 B { #site-b }

**기존 온실 설비에 연결한 시설 현장**입니다. 원래 있던 6동 연동 온실의 제어 설비에 AoT 를 연결했습니다.

- 센서: 온실 안 온습도 5곳과 바깥 기상대
- 장치: 측창·천창·보온커튼(기존 제어반의 열기·닫기 릴레이를 그대로 씀), 분무기
- 자동 제어: 온실 전체를 환경 제어 하나가 맡음

두 현장은 고르는 것이 아니라 참고하는 예시입니다. 노지 위주면 현장 A, 시설 위주면 현장 B 쪽을 참고하세요.

## 안 될 때 { #trouble }

| 증상 | 확인할 것 |
|---|---|
| 설치하다 막혔다 | 이 페이지 주소와 화면의 오류를 AI 에게 주세요. 자세한 방법은 [가이드 사용하는 방법](g02-ask-ai.md)에 있습니다 |
| 가이드의 화면 이름·버튼이 실제 화면과 다르다 | 설치한 AoT 의 버전. **관리 → 시스템 정보**에서 확인하세요. 이 가이드는 AoT 26.09.08 을 기준으로 합니다 |
| 무엇부터 해야 할지 모르겠다 | [설치](g03-install.md)부터 차례대로 하세요. 막히면 [가이드 사용하는 방법](g02-ask-ai.md) |

# 地図の構成

AoT は、センサーやデバイスが**どこに**あるかを知っていると、より多くのことができます。ゾーンごとに値を集めて表示し、
温室 1 棟の窓とセンサーをまとめて環境を制御し、区画ごとに何をいつ始めたかを記録します。
この章では、現場を地図に写します。地図を使わなくても AoT は動作しますが、ゾーンや施設が複数ある
現場なら、先に描いておくと後の章が楽になります。

地図に描くものは 4 種類です。

| 描くもの | 意味 | 例 |
|---|---|---|
| サイト | 現場全体の境界 | 現場 A 全体 |
| ゾーン | サイトの中を分けた土地 | 露地 3-1、3-2 |
| 施設 | 建物や温室。大きさと構造を入力して作成します | 単棟温室、6 連棟温室 |
| 区画 | ゾーンや施設の中で、一つの対象を育てたり管理したりする場所 | 3-1 の大豆の区画、温室内のレタス 3 ベッド |

**一つの地図に、管理するサイトと施設をすべて入れてもかまいません。** サイトごとに地図を分けて作る必要はありません。
地図を分けるのは管理しやすくするための選択であり、分けるとよい場合は [手順 5](#step-5) で説明します。

## この章を終えると { #goal }

- 背景地図（MapTiler）を登録し、地図画面に背景が表示されるようにする
- 現場の境界、ゾーン、施設を地図に描く
- 露地のゾーンと施設を区別し、その中に区画を作る

## 始める前に { #prepare }

- 最初の設定を終えた AoT（[主な設定](g02-settings.md#check)）
- 現場の位置（住所またはおおよその座標）、ゾーンを分ける基準、各施設の大きさ（幅・長さ・高さ・棟数）
- メールアドレス 1 つ：背景地図（MapTiler）のアカウントを作るときに使います
- 地番（筆）の境界をそのまま取り込みたい場合は VWorld のキー（任意）

## 手順 { #steps }

インストールしたばかりの AoT には**地図が一つもありません。** 地図画面を開いても、国境程度しか見えない空の背景が
表示されます。そこで、まず背景地図の取得元（**GIS入力**）を登録します。

現在、AoT でベクター地図の提供元は **MapTiler** です。地図画面（地図デザイン、ダッシュボードの地図ウィジェット、日誌の地図）は、
最初に開いたときに有効な MapTiler の地図を背景として表示し、地図の **レイヤー** ボタンで別の背景に切り替えられます。
そのため、MapTiler のキーを取得して MapTiler Vector の入力を一つ作ることが最初の手順です。

### 1. MapTiler のキーを取得する { #step-1 }

MapTiler のキー発行ページは、[手順 2](#step-2) の入力設定ウィンドウにある **API キー** のリンクからも開けます。

1. [cloud.maptiler.com](https://cloud.maptiler.com/) でアカウントを作成します（メールで登録し、無料プランから始められます）。
2. ログインしたら **API keys** のページ（[cloud.maptiler.com/account/keys](https://cloud.maptiler.com/account/keys/)）を開きます。
   既定のキーがすでに一つあります。新しく作る場合は **New key** をクリックし、名前（例：「AoT 現場 A」）を付けます。
3. キーの文字列をコピーして控えておきます。
4. キーの許可アドレス（Allowed HTTP origins）に AoT を開くアドレスを登録しておくと、キーが漏れても他のサイトでは
   使えません。現場ネットワークのアドレス（`http://192.168.x.x:8084`）と外部からのアクセス用アドレス（[ネットワーク接続](g03-network.md)で
   設定したアドレス）を**両方**登録してください。一覧にないアドレスから AoT を開くと、そのアドレスでだけ地図が読み込まれません。

!!! note "無料プランの使用量"
    MapTiler の無料プランには、月ごとの使用量の上限が決まっています。一つの現場を数人で見る程度なら
    たいてい十分ですが、上限を超えるとその月の残りの期間は地図の背景が読み込まれません。使用量は MapTiler のアカウントページで確認できます。

### 2. GIS入力に MapTiler の地図を追加する { #step-2 }

1. AoT で 設定 → **GIS入力** を開きます（ページタイトル：GIS入力マネージャー）。最初は一覧が空です。
2. **GISサービスを選択** の一覧で `GL: MapTiler Vector` を選び、**追加** をクリックします。
3. 新しくできたカードの歯車アイコンをクリックして、**入力設定: GL: MapTiler Vector** ウィンドウを開きます。
   - **MapTiler APIキー**：手順 1 でコピーしたキー
   - **地図チャネル設定**：チャネル（ストリート、屋外、衛星、ハイブリッド、海洋、地形）ごとに **ステータス** のスイッチがあります。
     使う背景をオンにします。複数オンにしておくと地図の **レイヤー** ボタンで選んで切り替えられ、最初に開いたときはオンにしたチャネルのうち最初のものが表示されます。
     一般的な地図なら **ストリート**、衛星画像に道路と地名を重ねるなら **ハイブリッド** が適しています。
   - **ラベルの言語**：`ko`（韓国語の地名）。空欄のままにするか `auto` にすると、ブラウザの言語に従います。
   - **保存** をクリックします。
4. カードの **有効化** をクリックします。新しく追加した GIS 入力は**オフの状態で作成される**ため、この手順は見落としがちです。

### 3. 他の地図を重ねる（任意） { #step-3 }

同じ **GISサービスを選択** の一覧から地図をさらに追加して **有効化** すると、地図画面の **レイヤー** ボタンに表示されます。
レイヤーウィンドウの **ベースマップ** は一度に一つだけ選び、**オーバーレイ** は背景の上に複数重ねてオンにできます。
最後に選んだ背景は記憶され、次に開いたときもそのまま表示されます。

| 地図 | キー | 用途 |
|---|---|---|
| Esri World Imagery | 不要 | 他の衛星画像と比較するとき |
| OpenStreetMap | 不要 | 道路地図 |
| VWorld | 必要（[vworld.kr](https://www.vworld.kr/) で発行） | 韓国の航空写真・地籍図、住所から筆の境界を取り込む |

### 4. 開始位置を決める { #step-4 }

1. 設定 → **地図** を開きます（ページタイトル：空間デザインスタジオ）。
2. 右上の **設定** ボタン → **デフォルト開始位置** で緯度・経度・ズームを入力するか、地図を現場まで動かしてから
   **位置情報を取得** をクリックし、**保存** をクリックします。

開始位置は**これから作成する地図**にだけ使われます。既存の地図は、最後に表示していた位置で開きます。

### 5. 地図を作る・分ける { #step-5 }

地図画面を初めて開くと、**My design** という地図が一つすでにあります。**編集** をクリックし、**地図設定** ダイアログの
**名前** をわかりやすい名前に変更します。この一つの地図に、管理するサイトと施設をすべて描いてもかまいません。

地図が一つのときは、サイトの間を **サイト一覧** で移動します。地図の左側のツールで **サイト一覧** をクリックするとサイトの名前が
表示され、名前をクリックするとその地図がそのサイトに移動します。ダッシュボードの地図ウィジェットにも同じボタンがあります
（[ダッシュボードの構成](g10-dashboard.md#step-5)）。

地図を分けるとよいのは、次のような場合です。

| 場合 | 地図を分けると |
|---|---|
| 人によって操作できる現場を変える必要があるとき | **地図設定** の **グループを選択** で、その地図を操作できるグループを決めます。データは全員に表示され、図形の保存・削除などの操作だけがそのグループに制限されます |
| 一つの現場を別にやり取りする必要があるとき | 地図画面の下にある **データ処理** の **マップをエクスポート** / **マップをインポート** が地図単位で動作します |
| ダッシュボードに現場ごとの地図を別に置きたいとき | 地図ウィジェットは一つの地図を表示します |

地図をさらに作る場合は、**地図を選択** ボックスで **新しい地図を作成** を選びます。新しい地図は「New Design Map」という名前ですぐに
保存され、[手順 4](#step-4) の開始位置で開きます。**編集** ボタンをクリックして名前を変更してください。

### 6. サイトを描く { #step-6 }

1. 地図の下端にあるタブの並び（サイト・ゾーン・施設・区画・設備・A）から **サイト** を選びます。
2. 右側の描画ツールで **ポリゴン** を選び、現場の境界の角を順にクリックします。
   **マウスの右ボタン**を押すと、最後の点が最初の点とつながって図形が完成します（点を3つ以上置いた場合は、ダブルクリックや Esc でも終えられます）。
   描いている途中で間違えて打った点は Backspace で消します。四角形・円のツールもあります。
3. 図形の中央にある名前の文字を**ダブルクリック**すると、名前の入力ウィンドウが開きます。現場の名前を入力して **保存** をクリックします。
   新しく描いたサイトの名前は、最初は「新しいサイト」です。

**形を直す**：右側のツールの **レイヤーを編集** をクリックして図形を選ぶと、角と辺の中央に点が表示されます。
角はドラッグして動かし、**辺の中央の点をクリックまたはドラッグすると、その位置に新しい角ができ**、思いどおりの形にできます。
直し終えたら **保存**、元に戻すには **キャンセル** をクリックします。編集中は自動では保存されません。

**住所からサイトを取り込む（大韓民国）**：VWorld の地図を GIS入力に登録して有効にしてあれば（[手順 3](#step-3)）、サイトのドロワーの
**住所から追加 → 検索** で、筆の境界をそのままサイトにできます。

- **住所入力** タブ：住所を複数行入力できます（**+ 住所を追加** または Enter）。**検索** をクリックすると、見つかった筆が地図に表示されます。
- **CSV一括** タブ：1 列目に住所を 1 行ずつ書いた CSV ファイル（UTF-8、見出し行なし）を、**CSVファイルを選択** → **アップロードして処理** でまとめて検索します。
- 検索結果が出ると、下に **隣接する筆を統合**、**サイト名**、**サイトとして保存** が表示されます。**隣接する筆を統合** をオンにすると、見つかった筆を**すべて合わせて一つのサイト**にし、オフにすると筆ごとにサイトが一つずつできます。
- **サイト名** を確認して **サイトとして保存** をクリックします。同じ地図にすでにある筆はスキップされます。

### 7. ゾーンを分ける { #step-7 }

**ゾーン** タブで、サイトと同じ方法でゾーンを描き、名前を付けます。

- ゾーンは**サイトの内側に**描きます。どのサイトに属するかは、AoT が図形の位置から判断します。
- ゾーン同士が**重ならないように**描きます。二つのゾーンが重なった場所に置いたセンサーや区画は、二つのうち
  **小さいほうのゾーン**に属するものとして扱われ、描いた人の意図と異なる場合があります。
- センサーもデバイスも区画も置かない土地は、ゾーンに分けなくてもかまいません。

### 8. 施設を作る { #step-8 }

温室、畜舎、倉庫のように構造がある建物は、線で描かずに**施設画面**で作成します。

1. 設定 → **施設** を開きます。上部のステップバーに 基本情報 · 位置・構造 · エンベロープ · 設備配置 · 連携 · 区画 · レビュー の順で表示されます。
2. **基本情報**：**+ 新規施設** → 名前、プリセット、スパン（幅）、軒高、棟高、長さ、屋根の種類を入力します。
3. **位置・構造**：地図とサイトを選びます。複数の棟がつながった温室の場合は、構造を**連棟**にして棟数を入力します。
   **地図に配置** をクリックし、地図上で施設の中心をクリックしてから、ドラッグして位置を合わせ、回転角度を調整します。
   サイトが一つもない地図では、**地図に配置** ボタンが表示されません。先にサイトを描いてください（[手順 6](#step-6)）。
4. **施設を保存** をクリックします。

!!! note "地図画面の施設タブでは描かないでください"
    地図画面で施設の形を線で描くと、大きさや構造の情報がない図形だけが残り、クリックしても施設が
    開きません。施設は必ず施設画面で作成してください。

### 9. 区画を作る { #step-9 }

**露地の区画**：地図画面の **区画** タブで四角形または多角形を描くと、**新しい区画** ウィンドウが開きます。
種類、品目、品種、区画名、プログラム、開始日、終了予定日を入力して保存します。一つのゾーンを同じ大きさの
複数の区画に分けるには、**区画に分ける** を使います。

**施設の区画**：施設画面の **区画** ステップには、**位置・構造** で分けたゾーンごとに欄があります。区画を置くゾーンの欄で
**区画を追加** をクリックし、種類・品目などを入力してから、面積の代わりに **割り当て**（そのゾーンで占める割合、%）を入力して **保存** をクリックします。
このステップは施設を保存した後にだけ開きます。

!!! note "終了予定日を過ぎたら区画を終了してください"
    区画は、人が終了するまで「進行中」のまま残ります。終わった区画をそのままにしておくと、その区画のステージ目標を
    使う環境制御が、古い目標に従い続けることがあります。

## 確認 { #check }

地図画面で**サイトの中にゾーンが、ゾーンの中に区画が**表示され、施設をクリックすると施設の情報が開けば完了です。

- 地図デザインとダッシュボードの地図ウィジェットの両方に、オンにした地図の背景が表示されることを確認します。
- 地図の下の **設計情報** カードに、描いた数だけのサイト数・ゾーン数が表示されることを確認します。
- 名前が「新しいサイト」「新しいゾーン」のように最初の名前のまま残っている図形がないことを確認します。
- ゾーンの面積を合計した値がサイトの面積より大きい場合は、どこかが重なっています。重なりを直してください。

## 現場 A { #site-a }

現場 A は、露地と施設の両方がある約 30,000 ㎡ のサイトです。

| 描くもの | 内容 |
|---|---|
| サイト | 現場 A 全体 |
| ゾーン | 露地 3-1（約 10,000 ㎡）、3-2（約 12,000 ㎡） |
| 施設 | 単棟温室 1 棟（339 ㎡）、ポンプ室、管理棟、倉庫 |
| 区画 | 3-1 に大豆、3-2 に黒豆、温室内にレタス（12 ベッドのうち 3 ベッド） |

センサーも区画もない残りの土地は、ゾーンに分けていません。

## 現場 B { #site-b }

現場 B では、一つの施設が現場のすべてです。

| 描くもの | 内容 |
|---|---|
| サイト | 温室が建つ敷地 |
| ゾーン | なし |
| 施設 | 6 連棟温室 1 棟（1,596 ㎡、換気窓 642 ㎡） |
| 区画 | 温室の半分を使う区画 1 つ |

露地がないためゾーンは描かず、施設画面で棟数・幅・長さを正確に入力することに時間をかけます。
環境制御は、これらの寸法から窓の面積と温室の容積を計算します。

## うまくいかないとき { #trouble }

| 症状 | 確認すること |
|---|---|
| 地図に国境しか表示されない | MapTiler Vector の入力がないか、追加しただけで **有効化** していません（[手順 2](#step-2)） |
| 地図の背景が灰色または空白になる | MapTiler のキーが間違っているか、キーの許可アドレスに今使っているアドレスが入っていないか、今月の使用量が上限を超えています（[手順 1](#step-1)） |
| 描いた図形が再読み込みすると消える | 線が交差している図形です。描き直してください |
| 施設をクリックしても開かない | 地図画面で線で描いた施設です。削除して、施設画面で作り直してください |
| 施設の区画ステップが空になっている | 先に施設を保存してください |
| サイト一覧や施設のサイト選択に「新しいサイト」が複数表示される | サイトの名前を変更していません。ラベルをダブルクリックして変更します（[手順 6](#step-6)） |
| ポリゴンが終わらない | 最初の点をもう一度クリックしても閉じません。マウスの右ボタン（またはダブルクリック、Esc）で終えます |
| 住所からの取り込みができない | VWorld の入力が登録・有効化されていて、キーが正しいかを確認します |

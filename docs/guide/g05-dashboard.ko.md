# 대시보드

대시보드는 자동차 계기판과 비슷합니다. 속도와 연료, 경고등처럼 운전에 필요한 것을 한 화면에 모아 두듯이, 봐야 할 값과 누를 조작을 한 화면에 모아 둡니다. AoT 에서 가장 많이 쓰는 화면이고, 무엇을 놓을지는 정해져 있지 않아 사용자가 원하는 대로 구성합니다.
이 장에서는 지난 장에서 받은 첫 번째 데이터를 대시보드에 올립니다. 현장 A 의 대시보드에 먼저 그래프를 놓습니다. 숫자만 보면 오르는지 내리는지 알기 어렵지만, 그래프로 보면 흐름이 한눈에 들어옵니다. 게이지는 지금 값이 정상 범위 안에 있는지 색과 바늘 위치로 바로 보여 주고, 지도 위젯을 더하면 값이 현장 어디에서 오는지까지 한 화면에서 볼 수 있습니다. 타이머와 함수 상태까지 놓으면 지금 무엇이 돌고 있는지도 이 화면에서 다 보이는, 내 현장에 맞춘 대시보드가 됩니다.
만드는 순서는 탭을 만들고, 위젯을 놓고, 자리를 잡은 뒤, 마지막으로 잠그는 것입니다. 뒤 장마다 만든 것(지도, 시설, 출력, 함수, 시퀀스, 승인 요청)도 이 대시보드에 위젯으로 하나씩 놓입니다.

## 이 장을 마치면 { #goal }

- 탭을 만들고 이름·그룹·잠금을 설정한다
- 위젯을 놓고, 옮기고, 크기를 바꾼다
- 휴대폰에서 어떻게 보이는지 안다

## 준비 { #prepare }

- 첫 번째 데이터가 들어오는 AoT([첫 번째 데이터](g04-first-value.md))
- 대시보드를 편집할 수 있는 계정(관리자 또는 편집자)

## 절차 { #steps }

### 1. 탭 만들기 { #step-1 }

처음에는 탭이 하나만 있습니다. 현장 A 는 탭 하나로 충분합니다. 지도 위젯이 대부분의 기능을 담고 있어서, 탭을 너무 많이 만들면 오히려 불편해질 수 있습니다.

탭은 현장별로 나눠도 됩니다. 대시보드 화면 위쪽 탭 줄의 **+** 를 누르면 탭이 하나 더 생깁니다(이름은 "대시보드 {번호}"). 여기서는 현장 B 를 위한 탭을 하나 더 만듭니다. 탭은 끌어서 순서를 바꿀 수 있으니, 자주 보는 탭을 앞쪽에 두세요.

### 2. 탭 설정 { #step-2 }

탭의 톱니바퀴를 눌러 **대시보드 설정**을 엽니다. 첫 탭의 이름을 "현장 A" 로 바꿉니다.

- **이름**: 다른 탭과 겹칠 수 없습니다. 무엇을 보는 탭인지 알 수 있는 이름을 붙이세요.
- **그룹 선택**: 그 탭을 조작할 수 있는 사용자 묶음입니다. 정하면 그 탭에 배치된 위젯은 그 그룹의 사용자만 조작하고, 정하지 않으면 누구나 조작합니다. 그룹은 설정에서 만듭니다. 현장 A 는 현장이 하나라서 그룹을 쓰지 않으니 그대로 둡니다.
- **잠금**: 위젯을 다 놓은 뒤에 씁니다([5단계](#step-5)).

### 3. 위젯 추가하기 { #step-3 }

1. 설정 창 아래쪽에 **잠금 해제** 버튼이 보이면 탭이 잠긴 것이므로 눌러서 풉니다. 잠겨 있으면 위젯을 추가·이동할 수 없습니다.
2. **위젯 추가** 목록에서 위젯을 고르면 설정 칸이 펼쳐집니다.
3. **이름**에는 위젯 종류 이름이 들어 있습니다. 같은 종류를 여러 개 놓을 때 무엇을 보여 주는지 알 수 있게 바꾸세요.
4. **사용자 옵션**의 칸을 채우고 맨 아래 **위젯 추가**를 누릅니다.

그 종류의 위젯을 **처음** 추가할 때는 "10초 동안 기다려주세요" 화면이 나오고 웹 화면이 한 번 다시 시작됩니다. 고장이 아니니 잠시 기다리세요. 10초가 지나도 화면이 나타나지 않으면 새로고침하면 됩니다.

### 4. 날씨 값을 그래프로 { #step-4 }

**그래프** 위젯을 추가하고, 보여 줄 값을 고릅니다. 데이터 소스에서 지난 장에서 만든 바깥 날씨 입력의 값을 고르세요. 위젯을 추가하면 대시보드에 그래프가 놓입니다. 그래프는 처음 추가하는 종류이므로 위 10초 기다림 화면이 나올 수 있습니다.

### 5. 자리 잡기와 잠그기 { #step-5 }

위젯은 왼쪽 윗부분(머리)을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기를 바꿉니다. 바꾸는 즉시 저절로 저장되므로 저장 버튼은 없습니다. 위젯 설정도 마찬가지입니다. 마음에 들지 않으면 **되돌리기**를 눌러 설정 창을 열었을 때의 상태로 되돌리세요.

배치를 마쳤으면 대시보드 설정에서 **잠금**을 눌러 잠급니다. 잠근 탭에서는 위젯을 더하거나 옮길 수 없습니다. 잠금은 권한 설정이 아니라 실수로 옮기지 않게 막는 장치입니다. 편집 권한이 있는 사람은 누구나 풀 수 있습니다.

### 6. 휴대폰에서 보기 { #step-6 }

현장 A 의 대시보드를 휴대폰으로 열면 위젯이 화면 폭에 맞춰 다시 쌓입니다. 컴퓨터의 배치를 그대로 옮기는 것이 아니라 폭에 맞게 다시 정렬하는 것이고, 휴대폰에서 위젯을 옮겨도 컴퓨터 화면의 배치는 바뀌지 않습니다. 지도·시퀀스·타이머·구획·시설 위젯은 휴대폰에서 화면 폭을 가득 채우고, 다른 위젯도 설정의 **모바일에서 전체 폭**으로 바꿀 수 있습니다.

### 7. 자주 쓰는 위젯, 앞으로 놓을 위젯 { #step-7 }

앞으로 장마다 만든 것을 현장 A 의 탭에 위젯으로 놓아 갑니다. 지도와 시설(6·7장), 출력과 타이머(8장), 함수와 시퀀스(9·10장)를 거쳐, AI 의 요청을 승인하는 곳(14장)까지 이어집니다. 새로 만든 현장 B 탭은 7장부터 채워 갑니다.

| 위젯 | 보여 주는 것과 할 수 있는 일 | 꼭 고를 것 |
|---|---|---|
| AoT 그래프 | 여러 값의 시간 변화. 확대하거나 기간 버튼으로 지난 값을 확인합니다 | **데이터 소스**, 표시 기간 |
| AoT 원형 게이지, 게이지(솔리드) | 값 하나를 바늘·막대와 색 구간으로. 지금 값이 정상 범위 안인지 바로 알 수 있습니다 | **측정값**, 최소값·최대값, 색 구간 |
| AoT 지도 | 현장 지도와 그 위의 값·출력([지도](g06-map.md)) | **지도 선택** |
| 함수 상태 | 함수 하나의 현재 상태(9장) | **함수** |
| AoT 타이머 | 출력 하나를 켜고 끄거나, 작동·휴식을 정한 횟수만큼 반복합니다([출력](g08-output.md)) | **출력** |
| 시퀀스 컨트롤러 | 순차 관수 전체를 켜고 끄고, 요일과 시간대를 정합니다(10장) | **시퀀스 함수** |
| MCP 승인 요청 | AI 가 올린 조작 요청을 승인·거절합니다(14장) | 없음 |

위젯마다 설정이 다양하니, 매뉴얼의 위젯 목록을 참고해서 내 현장에 맞게 사용하세요.

## 확인 { #check }

- 대시보드에 날씨 값 그래프가 놓여 있다
- 탭을 잠갔다 풀 수 있다
- 휴대폰으로 열어 봐도 읽을 수 있다

## 현장 A { #site-a }

현장 A 는 탭 하나(이름 "현장 A")로 충분합니다. 이 탭에 바깥 날씨 그래프를 놓고, 뒤 장에서 지도 위젯 등을 하나씩 더합니다. 그룹은 쓰지 않습니다.

## 현장 B { #site-b }

현장 B 를 위한 탭을 하나 더 만들어 둡니다(이름 "현장 B"). 이 탭은 시설을 다루는 [시설](g07-facility.md) 장부터 채웁니다.

## 안 될 때 { #trouble }

| 증상 | 확인할 것 |
|---|---|
| 위젯을 더하는 버튼이 안 보이거나 눌러도 안 된다 | 탭이 잠겨 있지는 않은지, 편집 권한이 있는 계정인지, 다른 그룹의 탭은 아닌지 살펴보세요 |
| 어떤 사람만 탭을 조작하지 못하거나 탭이 보이지 않는다 | 탭에 그룹이 지정되어 있습니다 |
| 그래프가 비어 있다 | 데이터 소스에서 고른 입력이 켜져 있고 값이 들어오는지 살펴보세요 |
| 화면이 느리다 | 한 탭의 그래프 수를 줄이세요 |

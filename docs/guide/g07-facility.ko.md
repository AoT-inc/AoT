# 시설

온실 같은 건물은 지도에 선으로 그려서 만들지 않고, 시설 화면에서 크기와 구조를 정해 만듭니다. 시설은 건물의 모양과 그 안의 센서·창·커튼 자리를 담는 곳이고, 뒤 장의 통합 환경 제어가 이것을 읽고 움직입니다. 이 장에서는 현장 A 의 온실을 세우고, 시설이 중심인 현장 B 의 온실도 함께 살펴보겠습니다.

## 이 장을 마치면 { #goal }

- 시설을 지도에 그리는 것이 아니라 시설 화면에서 만든다는 것을 안다
- 기본 정보·위치·구조·외피를 정하고 온실을 지도 위에 세운다
- 센서를 시설에 연결하고, 창과 커튼이 놓일 자리를 만든다
- 시설을 대시보드에 놓는다

## 준비 { #prepare }

- 지도가 있는 시스템([지도](g06-map.md))
- 시설에 연결할 센서 입력([첫 번째 데이터](g04-first-value.md)와 같은 방법으로 추가합니다)
- 시설을 편집할 수 있는 계정(관리자 또는 편집자)

## 절차 { #steps }

### 1. 시설은 시설 화면에서 만든다 { #step-1 }

선으로 그린 도형에는 크기와 구조가 없어서 시설이 되지 않습니다. 지도의 시설 모드에서 선으로 그린 도형은 일반 도형으로 남을 뿐입니다. 시설은 **설정 → 시설** 화면에서 크기와 구조를 정해 만드세요. 이 화면은 위쪽 단계 표시줄의 일곱 단계(**기본 정보 · 위치·구조 · 외피 · 설비 배치 · 연결 · 구획 · 검토**)로 채웁니다. 먼저 기본 정보와 위치·구조로 몸체를 정하고, 외피에서 창과 커튼을 정한 뒤, 설비 배치에서 센서와 장치가 놓일 자리를 만듭니다. 연결·구획·검토는 마무리 단계입니다. 단계를 누르면 오른쪽에 그 단계의 설정 서랍이 열립니다. 자동 저장은 없으니 **시설 저장**을 눌러야 저장됩니다.

### 2. 기본 정보 { #step-2 }

시설을 열면 빈 새 시설로 시작하고 **기본 정보** 서랍이 열려 있습니다. 이름부터 붙이세요. 현장 A 의 온실은 동 하나짜리 단동 온실이니, **프리셋**에서 **표준 아치형**을 고른 뒤 **경간**(동 하나의 폭)·**처마 높이**·**용마루 높이**·**길이**·**지붕 유형**을 온실에 맞게 정합니다. 이 치수가 나중에 냉난방과 환기 용량을 가늠하는 바탕이 됩니다.

### 3. 위치·구조 { #step-3 }

**위치·구조** 서랍에서 [6장](g06-map.md)에서 만든 지도를 고르고 **지도에 배치**를 누른 다음, 지도에서 온실이 설 자리를 누릅니다. 현장 A 는 대지 안쪽을 누릅니다. 눌러야 위치가 정해지고, **지도에 배치**를 하지 않으면 시설이 저장되지 않으니 꼭 하세요. 방향이 다르면 **회전**으로 맞춥니다.

**구조**는 단동과 연동 가운데 고릅니다.

| 구조 | 뜻 |
|---|---|
| 단동 | 동마다 독립된 건물입니다. 현장 A 의 온실이 이렇고, 동이 여럿이면 **간격**을 두고 섭니다 |
| 연동 | 여러 동이 측벽을 나눠 쓰며 한 건물을 이룹니다. 현장 B 는 구조를 연동으로 하고 **동 수**를 6으로 정합니다 |

동이 둘 이상이면 동 사이 경계를 눌러 **구역**을 나눌 수 있습니다. 지도 위젯과 구역별 환경 제어가 이 구역을 씁니다.

### 4. 외피 { #step-4 }

**외피**에서는 바깥을 두르는 **피복 레이어**(비닐·PO 필름·폴리카보네이트·유리 등)를 고릅니다. 창과 커튼은 켜는 스위치가 따로 있습니다. **외부 측면 환기**(측창)·**외부 천창 환기**(천창)·**보온 커튼**·**차광 커튼**을 켜세요. 현장 A 는 측창만 켜고, 현장 B 는 측창과 천창, 보온 커튼까지 켭니다. 여기서 켠 창과 커튼은 다음 단계의 구성요소 표에 행으로 나타나, 움직일 장치를 붙이는 자리가 됩니다. 피복 자재별 열 손실과 광투과율은 매뉴얼에 있습니다.

### 5. 설비 배치 { #step-5 }

**설비 배치**에서는 시설 안에 놓인 것을 등록합니다. 3D 화면 왼쪽 도구로 놓거나, **구성요소 추가**에서 종류를 고르고 **+ 추가**를 누릅니다.

- **센서 행**: **— 채널 선택 —**에서 입력의 측정 채널을 고르고, 측정 항목과 **실내**·**실외**를 정합니다. 현장 B 는 온실 안 온습도계를 실내로 정합니다. 시설의 실내 값과 바깥 조건은 이렇게 연결한 센서에서 옵니다. 즉 실내 센서는 시설의 실내 값이 되고, 실외 센서는 바깥 조건이 됩니다.
- **창·커튼 행**: 움직일 장치를 고르는 **액추에이터** 칸이 있습니다. 장치는 [출력](g08-output.md)에서 만드니 그때 채웁니다.

여기까지 됐으면 **시설 저장**을 누르세요. 자동으로 저장되지 않습니다. 저장하면 온실이 지도 위에 3D 로 섭니다. 평면 도형이 아니라 실제 크기를 가진 건물입니다.

### 6. 연결·구획·검토 { #step-6 }

나머지 세 단계는 큰 줄기만 짚습니다.

- **연결**: 날씨 예보 입력, 같은 종류 액추에이터를 묶는 그룹, 측정 값의 색 구간을 정합니다.
- **구획**: 시설 안의 구역마다 무엇이 있는지 적어 둡니다.
- **검토**: **수용량 미리보기**에 바닥 면적·부피·난방·냉방·환기 횟수가 참고치로 나옵니다. 현장 B 의 면적도 여기서 AoT 가 계산해 보여 줍니다. 기계설비를 견적하기 전에 가늠하는 값이니 정확한 설계 값으로 쓰지 마세요. **장치 점검**은 연결한 장치를 짧게 켰다 끄며 센서가 반응하는지 확인하는 기능으로, 시설을 저장한 뒤에만 쓸 수 있습니다. 장치를 연결하는 [출력](g08-output.md) 장 뒤에 써 보세요.

각 단계의 세부 옵션은 매뉴얼을 참고해서 내 현장에 맞게 사용하세요.

### 7. 대시보드에 놓기 { #step-7 }

[5장](g05-dashboard.md)에서 만들어 둔 현장 B 탭에서 **위젯 추가 → AoT 시설**을 고르면, 대시보드에서도 저장한 시설을 같은 모습으로 볼 수 있습니다. 설정의 **IEC 함수** 칸은 9장에서 만드는 통합 환경 제어를 고르는 곳이니, 지금은 비워 두세요. 비워 두면 가장 최근에 수정한 시설이 나옵니다. 3D 로 나온 시설은 오른쪽 버튼으로 돌리고, 왼쪽 버튼으로 옮기고, 스크롤로 확대합니다. 돌려 보면 시설 안에 놓인 센서와 설비까지 확인할 수 있습니다.

## 확인 { #check }

- 온실이 지도 위에 3D 로 서 있다
- 시설 화면의 검토에서 수용량 미리보기가 나온다
- 대시보드에서 시설을 볼 수 있다

지금까지 온실 모형을 세우고, 센서를 연결했습니다. 다음 장([출력](g08-output.md))에서는 이 시설의 창과 커튼을 움직이는 출력을 만듭니다.

## 현장 A { #site-a }

현장 A 의 온실은 동 하나짜리 단동 온실입니다. 필요할 때 사람이 조작하는 온실이고, 원격으로 조작하는 것은 측창뿐이라(구형 개폐기에 릴레이를 연결), 모형과 창 자리까지만 세워 둡니다. 표준 아치형 프리셋으로 시작하고, 온실은 [6장](g06-map.md)에서 그린 대지 안쪽에 배치합니다. 외피에서는 측창만 켭니다.

## 현장 B { #site-b }

현장 B 는 여섯 동을 이은 연동 온실입니다. 벽과 지붕의 크기와 방향에 따라 받는 햇빛과 바람이 달라지므로, 이 모양이 나중에 자동 제어의 바탕이 됩니다. 안에는 측창과 커튼이 있고, 열고 닫는 곳이 어디에 있는지가 뒤에서 온도와 습도를 자동으로 조절하는 열쇠가 됩니다. 구조를 **연동**, 동 수를 6으로 정하고 측창과 천창, 보온 커튼을 켭니다. 면적은 검토의 수용량 미리보기에서 AoT 가 계산한 값을 씁니다. 온실 안 온습도계는 실내 센서로 연결합니다. 이 시설은 통합 환경 제어가 읽고 움직이는 대상이라, 뒤 장으로 갈수록 현장 B 의 설정이 늘어납니다.

## 안 될 때 { #trouble }

시설이 저장되지 않거나 값이 이상하면, 다음 세 가지를 먼저 살펴보세요.

| 증상 | 확인할 것 |
|---|---|
| 시설이 저장되지 않는다 | 위치·구조에서 **지도에 배치**를 했는지 확인하세요 |
| 지도에 그렸는데 시설이 아니다 | 지도에서 선으로 그린 도형은 시설이 아닙니다. 시설 화면에서 만드세요 |
| 센서 값이 안 나온다 | 센서 행의 측정 항목과 실내·실외를 맞게 골랐는지 확인하세요 |
| 장치 점검을 못 한다 | 시설을 저장했는지 확인하세요 |

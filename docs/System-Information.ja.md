ページ\: `[歯車アイコン] -> System Information`

このページは、AoTのフロントエンドとバックエンド、およびそれを動かしているLinuxシステムについての情報を提供します。ユーザーがシステムがどのように動作しているかを把握できるよう、いくつかのコマンドとその出力が一覧表示されています。

<table>
<thead>
<tr class="header">
<th>Command</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td>AoT Version</td>
<td>設定ファイルに記録されている、現在のAoTのバージョンです。</td>
</tr>
<tr>
<td>Python Version</td>
<td>Webユーザーインターフェースを現在動かしているPythonのバージョンです。</td>
</tr>
<tr>
<td>Database Version</td>
<td>現在の設定データベースのバージョンです。現在のバージョンが本来あるべきバージョンと異なる場合、その問題を示すエラーと、詳しい情報を確認できるリンクが表示されます。</td>
</tr>
<tr>
<td>Daemon Status</td>
<td>緑色の &quot;Running&quot; または赤色の &quot;Stopped&quot; のいずれかで表示されます。さらに、画面左上のAoTバージョンとホスト名のテキストも、状態を示すために緑・黄・赤のいずれかで表示されることがあります。緑 = デーモンが実行中、黄 = 接続できない、赤 = デーモンが実行されていない、という意味です。</td>
</tr>
<tr>
<td>...</td>
<td>システムの健全性についての情報を提供するため、他にもいくつかの状態インジケーターやコマンドが一覧表示されています。ソフトウェアやハードウェアの問題を調査する際は、これらも他の情報と合わせて活用してください。</td>
</tr>
</tbody>
</table>

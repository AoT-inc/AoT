ページ\: `管理 → システム情報`

このページは、AoTのフロントエンドとバックエンド、およびそれを動かしているLinuxシステムについての情報を提供します。ユーザーがシステムがどのように動作しているかを把握できるよう、いくつかのコマンドとその出力が一覧表示されています。

<td>設定ファイルに記録されている、現在のAoTのバージョンです。</td>
</tr>
<tr>
<td>Pythonバージョン</td>
<td>Webユーザーインターフェースを現在動かしているPythonのバージョンです。</td>
</tr>

<td>データベースバージョン</td>
<td>現在の設定データベースのバージョンです。現在のバージョンが本来あるべきバージョンと異なる場合、その問題を示すエラーと、詳しい情報を確認できるリンクが表示されます。</td>
</tr>
<tr>
<td>Daemon Status</td>
<td>&quot;実行中&quot;と表示され、停止しているときは赤色の&quot;停止中&quot;とヘルプへのリンクが表示されます。ナビゲーションバーも、左上のブランド(ロゴ)領域に色を付けて同じ状態を知らせます。色なし = デーモンとWebアプリが正常、赤 = デーモンが停止、グレー = ブラウザがWebアプリに届いていない状態です。60秒ごとに確認します。</td>
</tr>

AoT는 [라즈베리 파이](https://en.wikipedia.org/wiki/Raspberry_Pi)와 같은 단일 보드 컴퓨터를 위한 오픈 소스 환경 모니터링·제어 시스템입니다. Docker에서도 동작하므로 다양한 하드웨어에 배포할 수 있습니다.

## Mycodo에서 GIS 디지털 트윈으로

AoT는 오픈 소스 [Mycodo](https://github.com/kizniche/Mycodo) 프로젝트를 기반으로 개발을 시작했습니다. Mycodo는 센서 **입력(Input)**과 장치 **출력(Output)**을 결합해 환경을 감지하고 제어하며, 인터페이스는 텍스트 수치와 그래프 위주입니다.

AoT는 대규모·다지점 운영을 더 쉽게 이해하고 다루기 위해, 이를 **GIS 기반 디지털 트윈**으로 개편했습니다 — 모든 장치·센서·구조물이 지도 위 실제 위치를 갖는 지도·시설 중심 인터페이스입니다. 이 토대 위에 GIS·AI·개편된 UI를 더했으며, 그 아래에는 Mycodo의 검증된 제어 모델을 그대로 유지합니다.

## 핵심 모델: 입력·출력·함수

AoT의 모든 것은 세 가지 컨트롤러 유형 위에 구성됩니다:

- **입력(Input)** — 측정값을 수집해 InfluxDB 시계열 데이터베이스에 저장합니다. 측정값은 보통 센서에서 오지만, 리눅스 Bash·Python 명령의 반환값이나 수식일 수도 있습니다.
- **출력(Output)** — 변화를 만들어냅니다: GPIO 핀 스위칭(HIGH/LOW), PWM 신호 생성, 펌프 구동, MQTT 발행, 명령 실행 등.
- **함수(Function)** — 입력과 출력을 결합해 상위 동작을 만듭니다: PID 피드백 루프, 시퀀스, 타이머, 조건부, 그리고 시간에 따라 변하는 설정값(메서드).

## 추가된 기능

AoT가 그 위에 더한 기능들을, 각각 입력·출력·함수와 어떻게 연동되는지 기준으로 설명합니다.

### GIS — 지도·시설·정보

- **입력(Input)** — GIS 데이터 소스 입력(날씨, 위성, 토양 레이어)을 등록하고, 센서 입력을 지도에 배치해 시설·구역에 연결하여 공간 기반으로 모니터링합니다.
- **출력(Output)** — 출력 장치(밸브, 릴레이, 커튼, 환기창)를 지도에 배치하고 지도·시설 화면에서 직접 조작합니다.
- **함수(Function)** — 시설 단위 환경 제어가 GIS 형상(개구부 면적, 방위각, 풍향)을 활용해 여러 액추에이터를 하나의 피드백 루프로 조율합니다(예: 풍향에 따른 차등 환기).

### AI

- **입력(Input)** — AI가 입력 측정값을 관찰하고 센서 이상을 진단하며, 요청 시 입력을 생성·편집할 수 있습니다.
- **출력(Output)** — AI가 출력을 조작할 수 있지만, 모든 쓰기 동작은 적용 전에 사용자 승인이 필요합니다.
- **함수(Function)** — AI가 함수를 생성·편집하고, 설정값을 조정하며, 실제 시설 데이터에 근거한 환경 제어 조언을 제공합니다.

### UI — 탭 시스템·사용자 색상·스타일

- **탭 시스템** — 입력·출력·함수 페이지와 대시보드가 탭으로 구성되어, 장치 목록이 많거나 화면이 여러 개여도 관리하기 쉽습니다.
- **사용자 색상·스타일** — 브랜드 색상, 차트 팔레트, 라이트/다크 테마를 사용자가 설정할 수 있으며 위젯과 페이지 전반에 일관되게 적용됩니다.

## 라즈베리 파이와 Docker에서 작동

AoT는 라즈베리 파이 OS나 Debian에 네이티브로 설치하거나, 다른 플랫폼에서는 **Docker**로 실행할 수 있습니다 — 하드웨어에 맞는 방식을 고르면 동일한 애플리케이션이 동작합니다.

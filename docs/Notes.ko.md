# Notes & Device Notes

AoT는 장치, 센서, 컨트롤러 및 일반 시스템과 관련된 노트를 관리하는 통합 시스템을 제공합니다. 여기에는 GPS 위치, 스마트 제목, 첨부파일, 태그 지원이 포함됩니다.

## 1. 주요 기능

주요 기능으로는 GPS 연동(위치에 연결된 노트), 스마트 제목(첫 줄 자동 추출), 멀티미디어 첨부(이미지 및 파일), 태그 시스템(분류 및 지도 표시 여부 제어)이 있습니다.

## 2. 사용 안내

사용자는 사용자 지정 타임스탬프로 노트를 만들고, 파일을 첨부하고, 태그를 지정할 수 있습니다. Notes Widget을 사용하면 대시보드의 어느 페이지에서든 빠르게 접근할 수 있습니다.

## 3. 개발자 안내 (API)

개발자는 CustomEvent를 통해 노트 인터페이스를 트리거하거나, REST API를 사용해 노트와 태그를 생성, 조회하고 표시 여부를 전환할 수 있습니다.

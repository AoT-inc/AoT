페이지\: `추가 기능 -> 가져오기 내보내기`

선택한 날짜/시간 범위 내에 있는 측정값은 해당 타임스탬프와 함께 CSV로 내보낼 수 있습니다.

또한, 전체 측정 데이터베이스(influxdb)를 ZIP 아카이브 백업으로 내보낼 수 있습니다. 이 ZIP에는 `influxd backup -portable`(InfluxDB 1.x) 또는 `influx backup`(InfluxDB 2.x)으로 만든 InfluxDB 백업 파일이 들어 있습니다. AoT에는 이 ZIP을 가져오는 화면이 없습니다. 측정값을 복원하려면 InfluxDB 문서에 안내된 InfluxDB 자체 복원 도구를 사용하세요.

!!! 참고
    측정값은 특정 시스템의 입력/출력 등과 연결된 특정 ID와 연관되어 있습니다. 측정값을 복원하면서 관련된 입력/출력 등을 가져오지 않으면 이러한 측정값을 볼 수 없습니다(예: 대시보드 그래프에서). 따라서 나중에 복원할 때 측정값과 연결된 장치가 대상 시스템에서 사용 가능하도록 측정값과 설정을 동시에 내보내는 것이 좋습니다.

AoT 설정은 **설정 내보내기**로 AoT 설정 데이터베이스(sqlite)와 사용자 정의 입력, 출력, 함수, 위젯, 업로드한 파일을 포함하는 ZIP 파일로 내보낼 수 있습니다. 이 ZIP 파일은 가져오는 시스템의 AoT 버전이 같거나 더 새로우면 **설정 가져오기**로 다른 AoT 설치에 복원할 수 있습니다. 가져오기는 파일 이름(`AoT_<AoT 버전>_Settings_<데이터베이스 버전>_<호스트>_<날짜>_<시각>.zip`)에서 AoT 버전을 읽으므로 내보낸 이름을 그대로 두세요. 지금 실행 중인 버전보다 새로운 AoT 버전의 파일은 거부됩니다. 가져온 데이터베이스는 이어서 현재 버전으로 업그레이드됩니다. 예를 들어, AoT 8.5.0에서 설정을 내보내면 AoT 8.8.0이나 9.0.0에는 가져올 수 있지만, AoT 8.2.0(더 오래된 버전)에는 가져올 수 없습니다.

!!! 경고
    가져오기는 현재 설정 및 사용자 정의 컨트롤러 데이터를 덮어씁니다(즉, 삭제합니다). 가져오기를 시도하기 전에 AoT 백업을 만드는 것이 권장됩니다.

!!! 참고
    설정 내보내기와 가져오기는 **관리자만** 할 수 있습니다(웹 화면과 API 모두). 설정 데이터베이스에는 사용자 계정·역할·비밀번호 해시가 들어 있어서, 관리자가 아닌 사람이 내려받거나 가져오면 계정 정보가 새거나 스스로 권한을 바꿀 수 있기 때문입니다. 다른 역할에게는 설정 내보내기·가져오기 칸이 보이지 않습니다. 측정값 내보내기는 그대로 쓸 수 있습니다.

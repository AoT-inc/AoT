# GIS 및 지도 시스템 (GIS & Map System)

최종 업데이트: 2026-02-02
AoT 버전: 26.0.1

AoT 시스템은 Leaflet 기반의 인터랙티브 지도를 통해 자산의 위치를 시각화하고 제어할 수 있는 통합 GIS 환경을 제공합니다. 이 시스템은 관리자 설정 페이지(`setting`, `input`, `design`)를 통해 구성되며, 최종적으로 대시보드의 **AoT_map 위젯**으로 서비스됩니다.

## 1. geo/setting (GIS 설정)

시스템 전역에서 사용되는 공통 GIS 파라미터를 관리합니다. 

- **전역 맵 파라미터**: 초기 지도 중심 좌표(위도/경도), 기본 축척(Zoom Level), 최대 확대 한도(`max_zoom`) 등을 설정합니다.
- **검색 공급자(Search Provider)**: 주소 검색에 사용할 API 공급자(OpenStreetMap, VWorld 등)를 선택합니다. 활성화된 레이어 중 유효한 API 키가 등록된 공급자만 선택 목록에 나타납니다.
- **테마 설정 (Theme Configuration)**: 대지(Site), 구역(Zone), 기기(Device) 등 각 객체의 기본 마커 색상과 오버레이 패널의 투명도 등을 사용자 정의할 수 있습니다.
- **보안 및 키 관리**: 외부 지도 타일 서버 호출에 필요한 API Key를 관리합니다.

## 2. geo/input (GIS 레이어 관리)

지도 위에 중첩(Overlay)하여 표시할 외부 데이터 소스를 정의하고 관리합니다.

- **레이어 등록**: VWorld(배경/항공), OpenStreetMap, 공공 데이터 포털의 WMS/TMS 레이어 등을 시스템에 추가할 수 있습니다.
- **활성화 제어**: 각 레이어의 사용 여부를 개별적으로 토글할 수 있으며, 활성화된 레이어만 디자인 맵 및 위젯 설정에서 선택 가능합니다.
- **개별 옵션**: 특정 레이어에 대한 API 키 오버라이드나 가시성 우선순위를 설정합니다.

## 3. geo/design (지도 디자인 및 편집)

실제 기기를 배치하고 구역을 설정하는 인터랙티브 편집 도구입니다.

- **Design Map 생성**: 특정 목적에 맞는 지도 캔버스를 생성하고 관리합니다.
- **기기-공간 바인딩 (Spatial Join)**: 지도 위에서 기기의 위치를 지정하면, 기기가 속한 구역(Site/Zone)을 자동으로 감지하여 데이터베이스 관계를 생성합니다.
- **영역 그리기 (Shape Editing)**: Leaflet.Draw 도구를 사용하여 대지 경계, 파이프라인, 구역 등을 그리거나 편집합니다.
- **레이아웃 저장**: 맵별로 선택된 베이스 레이어와 오버레이 레이어의 조합을 저장하여 위젯에서 일관된 뷰를 제공합니다.

## 4. AoT_map Widget (지도 위젯)

위의 설정들을 집약하여 일반 사용자가 대시보드에서 접근하는 최종 인터페이스입니다.

### 4.1 생성 및 로직
- 위젯은 `design` 페이지에서 생성된 특정 맵 UUID를 참조하여 초기 뷰를 구성합니다.
- `setting`의 테마와 `input`에서 활성화된 레이어 정보를 실시간으로 결합하여 렌더링합니다.

### 4.2 주요 기능 및 인터랙션
- **상태 업데이트**: 폴링(Polling) 방식을 통해 기기의 실시간 데이터와 작동 상태를 마커에 반영합니다.
- **기기 제어**: 마커 클릭 시 나타나는 팝업에서 출력 장치를 직접 온/오프할 수 있습니다.
- **잠금 상태 유지**: 지도 잠금(Map Lock) 기능이 브라우저 로컬 저장소에 귀속되어 사용자별 뷰 고정을 지원합니다.

### 4.3 위젯 상세 옵션 (AoT_map.py)
위젯 설정 팝업에서 다음 항목을 조정할 수 있습니다:
- **주기(Period)**: 데이터 새로고침 간격 (단위: 초).
- **라벨 제어**: 대지, 구역, 장치 이름의 표시 여부 및 글꼴 크기.
- **도형 스타일**: 기기와 연결된 영역(Shape)의 투명도(`device_shape_opacity`) 조정.
- **표시 기기 필터**: 특정 기기만 선택하여 노출하거나 전체 기기를 표시하도록 설정.

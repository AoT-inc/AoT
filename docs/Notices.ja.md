# 掲示板

ページ: `追加機能 -> お知らせ`

掲示板は、システム管理者や運用担当者がユーザーにお知らせを伝えたり、簡単な投票を実施したりできる掲示板です。マークダウン書式、添付ファイル、投票、上部固定、有効期限に対応しています。

---

## 投稿を作成する { #posts }

`新規投稿` ボタンから投稿を作成します。このボタンは、設定を編集できる権限を持つユーザーにのみ表示されます。

- **カテゴリー**: お知らせを分類します。すでに使われているカテゴリーが入力候補として表示され、一覧の検索ボックスもカテゴリーを対象にします。
- **内容**: マークダウン書式に対応しています。
    - `**太字**` や `*斜体*` などの基本的なマークダウン
    - リンク、YouTubeのアドレス、画像URLは自動的に認識され、リンク・動画・画像として表示されます。
- **添付**: 画像（PNG・JPG・GIF・WEBP・BMP・HEIC）、動画（MP4・MOV・WEBM）、文書（PDF・TXT・CSV・XLS・XLSX・DOC・DOCX）を添付できます。それ以外の形式は添付されません。HEIC画像はJPGとして保存され、縦または横が1920pxを超える画像は縮小されます。
- **上部に固定**: 重要なお知らせをリストの一番上に固定します。固定された投稿には `固定表示` と表示されます。この項目は管理者にのみ表示されます。
- **公開日時**: デフォルトは即時公開（`Publish Immediately`）です。これをオフにして日時を指定すると、予約公開になります。その時刻までは一覧に表示されません。
- **有効期限**: `Set Expiration` をオンにして日付を指定すると、その日付を過ぎたお知らせは自動的にリストから外れます。オフのままにすると期限は設定されません。

日時は、入力欄の下に表示されているタイムゾーンを基準に `YYYY-MM-DD HH:MM:SS` の形式で入力します。タイトルか内容のどちらかは必要で、タイトルを空にすると `Untitled` として保存されます。

投稿後は、投稿者本人（設定を編集できる権限を持ち続けている場合）または管理者が、詳細画面から編集・削除できます。編集画面では、すでにアップロードした添付ファイルを削除することもできます。

## 返信 { #replies }

お知らせの詳細画面では、誰でも短い返信（コメント）を残せます。内容が空の返信は登録されません。各ユーザーは自分が書いた返信を削除でき、管理者はどの返信でも削除できます。

## 投票 { #poll }

お知らせに投票を含めることができます。

1. 投稿作成画面で `投票を追加` を選択します。
2. 質問と選択肢を入力し、必要であれば `選択肢を追加` で項目を増やします。質問があり、選択肢が2つ以上入力されている場合にのみ投票が保存されます。
3. `複数選択を許可` をオンにすると、1人のユーザーが複数の項目を選択できるようになります。`投票を削除` で外すこともできます。

ユーザーはお知らせの詳細画面で選択肢を選び、`投票（Vote）` を押して参加します。選択肢ごとの票数と参加人数はリアルタイムで集計され、もう一度投票するとそのユーザーの以前の選択が置き換わります。編集画面で投票を変更すると、すでに入っている票はすべてリセットされます。

## 確認 { #acknowledge }

すべてのお知らせの詳細画面には `確認（Acknowledge）` ボタンがあり、ユーザーは内容を読んだことを示せます。一度押すとボタンは `確認済み（Acknowledged）` に変わり、それ以上押せなくなります。隣には確認した人数が表示され、同じ件数は一覧の各項目にも表示されます。

## 一覧表示 { #list }

- 固定されたお知らせは常に一番上に表示され、それ以外は新しい順に並びます。
- タイトルの下にある検索ボックスで、タイトル・内容・カテゴリーをまとめて対象に絞り込めます。検索語はアドレスに残るため、再読み込みやブックマークからでも保持されます。
- 各項目には、カテゴリー・作成者・投稿日時と内容の冒頭が表示され、あわせて返信の件数、確認した人数、投票が付いている場合は `投票（Poll）` の表示が並びます。管理者には項目ごとに `固定（Pin）`・`固定解除（Unpin）` ボタンも表示されます。
- 1ページに15件ずつ表示され、それ以上ある場合はリストの下に `前へ（Previous）`・`次へ（Next）` ボタンが表示されます。
- 公開日時がまだ来ていない投稿と、有効期限を過ぎた投稿は一覧に表示されません。
- お知らせが1件も登録されていない場合は `お知らせはまだありません。`、検索に一致するものがない場合は `検索に一致するお知らせはありません。` と表示されます。

## ダッシュボードウィジェット { #widget }

**Notice & Notes Board**（お知らせ・ノート掲示板）ダッシュボードウィジェット（`widget_notice`）は、お知らせのタイトルとノートを、お知らせに続けてノートという順で1つのスクロールするリストとして表示します。それぞれ独立してオン・オフでき、初期状態はお知らせがオン・ノートがオフです。両方オフにすると、その旨の文言が代わりに表示されます。

- **お知らせ側**: 表示する投稿数、ウィジェットの投稿ポップアップから投票や返信を許可するか、複数選択のカテゴリーフィルター（何も選ばない場合はすべてのカテゴリーの投稿が表示されます）。
- **ノート側**: 表示するノート数、並び順（新着順・優先度・カテゴリー）、カテゴリー／タグのテキストフィルター（任意）、対象とするサイト・ゾーン・施設・区画 — **入れ子の空間を含める**をオンにすると、その配下に含まれるものも一緒に取得します。
- **更新間隔（秒）**: 2つのリストを再読み込みする間隔です（既定は60秒）。

お知らせをクリックすると、本文・投票・返信・確認をまとめた投稿全体がポップアップで開き、ノートをクリックすると共有のノートパネルで開きます。書き込み権限を持つユーザーにはウィジェットのタイトル行に `+` ボタンが表示され、ウィジェットから直接投稿の作成・編集・削除もできます。

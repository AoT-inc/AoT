# 掲示板

ページ: `ツール -> お知らせ`

掲示板は、システム管理者や運用担当者がユーザーにお知らせを伝えたり、簡単な投票を実施したりできる掲示板です。マークダウン書式、添付ファイル、投票、上部固定、有効期限に対応しています。

---

## 投稿を作成する { #posts }

`新規投稿` ボタンから投稿を作成します。

- **カテゴリー**: お知らせを分類します。リストをカテゴリーで絞り込めます。
- **内容**: マークダウン書式に対応しています。
    - `**太字**` や `*斜体*` などの基本的なマークダウン
    - リンク、YouTubeのアドレス、画像URLは自動的に認識され、リンク・動画・画像として表示されます。
- **添付**: 文書や画像などのファイルを添付できます。
- **上部に固定**: 重要なお知らせをリストの一番上に固定します。固定された投稿には `固定表示` と表示されます。
- **有効期限**: 設定した日付を過ぎると、そのお知らせは自動的にリストから外れます。空欄にすると期限は設定されません。

## 投票 { #poll }

お知らせに投票を含めることができます。

1. 投稿作成画面で `投票を追加` を選択します。
2. 選択肢を入力し、必要であれば `選択肢を追加` で項目を増やします。
3. `複数選択を許可` をオンにすると、1人のユーザーが複数の項目を選択できるようになります。

ユーザーはお知らせの詳細画面で投票に参加でき、結果はリアルタイムで集計されます。

## 確認 { #acknowledge }

一部のお知らせは、ユーザーに内容を確認したことを示してもらうよう求めることができます。ユーザーが確認すると、ステータスが `確認済み` として記録されます。ログイン時に表示されるセットアップガイドのお知らせも、この仕組みで動作します。

## 一覧表示 { #list }

- 固定されたお知らせは常に一番上に表示され、それ以外は新しい順に並びます。
- カテゴリーで絞り込むことができます。
- お知らせが1件も登録されていない場合は、`お知らせはまだありません。` と表示されます。

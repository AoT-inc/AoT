# 공지 게시판 (Notice Board)

페이지: `도구 -> 공지`

공지 게시판은 시스템 관리자나 운영자가 사용자에게 안내 사항을 전달하고, 간단한 투표를 진행할 수 있는 게시판입니다. 마크다운 서식, 첨부파일, 투표, 상단 고정, 만료일을 지원합니다.

---

## 게시글 작성 { #posts }

`새 공지(New Post)` 버튼으로 글을 작성합니다.

- **카테고리(Category)**: 공지를 분류합니다. 목록에서 카테고리별로 필터링할 수 있습니다.
- **내용(Content)**: 마크다운 서식을 지원합니다.
    - `**굵게**`, `*기울임*` 등 기본 마크다운
    - 링크, 유튜브 주소, 이미지 URL은 자동으로 인식되어 링크·영상·이미지로 표시됩니다.
- **첨부파일(Attachments)**: 문서·이미지 등 파일을 첨부할 수 있습니다.
- **상단 고정(Pin to Top)**: 중요한 공지를 목록 맨 위에 고정합니다. 고정된 글은 `고정됨(Pinned)`으로 표시됩니다.
- **만료일(Expires At)**: 설정한 날짜가 지나면 공지가 목록에서 자동으로 내려갑니다. 비워 두면 만료되지 않습니다.

## 투표 { #poll }

공지에 투표를 함께 넣을 수 있습니다.

1. 글 작성 화면에서 `투표 추가(Add Poll)`를 선택합니다.
2. 선택지를 입력하고, 필요하면 `옵션 추가(Add Option)`로 항목을 늘립니다.
3. `복수 선택 허용(Allow Multiple Choices)`을 켜면 한 사용자가 여러 항목을 선택할 수 있습니다.

사용자는 공지 상세 화면에서 투표에 참여하며, 결과는 실시간으로 집계됩니다.

## 확인 처리 { #acknowledge }

일부 공지는 사용자가 내용을 확인했음을 표시하도록 요청할 수 있습니다. 사용자가 확인하면 `확인함(Acknowledged)` 상태로 기록됩니다. 로그인 시 표시되는 설치 안내 공지도 이 방식으로 동작합니다.

## 목록 보기 { #list }

- 고정된 공지가 항상 상단에 표시되고, 그 아래로 최신순으로 정렬됩니다.
- 카테고리로 필터링할 수 있습니다.
- 등록된 공지가 없으면 `아직 공지가 없습니다(No notices yet.)`가 표시됩니다.

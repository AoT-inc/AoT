# 공지 게시판 (Notice Board)

페이지: `추가 기능 -> 공지`

공지 게시판은 시스템 관리자나 운영자가 사용자에게 안내 사항을 전달하고, 간단한 투표를 진행할 수 있는 게시판입니다. 마크다운 서식, 첨부파일, 투표, 상단 고정, 만료일을 지원합니다.

---

## 게시글 작성 { #posts }

`새 공지(New Post)` 버튼으로 글을 작성합니다. 이 버튼은 설정 편집 권한이 있는 사용자에게만 보입니다.

- **카테고리(Category)**: 공지를 분류합니다. 이미 쓰고 있는 카테고리가 입력 추천으로 뜨고, 목록의 검색창도 카테고리를 함께 훑습니다.
- **내용(Content)**: 마크다운 서식을 지원합니다.
    - `**굵게**`, `*기울임*` 등 기본 마크다운
    - 링크, 유튜브 주소, 이미지 URL은 자동으로 인식되어 링크·영상·이미지로 표시됩니다.
- **첨부파일(Attachments)**: 이미지(PNG·JPG·GIF·WEBP·BMP·HEIC), 영상(MP4·MOV·WEBM), 문서(PDF·TXT·CSV·XLS·XLSX·DOC·DOCX)를 첨부할 수 있습니다. 그 밖의 형식은 첨부되지 않습니다. HEIC 이미지는 JPG로 저장되고, 가로나 세로가 1920px을 넘는 이미지는 줄여서 저장됩니다.
- **상단 고정(Pin to Top)**: 중요한 공지를 목록 맨 위에 고정합니다. 고정된 글은 `고정됨(Pinned)`으로 표시됩니다. 이 항목은 관리자에게만 보입니다.
- **게시 시각(Publish At)**: 기본은 즉시 게시(`Publish Immediately`)이며, 이를 끄고 날짜를 지정하면 예약 게시로 전환됩니다. 그 시각 전까지는 목록에 나타나지 않습니다.
- **만료일(Expires At)**: `만료 설정(Set Expiration)`을 켜고 날짜를 지정하면, 그 날짜가 지난 뒤 공지가 목록에서 자동으로 내려갑니다. 토글을 꺼 두면 만료되지 않습니다.

날짜는 입력칸 아래 표시된 시간대를 기준으로 `YYYY-MM-DD HH:MM:SS` 형식으로 적습니다. 제목과 내용 중 하나는 있어야 하며, 제목을 비워 두면 `제목 없음(Untitled)`으로 저장됩니다.

작성한 뒤에는 글쓴이 본인(설정 편집 권한이 유지되는 동안)이나 관리자가 상세 화면에서 글을 수정·삭제할 수 있습니다. 수정 화면에서는 이미 올린 첨부파일도 지울 수 있습니다.

## 댓글 { #replies }

공지 상세 화면에서 누구나 짧은 댓글(답글)을 남길 수 있습니다. 내용이 비어 있으면 등록되지 않습니다. 각 사용자는 자기가 쓴 댓글을 지울 수 있고, 관리자는 어떤 댓글이든 삭제할 수 있습니다.

## 투표 { #poll }

공지에 투표를 함께 넣을 수 있습니다.

1. 글 작성 화면에서 `투표 추가(Add Poll)`를 선택합니다.
2. 질문과 선택지를 입력하고, 필요하면 `옵션 추가(Add Option)`로 항목을 늘립니다. 질문이 있고 선택지가 두 개 이상 채워져 있어야 투표가 저장됩니다.
3. `복수 선택 허용(Allow Multiple Choices)`을 켜면 한 사용자가 여러 항목을 선택할 수 있습니다. `투표 제거(Remove Poll)`로 다시 뺄 수 있습니다.

사용자는 공지 상세 화면에서 선택지를 고르고 `투표(Vote)`를 눌러 참여합니다. 선택지별 표 수와 참여자 수는 실시간으로 집계되며, 다시 투표하면 그 사용자의 이전 선택을 대체합니다. 수정 화면에서 투표를 바꾸면 이미 들어온 표는 모두 초기화됩니다.

## 확인 처리 { #acknowledge }

모든 공지의 상세 화면에는 `확인(Acknowledge)` 버튼이 있어, 사용자가 내용을 읽었음을 표시할 수 있습니다. 한 번 누르면 버튼이 `확인함(Acknowledged)`으로 바뀌고 다시 누를 수 없으며, 옆에 확인한 사람 수가 표시됩니다. 같은 집계는 목록의 각 항목에도 나타납니다.

## 목록 보기 { #list }

- 고정된 공지가 항상 상단에 표시되고, 그 아래로 최신순으로 정렬됩니다.
- 제목 아래 검색창에서 제목·내용·카테고리를 한 번에 훑어 목록을 좁힐 수 있습니다. 검색어는 주소에 남아 새로고침하거나 즐겨찾기로 열어도 유지됩니다.
- 각 항목에는 카테고리·작성자·작성 시각과 내용 앞부분이 표시되고, 댓글 수, 확인한 사람 수, 투표가 붙어 있으면 `투표(Poll)` 표시가 함께 나옵니다. 관리자에게는 항목마다 `고정(Pin)`·`고정 해제(Unpin)` 버튼도 보입니다.
- 한 쪽에 15건씩 표시되며, 더 있으면 목록 아래에 `이전(Previous)`·`다음(Next)` 버튼이 나타납니다.
- 게시 시각이 아직 오지 않은 글과 만료일이 지난 글은 목록에 나오지 않습니다.
- 등록된 공지가 없으면 `아직 공지가 없습니다(No notices yet.)`가, 검색 결과가 없으면 `검색과 일치하는 공지가 없습니다(No notices match your search.)`가 표시됩니다.

## 대시보드 위젯 { #widget }

**공지·노트 게시판(Notice & Notes Board)** 대시보드 위젯(`widget_notice`)은 공지 제목과 노트를 대시보드에 한 목록으로 이어서 보여줍니다(공지 다음에 노트, 스크롤은 하나). 둘은 각각 독립적으로 켜고 끌 수 있으며, 기본값은 공지 켬·노트 끔이고 둘 다 끄면 그 사실을 알리는 문구가 대신 표시됩니다.

- **공지 쪽**: 표시할 글 개수, 위젯의 글 팝업에서 투표 참여·댓글 작성을 허용할지, 다중 선택 카테고리 필터(아무것도 고르지 않으면 모든 카테고리의 글이 나옵니다).
- **노트 쪽**: 표시할 노트 개수, 정렬 기준(최신순 · 우선순위 · 카테고리), 카테고리/태그 텍스트 필터(선택), 그리고 범위를 좁힐 대상 부지·구역·시설·구획 — **하위 공간 포함(Include Nested Spaces)** 토글을 켜면 그 아래 딸린 것들도 함께 가져옵니다.
- **새로 고침 주기(Refresh (seconds))**: 두 목록을 얼마나 자주 다시 불러올지 정합니다(기본 60초).

공지를 클릭하면 본문·투표·댓글·확인 처리가 포함된 전체 글이 팝업으로 열리고, 노트를 클릭하면 공용 노트 패널에서 열립니다. 쓰기 권한이 있는 사용자에게는 위젯 제목줄에 `+` 버튼이 생기며, 위젯에서 바로 글을 작성·수정·삭제할 수 있습니다.

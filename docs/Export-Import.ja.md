ページ\: `追加機能 -> インポート エクスポート`

選択した日付・時刻の範囲内の測定値は、タイムスタンプとともにCSVとしてエクスポートできます。

さらに、測定値データベース(influxdb)全体を、ZIPアーカイブのバックアップとしてエクスポートすることもできます。このZIPには、`influxd backup -portable`(InfluxDB 1.x)または`influx backup`(InfluxDB 2.x)で作成したInfluxDBのバックアップファイルが入っています。AoTにはこのZIPをインポートする画面はありません。測定値を復元するには、InfluxDBのドキュメントに従ってInfluxDB自体の復元ツールを使ってください。

!!! note
    測定値は、特定のシステムの入力・出力などに関連付けられた特定のIDと結び付いています。関連する入力・出力などをインポートせずに測定値だけを復元すると、(たとえばダッシュボードのグラフなどで)これらの測定値を表示できません。そのため、測定値と設定は同時にエクスポートしておき、後で復元する際に復元先のシステム上で測定値に対応するデバイスが利用できる状態にしておくことをおすすめします。

AoTの設定は、**設定をエクスポート**で、AoT設定データベース(sqlite)に加えて、カスタム入力・出力・機能・ウィジェットとアップロードしたファイルを含むZIPファイルとしてエクスポートできます。このZIPファイルは、インポート先のシステムのAoTバージョンが同じかより新しい場合に、**設定をインポート**で別のAoTインストールへ復元できます。インポートはファイル名(`AoT_<AoTバージョン>_Settings_<データベースバージョン>_<ホスト>_<日付>_<時刻>.zip`)からAoTバージョンを読み取るため、エクスポートしたときの名前のままにしてください。実行中のバージョンより新しいAoTバージョンのファイルは拒否されます。インポートしたデータベースは、その後現在のバージョンにアップグレードされます。たとえば、AoT 8.5.0から設定をエクスポートした場合、AoT 8.8.0や9.0.0にはインポートできますが、AoT 8.2.0(より古いバージョン)にはインポートできません。

!!! warning
    インポートを行うと、現在の設定とカスタムコントローラーのデータが上書き(つまり削除)されます。インポートを実行する前にAoTのバックアップを作成しておくことをおすすめします。

!!! note
    設定のエクスポートとインポートは**管理者のみ**が行えます(Webインターフェース・APIとも)。設定データベースにはユーザーアカウント・ロール・パスワードハッシュが含まれているため、管理者以外がエクスポートするとアカウント情報が漏れ、インポートすると自分の権限を変更できてしまうためです。他のロールには設定のエクスポート・インポート欄が表示されません。測定値のエクスポートはこれまでどおり使えます。

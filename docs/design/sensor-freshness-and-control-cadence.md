# 센서 신선도와 제어 주기 — 오래된 값을 버릴 것인가 쓸 것인가

제어 주기가 센서 주기보다 빠른 것은 **비정상이 아니라 기본 조건**이다. 센서가
값을 내는 시점은 센서(또는 그 공급원)가 정하고 우리는 못 정한다 — 기상청 300초,
OpenWeather 600초, LoRaWAN 노드 40분. 그런데 지금 제어는 "이보다 오래된 값은
안 쓴다" 는 **이진 게이트**를 지나므로, 두 주기가 어긋나는 순간 그 축이 통째로
사라진다.

이 문서는 그 어긋남을 정상 조건으로 받아들이는 설계다. 정본 판정 모듈은
`aot/utils/measurement_freshness.py` 이고 여기서 정하는 규칙은 그 모듈과 그것을
쓰는 다섯 소비처에 적용된다(CLAUDE.md "측정값 신선도" 절 참조).

## 왜 지금 구조가 무너지는가 — 실측

2026-08-28 육묘장3(`env_coordinator`)에서 실제로 일어난 일이다.

| | |
|---|---|
| 실외 센서 | 기상청 · `period` 300초 · `max_age_s` 미설정 |
| 코디네이터 `sensor_max_age` | **120초**(옛 기본값, 사람이 고른 값이 아니다) |
| 결과 | 실외 유효 0/6채널 · 측창 둘이 24시간 내내 `실외 값 없음`(근거 16) |

배선은 6채널 모두 정상이었다. 상한만 만족 불가능했다 — 300초마다 오는 값에
120초 상한을 걸면 **어떤 순간에도** 유효할 수 없다. 그런데 증상은 "센서가 없다"
라서 로그만 보면 배선 문제로 읽힌다.

같은 일이 이미 두 번 있었다: 영양·쿠마모토가 1200 인 것은 누군가 이 문제를 겪고
손으로 고쳤다는 뜻이다.

**1차 조치는 끝났다**(2026-08-28): 기본값을 0(= 센서가 정한다)으로 내리고,
호출부의 숫자 폴백(`or 120.0` · `or 600.0`)을 걷어 `requested=None` 이 규칙에
도달하게 했다. 미지정이면 그 센서의 주기×2 로 판정한다.

**그러나 그것으로 끝이 아니다.** 자동값(주기×2)도 결국 이진 게이트라, 공급원이
한 번 늦으면 그 축이 그 사이클 통째로 사라진다. 실제로 같은 날 기상청 도착이
739초 밀려 자동값 600초로도 만료였다. 아래 세 규칙이 그 다음이다.

---

## 규칙 A — 오래된 값은 **안전한 방향으로만** 쓴다

"버린다 / 쓴다" 이진이 아니라 **어느 쪽 결정에 쓰는가**로 가른다. 게이트마다
위험한 방향이 하나뿐이라 이 규칙은 기계적으로 적용된다.

| 오래된 실외 값 | 닫는 근거로 | 여는 근거로 |
|---|---|---|
| "비 옴" | **쓴다** | — |
| "비 안 옴" | — | **안 쓴다** |
| "바람 셈" | **쓴다** | — |
| "바람 없음" | — | **안 쓴다** |
| 온도·습도·CO₂ | 쓴다 | 쓴다 |

근거: 오래된 값으로 인해 **새로 생기는 위험이 있는 방향만** 막으면 된다. 10분
전 "비 안 옴" 으로 창을 열면 비가 들이치지만, 10분 전 "비 옴" 으로 창을 닫아
두는 것은 최악이 "필요 없는데 닫혀 있음" 이다.

⚠ **`max_age × 2` 를 일률 적용하지 말 것.** 외기 온도는 10분이 지나도 유효하지만
돌풍은 초 단위고 강우는 그 사이에 시작된다. 하나의 배수로 묶으면 온도는 맞고
강우는 틀린다 — 그리고 틀리는 쪽이 물리 피해다.

## 규칙 B — 노화 속도는 변수마다 다르다

규칙 A 가 방향 축이라면 이것은 시간 축이다. 같은 "10분 전 값" 이라도 신뢰도가
다르다.

| 변수 | 관대함 | 근거 |
|---|---|---|
| 외기 온도·습도 | 높음 | 시상수가 시간 단위. 10분에 크게 안 변한다 |
| CO₂(외기) | 높음 | 대기 배경값이라 사실상 상수 |
| 일사 | 중간 | 구름 한 장에 절반이 된다 |
| 풍속 | 낮음 | 돌풍은 초 단위 |
| 강우 | 낮음 | 시작 순간이 곧 위험 |

배수를 **정본에 상수로 박지 말 것.** 자리마다 근거가 다르다는 것이 이미
`measurement_freshness` 의 판단이고(호출부가 `factor` 를 넘긴다), 여기서도
변수별 배수는 호출부 — 즉 안전 게이트와 제어 각각 — 이 정한다.

## 규칙 C — 적분은 **새 정보**에만 쌓는다

센서 주기 600초 · 제어 주기 300초면 두 사이클 중 하나는 **같은 값**을 본다.
지금은 그 사이클에도 `I = clamp(I + ki·e)` 가 그대로 돌아, 장치가 반응했는지
확인하기도 전에 적분이 자란다.

지금 코드는 이 위험을 이미 알고 있다 — 실외 근거가 아예 없을 때는 적분을
얼린다(`coordinator.py` hold 분기: *"모르는 동안 '평형 개도 기억' 을 흔들면
실외가 돌아왔을 때 엉뚱한 자리에서 다시 출발한다"*). **규칙 A 로 오래된 값을
쓰기 시작하면 그 보호가 사라진다.** 값은 있으니 hold 분기에 들어가지 않는데,
정보는 새것이 아니다.

    값은 쓰되 **새 정보로 치지 않는다** — P 항은 계산하고 I 는 쌓지 않는다.

### 구현안 둘 — 어느 쪽도 공짜가 아니다

**안 1: 측정 타임스탬프를 올린다(정확)**

`_read_one_sensor` 는 이미 `get_last_measurement()` 에서 `(ts, val)` 을 받아
**ts 를 버린다**. 그것을 변수별로 올려 이전 사이클과 비교한다.

    _read_one_sensor → read_facility_sensors / read_outdoor_sensors
                     → _collect_internal → internal['_ts']
                     → situation.context → coordinator → CoordinatorState

- 정확하다. 공급원이 늦거나 건너뛴 것까지 그대로 반영한다.
- 대가: 제어 데이터 경로 4개 파일 + 상태 스키마. 여러 센서의 가중평균에서
  "그 변수의 ts" 를 무엇으로 볼지도 정해야 한다(가장 새것이 무난하다).

**안 2: 알려진 주기로 이득을 나눈다(근사)**

제어 주기 C, 그 변수에 기여하는 가장 느린 센서 주기 P 일 때
`ki_eff = ki × min(1, C/P)`. 600초마다 오는 값을 300초 주기로 읽으면 이득이
절반이 되어, 시간당 누적이 C=P 일 때와 같아진다.

- 타임스탬프 배선이 필요 없고 오탐이 없다(P 를 모르면 비율 1 = 현재 동작).
- 대가: 공급원이 **실제로** 늦은 경우를 모른다. 평균적으로만 맞다.

**권고: 안 1.** 안 2 는 "평균적으로 맞다" 인데, 이 도메인에서 값이 늦는 것은
평균적 현상이 아니라 **몰려서** 일어난다(수집 실패 → 연속 결측). 다만 안 2 는
안 1 의 배선 없이 오늘 넣을 수 있으므로, 안 1 이 늦어지면 중간 조치로 쓸 수 있다.

### ⚠ 값 비교로 대신하지 말 것

"이번 값이 지난 값과 같으면 갱신 안 된 것" 은 배선이 없어 매력적이지만 **틀린
신호**다. 0.1℃ 해상도 센서가 안정 상태에서 같은 값을 내는 것은 흔하고, 그때
적분을 얼리면 **정말 필요한 순간에** 제어가 둔해진다. 게다가 그 실패는
조용하다 — 로그에는 "값이 같았다" 밖에 안 남는다.

**1 이 2 보다 앞이다.** 순서를 뒤집으면 오래된 값을 쓰기 시작한 사이클부터
적분이 중복으로 쌓이는데, 그 증상은 과적분·오버슈트라 원인이 신선도 변경이었다는
것을 알아보기 어렵다.

**전부 하루를 살아 봐야 아는 변경이다.** 합성 테스트는 "오래된 값을 안전한
방향으로만 썼는가" 를 확인할 수 있지만, 그 결과 창이 언제 열리고 닫히는지는
못 잡는다. 각 단계 뒤에 `check_env_coordinator_health.py` 로 최소 2박 3일을
관찰한다 — 특히 **진동/h** 와 **난방·냉방 동시 가동**.

## 이 문서가 막으려는 것

- 배수 하나로 모든 변수를 판정하는 것(규칙 B)
- 오래된 값을 여는 근거로 쓰는 것(규칙 A)
- 오래된 값을 쓰면서 적분은 그대로 쌓는 것(규칙 C)
- 호출부에 숫자 폴백을 되살려 자동 경로를 다시 막는 것(단계 0, 회귀 테스트
  `test_measurement_freshness.py::TestUnsetSurvivesTheTripToTheRule` 이 고정)

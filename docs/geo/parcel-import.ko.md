# 필지 가져오기

한국 토지 데이터(VWorld)를 사용해 대지 경계를 지도 위에 빠르게 가져오는 기능입니다. 폴리곤을 직접 그리는 대신, 주소 검색이나 CSV 파일로 정확한 지적 경계를 즉시 생성할 수 있습니다.

---

## 사전 조건 { #prerequisites }

VWorld API 키가 등록되어 있어야 합니다.

1. `/geo/layer` 에서 VWorld 레이어 추가
2. 기어 아이콘 → API Key 입력 → Save
3. Activate

Activate 는 VWorld 지도 타일을 화면에 띄우기 위한 것입니다. 필지 가져오기 자체는 키만 있으면 되며, 활성화된 VWorld 레이어를 먼저 쓰고 활성화된 것이 없으면 등록만 되어 있는(비활성) VWorld 레이어의 키를 대신 씁니다. VWorld 레이어가 아예 없거나 API Key 칸이 비어 있으면, VWorld GIS 입력이 등록되지 않았거나 API Key가 없다는 메시지와 함께 조회가 실패합니다.

## 가져오기 창 열기 { #opening-the-import-dialog }

1. `/geo/design` 으로 이동합니다.
2. 지도 아래 모드 바에서 **대지** 모드로 전환합니다.
3. 대지 설정 드로어에서 **주소로 추가** 옆의 **검색** 버튼을 클릭합니다.

그러면 **주소로 대지 가져오기** 창이 열리는데, 여기에는 **주소 입력**과 **CSV 일괄** 두 탭이 있습니다. 이 창은 지도를 덮는 대신 오른쪽에서 서랍으로 밀려 들어오므로, 찾은 필지의 경계가 지도에 그려지는 것을 보면서 다음 주소를 이어서 넣을 수 있습니다. 서랍은 한 번에 하나만 열리기 때문에 대지 설정 드로어는 닫힙니다. 폰에서는 화면 전체를 덮으며, 위쪽 가장자리의 손잡이로 살짝 내렸다가 다시 올릴 수 있습니다.

서랍은 구획마다 **제목 + 카드**로 나뉘고, 줄마다 하는 짧은 동작(주소 줄의 위치·삭제, 주소 추가, 검색, 닫기)은 글자 없는 **아이콘 알약** 버튼입니다. 이름은 마우스를 올리면 뜨는 툴팁으로, 터치 화면에서는 길게 눌러 봅니다. 업로드·저장처럼 뜻이 글로 필요한 결정은 글자 버튼입니다.

## 주소로 가져오기 (주소 입력) { #address-input }

1. 주소를 입력합니다 (예: `서울특별시 강남구 역삼동 808`). 콤마로 구분해 여러 개를 한 번에 넣거나, **주소 추가**(＋) 버튼으로 입력란을 늘릴 수 있습니다. 주소를 직접 치지 않고 지도에서 골라 채울 수도 있습니다(아래 [위치 시트로 주소 채우기](#pick-location)).
2. **검색**(돋보기) 버튼을 클릭합니다.
3. 찾은 필지가 아래 미리보기 목록에 나타나고 지도 위에도 경계가 그려집니다. 실패한 항목은 사유와 함께 표시됩니다.

### 위치 시트로 주소 채우기 { #pick-location }

주소를 모르거나 치기 번거로우면 주소 줄 오른쪽의 **위치**(핀) 버튼을 누릅니다. 서랍 안에 [위치 시트](design-tool.md#location-sheet)가 펼쳐집니다. 서랍을 닫지 않으므로 입력하던 주소 줄과 미리보기, 진행 상태가 그대로입니다. 시트에서 주소 검색·내 위치·지도 중심·지도에서 직접 찍기·즐겨찾기·최근 중 어느 쪽으로든 자리를 고르고 **이 주소 사용**을 누르면 그 줄에 주소가 채워집니다.

- 같은 줄의 **위치** 버튼을 다시 누르면 시트가 접히고, 다른 줄의 버튼을 누르면 채울 줄만 바뀝니다.
- 채워진 줄은 직접 고칠 수 있고, 검색·Enter 는 그대로입니다. 채워진 주소는 주소 하나로 취급되어 안의 쉼표 때문에 여러 주소로 갈라지지 않습니다.
- 고른 자리의 주소는 서버가 좌표로 역조회해서 구합니다. 몇 초 걸릴 수 있고, 그동안 **이 주소 사용**은 눌리지 않으며 이름이 **주소를 찾는 중…**으로 바뀝니다. 주소를 구하지 못하면 눌리지 않은 채로 남으니, 다른 자리를 고르거나 주소를 직접 입력하세요.
- 위치 시트가 주는 주소가 지번 주소가 아닐 수 있고, 한국 밖 주소는 VWorld 가 풀지 못합니다. 이런 주소로 필지 조회가 실패하면 상태줄에 "필지 조회는 VWorld 가 풀 수 있는 주소만 찾을 수 있습니다. 주소를 고쳐서 다시 시도하세요." 안내가 붙을 뿐 자동으로 바꿔 주지는 않습니다 — 주소를 고쳐 다시 검색하세요.

## CSV 일괄 가져오기 (CSV 일괄)

여러 필지를 한 번에 가져올 때 사용합니다.

### CSV 파일 형식 { #csv-file-format }

**CSV 일괄** 탭 맨 위의 **CSV 형식 안내** 카드에도 같은 내용이 적혀 있습니다.

주소만 한 줄에 하나씩, **첫 번째 열**에 넣습니다. 헤더 행도, 이름 열도 없습니다 — 다른 열이 있어도 무시되며, 가져온 각 대지의 이름은 주소 자체(또는 저장 시 **대지 이름** 필드)에서 옵니다.

```csv
경기도 화성시 송산면 고정리 123
경기도 화성시 송산면 고정리 124
경기도 수원시 권선구 입북동 456
```

파일은 쉼표 구분·UTF-8 로 저장합니다(엑셀은 "CSV UTF-8"). 헤더 행을 건너뛰지 않으므로, 헤더를 넣으면 주소로 조회되어 실패 목록에 나옵니다.

카드는 주소를 어디서 가져왔는지에 따라 두 가지를 안내합니다.

- **VWorld** — 지번 주소를 쓰세요. 필지는 지번으로 찾기 때문에 도로명 주소는 좌표가 도로 위에 떨어지면 실패할 수 있습니다. 한국 주소만 가능합니다.
- **Google Maps** — Google 지도 / 내 지도에서 내보낸 파일의 주소 열을 첫 번째 열로 옮기세요. Google 은 도로명 주소를 주므로 일부 행이 실패할 수 있으니 실패 목록을 확인하세요. 한국 밖 주소는 읽지 못합니다.

### 가져오기 방법 { #how-to-import }

1. **CSV 일괄** 탭에서 **CSV 파일 선택**으로 파일을 고릅니다.
2. **업로드 및 처리** 버튼을 클릭합니다.
3. 결과는 주소 검색과 같은 미리보기 목록에 나타납니다 — 성공한 필지는 ✓, 실패한 주소는 사유와 함께.

## 확인 후 저장 { #reviewing-and-saving }

두 탭 모두 아래 미리보기 영역을 공유합니다.

- **인접 필지 통합** (체크박스, 기본 꺼짐) — 미리보기에서 서로 맞닿은 폴리곤을 turf.js로 하나의 대지로 합쳐서 저장합니다. 꺼두면 미리보기의 각 필지가 각자 별도 대지로 저장됩니다. CSV로 가져온 필지도 이 체크박스를 켜야만 합쳐집니다 — 자동으로 합쳐지지 않습니다.
- **대지 이름** — 첫 결과 이름으로 자동 채워집니다(여러 건이면 "외 N필지"가 붙음). 저장 전 수정할 수 있습니다. 병합하지 않은 여러 필지를 저장할 때는(결과가 정확히 1건이 아닌 한) 이 필드 대신 각 필지가 자신의 이름으로 저장됩니다.
- **대지로 저장** — 미리보기의 모든 필지(또는 병합된 결과 하나)를 저장합니다. 저장하려면 설정 편집 권한이 있어야 하고, 그 지도가 자신의 접근 그룹 안에 있어야 합니다. 둘 중 하나라도 없으면 아무것도 저장되지 않고 모든 필지가 그냥 실패로 집계됩니다. 검색과 미리보기는 로그인한 사람이면 누구나 할 수 있습니다.

저장 후 상태줄에 저장한 건수, **이미 가져옴**(아래 참조) 건수, 실패 건수가 각각 표시됩니다. 저장이나 이미 가져옴이 한 건이라도 있으면 서랍이 닫히고 지도가 다시 불러와져, 각 대지가 가운데 이름 라벨과 함께 표시됩니다.

!!! note "같은 필지를 두 번 가져와도 중복 생성되지 않습니다"
    현재 지도에 같은 기하(geometry)의 대지가 이미 있으면, 다시 저장을 시도해도 오류가 아니라 건너뛰기로 처리되고 "이미 가져옴"으로 따로 집계됩니다.

저장된 필지는 `Site` 타입 GeoShape(대지)이며, 손으로 그린 대지와 동일하게 편집할 수 있습니다.

## API 직접 사용

자동화 스크립트에서 필지 가져오기를 호출하는 경우 REST API를 사용합니다. 위 화면 UI도 결국 아래 세 엔드포인트를 그대로 부르는 얇은 클라이언트입니다.

### 주소로 가져오기 { #import-by-address }

```http
POST /api/geo/parcel/from_address
Content-Type: application/json

{
  "address": "경기도 화성시 송산면 고정리 123"
}
```

응답:
```json
{
  "ok": true,
  "feature": {
    "type": "Feature",
    "geometry": { "type": "Polygon", "coordinates": [[[...], ...]] },
    "properties": { "name": "..." }
  },
  "name": "경기도 화성시 송산면 고정리 123",
  "pnu": "4159025300100230000"
}
```
실패 시: `{"ok": false, "error": "..."}`. 주소나 필지를 찾지 못한 실패 응답에는 `upstream_failed` 도 함께 담깁니다. 보낸 VWorld 호출이 모두 실패했으면(VWorld 서비스 자체의 장애·오류) `true`, VWorld 가 응답했지만 일치하는 결과가 없었으면 `false` 입니다.

### CSV 일괄 가져오기 { #csv-batch-import_1 }

```http
POST /api/geo/parcel/from_csv
Content-Type: multipart/form-data

file=<CSV 파일, 한 줄에 주소 하나, 첫 번째 열만 사용>
```

응답:
```json
{
  "ok": true,
  "features": [ /* 성공한 주소마다 GeoJSON Feature 하나씩 */ ],
  "names": [ "..." ],
  "errors": [ "<주소>: <사유>", "..." ]
}
```

### 대지로 저장 { #save-as-site }

```http
POST /api/geo/parcel/save_as_site
Content-Type: application/json

{
  "feature": { "type": "Feature", "geometry": { "type": "Polygon", "coordinates": [...] }, "properties": {} },
  "name": "1번 온실 대지",
  "map_uuid": "<지도 UUID>"
}
```

`edit_settings` 권한과 대상 지도에 대한 스코프가 필요합니다(없으면 `403`). `map_uuid` 는 실제로 존재하는 지도여야 합니다. 같은 지도에 같은 기하의 대지가 이미 있으면, 새로 만드는 대신 `409` 와 함께 `{"ok": false, "duplicate": true, "shape_id": ..., "existing_name": "..."}` 를 돌려줍니다.

## 참고사항 { #notes }

- VWorld PNU(필지번호) API를 사용하므로 국내 주소만 지원합니다.
- 주소 인식 실패 시 지번 주소와 도로명 주소를 모두 시도해보세요.
- 대규모 CSV 가져오기(100개 이상)는 각 행마다 VWorld 조회가 따로 일어나 처리 시간이 걸릴 수 있습니다.
- 가져온 필지는 일반 대지와 동일하게 편집 가능합니다.

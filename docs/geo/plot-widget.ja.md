# AoT_plot ウィジェット

`AoT_plot` は、今育っているすべての区画の状態をダッシュボードに常駐させるウィジェットです。[地図ウィジェット](map-widget.md#plot)が汎用的で、区画をクリックして見て、そのポップアップを閉じるという使い方であるのに対し、このウィジェットはその正反対の習慣のために作られています — 作期の間ずっと作物を見守るように、区画を継続的に見続けるためのものです。デバイス制御はあえて含んでいません（アクチュエーターの操作は地図ウィジェットや施設ウィジェットの仕事です）。カードをタップするとその区画の状態とスケジュールが開き、戻る矢印で一覧に戻ります。

---

## ウィジェットを追加する

1. ダッシュボードで **Add Widget → AoT Plot** を選択します。
2. **Save** をクリックします — ウィジェットは区画一覧の画面で開きます。

!!! note "固定サイズ"
    このウィジェットは内容に合わせて伸びることはなく、高さが固定されています — デフォルトサイズは幅12×高さ22グリッド単位です。ウィジェット自体をスクロールする代わりに、一覧・タブ・ページの間を移動して見ます。もっと広く見たい場合は、他のウィジェットと同じようにサイズを変更してください。

---

## 区画一覧

今育っている区画だけを1枚ずつカードで並べます — まだ始まっていない（計画中の）区画と、すでに終わった区画は一覧に出ません。各カードには次が表示されます。

- **1行目** — 左側に区画名、右側に進捗率。予定していた終了日を過ぎると100%を超えることがあり、比較する終了日がない場合は「—」と表示されます。
- **2行目** — シンプルなステージトラック: 現在のステージの区間が緑色で塗られます（Stagesタブの全体軸と同じルール）。プログラムのない区画は、代わりに経過分が緑色で塗られます。このトラックに「今日」の印はありません — どのあたりかは1行目の進捗率がすでに示しています。

カードをタップすると、その区画の詳細が開きます。

---

## 区画詳細

ヘッダーは[地図ウィジェット](map-widget.md#plot)の区画モーダルと同じです — 左側の戻る矢印（←）を押すと区画一覧に戻り、その隣に区画名があります。ヘッダーの下には、同じモーダルから引き継いだ3つのタブがあります: **Stages（ステージ）**、**Environment（環境）**、**Notes（ノート）**。

### Stages（ステージ）

保留中のステージ切り替え確認があれば、一番上に表示されます。その下がステージカードです — [地図ウィジェット](map-widget.md#plot)の区画モーダルが描く**まさにその軸**です（ステージ名、日付スケール、今日は縦線、過去の切り替わりは点）。セグメントをタップすると、そのステージの期間・目標・ガイダンスが下に展開され、プログラムが日付ではなく[GDD](journal.md#gdd)でステージを進める場合は、そのステージのGDD進捗もあわせて表示されます。

このタブでのみ、かつこの区画を編集できる場合にのみ、タブバーの右端に **Edit** ボタンが表示されます。

### Environment（環境）

地図ウィジェットの区画モーダルと同じ環境カードです — このステージの目標・限界値に対する現在の実測値で、各測定値がそれぞれ独自の行と軸を持ち、DLIと[積算温度](journal.md#gdd)も一緒に表示されます。独自の範囲を持たない行（CO2、土壌水分、露点など）は、*Trends* がオンのとき、推移を示すスパークラインで埋められます。

このタブが開いている間、タブバーの右端に **[Today][Daily][Weekly]** が表示されます — Dailyは直近7日間、Weeklyは直近8週間です。ステージ軸でステージを選ぶと、これまで通りそのステージの期間が表示期間になります。

実測値は**1ページに3つずつ**表示されます。4つ以上ある場合は、左右にスワイプ（またはマウスでドラッグ、フォーカス後は矢印キー）してページ単位で切り替えます。実測値の下に「1 / 3」のようなページ表示が出ます。

### Notes（ノート）

この区画のノートの最新の写真、続いて直近の予定と最近のノート、そして [Open Notes] — 地図ウィジェットの区画モーダルが使うのと**同じブロック**です（共有の `AoTNotesBlock`）。この区画自身のノートのみを表示し、ゾーンや施設のノートは表示しません。

---

## 編集

**Edit** を押すと、[`/plots` ページ](programs.md#plots-page)と同じドロワーが開きます — 文字通り同じ2つのコンポーネントなので、別途覚えることは何もありません。スケジュール、ステージのガイダンス、またはこの区画だけの[目標のオーバーライド](programs.md#plot-override)を変更し、**Save** を押します。押すまでは何も送信されません。保存せずにモーダルを閉じると、変更は破棄されます。ボタン自体は **Stages** タブのタブバー右端にあります。

---

## 最後の状態を覚えておく

一覧と区画詳細のどちらが開いていたか、どの区画だったか、どのタブだったか、環境ビューの単位（[Today]/[Daily]/[Weekly]）まで、ウィジェットが保存してページ再読み込み後に復元します。保存にはダッシュボードの編集権限が必要です。権限がなくても操作自体は自由にできますが、次回には覚えられていません。

## ウィジェット設定

| オプション | 説明 | デフォルト |
|---|---|---|
| 地図・サイト | 区画一覧を地図1つ、またはその中のサイト1つに絞り込みます — 選択肢は地図ごとにまとめられ、各グループは「**[地図名]・すべてのサイト**」（その地図全体）で始まり、続けてその中のサイトが並びます。空欄のまま（**すべての地図**）にすると、地図を問わず育成中の区画をすべて表示します。 | すべての地図 |
| Program stages | Stagesタブにステージ軸を表示します。 | On |
| Targets vs now | Environmentタブを表示します。 | On |
| Trends | Environmentタブで、独自のゲージを持たない行を最近の推移線で埋めます。*Targets vs now* が必要です。 | On |
| Accumulated heat | StagesタブにこのステージのGDD進捗を表示します（累計は環境カードに表示されます）。 | On |
| Refresh Interval | 再読み込みの間隔（分）。表示中の画面（一覧か、開いている区画詳細）だけが再読み込みされます。 | 5 |

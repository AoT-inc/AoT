# 시설 관리

`/geo/facility` 페이지에서 온실·재배사·설비동 등 건물의 3D 모델링, 공학 계산, 센서·액추에이터 연결, 장치 점검을 수행합니다. 모형이 창 전체를 쓰고, 시설 설정은 **설정** 단추로 여는 설정 창 하나에 **위치 · 구조 · 외피 · 구성요소 · 연결 · 검토** 여섯 탭으로 있습니다.

---

## 화면 구성

```
시설 설계 · [지도로] · <시설 이름> <남은 일> · [저장 안 된 변경] · [시설 저장]          ← 제목 줄
[지도 | 3D]  추가 [선택] [개구부] [시설물] [관수] [센서]  [보기: 방향 · 투시 | 등축 · 3D에 표시]  [도구 & 내보내기] [실행 취소]  [설정]   ← 도구 막대
┌── 무대: 3D 또는 지도 (한 번에 하나, 창 높이에 맞춤) ──┐   ┌── 설정 창 (오른쪽 서랍, 열어도 무대는 보임) ──┐
│                                                        │   │  위치 · 구조 · 외피 · 구성요소 · 연결 · 검토  ← 탭 │
│                                                        │   │  (고른 탭의 내용)                                  │
└── 상태줄 (고른 것 · 도구 안내) ────────────────────────┘   │  [새 시설] [시설 복제] [시설 저장]                 │
                                                             └────────────────────────────────────────────────────┘
```

- **제목 줄** — **시설 설계**, **지도로**, 지금 연 시설 이름과 그 옆의 **남은 일** 꼬리표, **저장 안 된 변경** 표시, **시설 저장**. 꼬리표는 버튼이 아니라 할 일이 남은 것만 말합니다 — **위치 남음**(이름·지도·배치 중 빠진 것이 있음), **연결 안 됨 3**(장치가 없는 구성요소 수). 끝난 것은 말하지 않으므로 다 채우면 꼬리표가 사라집니다. **위치 남음** 위에 마우스를 올리면 무엇이 빠졌는지 적혀 있습니다(**이름을 입력하세요**, **지도를 선택하고 시설을 배치하세요**). 치수·평면·구조·위치·외피는 **시설 저장**을 눌러야 저장됩니다. 저장된 시설의 구성요소와 **연결** 설정은 고치고 나서 약 1.5초 뒤 스스로 저장되고, 제목 줄에 **저장됨 HH:MM** 이 보입니다.
- **도구 막대** — 모형 위 한 줄입니다. 오른쪽 끝의 **설정** 이 설정 창을 엽니다. **지도 | 3D** 로 무대를 바꿉니다. **위치** 탭은 지도로, 나머지 탭은 3D로 열리고, 직접 고른 쪽은 그 세션 동안 탭마다 기억합니다. 지도에서는 **배치 지우기**·**지도에 배치**, 3D에서는 추가 도구(**선택**, **개구부**, **시설물**, **관수**, **센서** — **시설물 › 지도에서 가져오기…** 는 지도에 그려 둔 것을 구성요소로 가져옵니다), **보기** 메뉴(**방향** — 정해 둔 시점 9개, **투시 | 등축**, **3D에 표시** — 종류별로 모형에서 숨기기·보이기, 숨긴 것이 있으면 **보기** 옆에 그 수가 붙습니다), **도구 & 내보내기**(자산 라이브러리 · PNG/사양 파일/GLB 내보내기 · 사양 파일/GLB 불러오기 · 고품질 / 빠른 미리보기 · **3D 모형 다시 그리기**), **실행 취소** 가 있습니다. 설정 창을 열어 무대가 좁아지면 도구 막대가 한 줄을 지키도록 **실행 취소** 가 **더 보기**(=**도구 & 내보내기**) 메뉴 맨 위로 들어갑니다.
- **무대 — 3D** — 모형이 창 아래까지 꽉 차고, 페이지는 스크롤되지 않습니다. 모형 위에는 아무것도 덮지 않습니다. 맨 아래 상태줄에 고른 것, 켜져 있는 도구와 끝내는 법, 마우스 조작이 보입니다.
- **무대 — 지도** — **지도에 배치**를 누르고 지도에서 시설 중심을 클릭합니다. 놓인 시설은 끌어서 옮기고, 치수·회전은 입력하는 대로 사각형에 바로 반영됩니다.
- **설정 창** — **설정** 을 누르면 오른쪽에서 서랍처럼 열리고, 열린 동안에도 무대는 그대로 보이고 조작됩니다 — 모형을 보면서 값을 바꿉니다. 3D에서 구성요소를 클릭해도 열리고, 새 시설을 시작할 때는 저절로 열립니다. **닫기** 를 누르면 무대만 남습니다. 맨 위에 탭 여섯 개가 한 줄로 있고 고른 탭의 내용만 보입니다. 내용을 스크롤해도 탭 줄은 위에 남고, 방향키로 탭 사이를 옮깁니다. **저장된 시설** 은 머리의 **닫기** 왼쪽 단추입니다 — 누르면 목록이 설정 창 전체 높이로 열리고 지금 편집 중인 시설 위치에서 시작하며, 다시 누르거나 시설을 고르면 보던 탭으로 돌아옵니다.
- **구성요소 탭** — 모든 구성요소를 종류별로 보여 주고, 장치가 없는 행에는 **장치 없음**·**입력 없음** 꼬리표가 붙습니다. 위의 **추가** 옆에서 종류를 고르면 기본 위치에 하나 더합니다. 행을 고르면 3D에서 그 구성요소가 선택됩니다. 함께 만들어진 구성요소(여러 동의 천창처럼 한 장치를 같이 쓰는 것)는 **천창 ×6** 같은 한 줄로 접혀 있고, 그 줄에서 장치를 고르면 묶음 전체에 한 번에 들어갑니다. 줄을 누르면 펼쳐져 하나하나가 보입니다. 묶음에서 장치를 따로 쓰도록 떼어 낸 것은 펼친 목록에 **개별** 로 표시되고, 묶음의 장치 선택이 닿지 않습니다. 장치를 따로 쓰는 것만 남은 묶음(예: 측창 좌·우)은 접지 않습니다.
- **고른 구성요소** — 3D나 구성요소 탭에서 하나를 고르면 설정 창이 그 구성요소(이름·장치·위치·크기·회전·개폐 방식·삭제)로 바뀌고, **시설로** 를 누르면 돌아옵니다. **연결**·**검토** 탭은 시설을 저장하기 전까지 누를 수 없고, 탭 줄 바로 아래 한 줄에 그 이유를 적습니다.
- **휴대폰에서** — 열람과 작은 수정만 합니다. 제목 줄은 없고, 메뉴 아래 한 줄에 **지도로**·**지도 | 3D**·**설정** 만 남습니다(추가 도구·보기 메뉴·지도 배치·상태줄은 싣지 않습니다). 지금 연 시설 이름은 설정 창 제목에 나옵니다. 설정 창을 닫으면 모형이 화면을 채우고, **설정** 을 누르면 같은 설정 창이 화면 전체를 덮으며 위쪽 손잡이를 당기면 아래로 내려가 모형이 보입니다. 내려 둔 동안에도 위 줄의 단추를 누를 수 있고, **설정** 을 누르면 창이 다시 올라옵니다. 창 맨 위에 **배치와 평면 수정은 넓은 화면에서 합니다.** 가 있고, 탭은 **위치**·**구조**(숫자·켜기/끄기)·**외피**·**구성요소** 만 나오며(**연결**·**검토** 는 나오지 않습니다), 3D·목록에서 고른 구성요소는 이름과 장치만 담습니다. 진행은 **3/4 단계 · 연결 안 됨 2** 같은 한 줄입니다.

탭별 내용:

| 탭 | 내용 |
|------|-----------|
| **저장된 시설** (머리의 단추) | 목록(골라서 열기 · 삭제) — **새 시설**·**시설 복제** 는 열 아래쪽에 있습니다 |
| **위치** | **지도 및 대지**(이름 · 지도 · 대지), **위치**(회전) |
| **구조** | **구조**(구조 · 평면 · 동 수 · 간격 · 구역), **규격**(그룹 선택 · 프리셋 · 경간 · 처마 높이 · 용마루 높이 · 길이 · 지붕 유형), **수용량 미리보기**, **구역**(평면을 그렸을 때 그 구역) |
| **외피** | **피복 및 환기**, **커튼** |
| **구성요소** | 구성요소 목록과 **추가**, **관수**(배관·관수 장치·밸브 자동 생성) — 도구 막대 **관수** 메뉴의 자동 생성이 이 탭을 엽니다 |
| **연결** | **날씨**(예보 Input 연결), **그룹**(같은 종류 액추에이터를 리더·팔로워로 묶기), **라벨 색상**(측정 항목별 색 구간) — 시설을 저장한 뒤에 쓸 수 있습니다 |
| **검토** | **장치 점검**, **IEC 통합 요약**, 구획 페이지로 가는 링크 줄 — 시설을 저장한 뒤에 쓸 수 있습니다 |

구역마다 무엇을 기르는지는 여기가 아니라 구획 페이지에서 적습니다 — **검토** 탭 맨 아래 줄에 그 페이지로 가는 링크가 있습니다.

## 시설 등록 흐름 { #facility-registration-flow }

```
/geo/facility 열기  (/geo/design 시설 설정의 시설 설계 › 열기, 지도의 시설, 또는 주소 직접 입력)
         ↓
위치 › 이름 · 지도(대지는 선택) → 지도에 배치 → 지도에서 시설 중심 클릭 · 회전
         ↓
구조 › 구조·치수·지붕 → 외피 › 피복·환기·커튼 → 3D에서 확인
         ↓
도구 막대 › 모형에 센서·액추에이터 배치 → 하나씩 골라 설정 창에서 장치 연결
         ↓
시설 저장
         ↓
연결 › 날씨 서비스 · 액추에이터 그룹 · 라벨 색상 → 검토 › 장치 점검
```

- 시설은 이 페이지의 **시설 저장**으로 만들어집니다 — `/geo/design` 에서 먼저 그릴 필요가 없습니다. 저장하면 고른 지도에 시설 윤곽도 함께 놓입니다.
- 시설 없이 열면 빈 새 시설로 시작하고 **위치** 탭이 지도와 함께 열립니다. 지도에서 열면 그 지도가 이미 골라져 있습니다. 저장된 시설은 **저장된 시설** 목록에서 엽니다. 이때 주소에 `?facility_uuid=` 가 붙어 새로 고침이나 즐겨찾기로 같은 시설이 다시 열립니다.
- 저장하려면 지도와 배치가 있어야 합니다 — **지도에 배치** 없이는 저장이 거절됩니다. 이름은 비워 둘 수 있지만 제목 줄의 **위치 남음** 꼬리표가 계속 **이름을 입력하세요** 라고 알립니다.
- **시설 복제**는 지금 연 시설을 복사합니다. 연결된 센서·출력은 옮겨지지 않습니다.
- **연결**·**검토** 탭 — 그 안의 **IEC 통합 요약**·**장치 점검** 도 — 은 시설을 저장한 뒤에만 쓸 수 있습니다.

## 외피 설정

건물의 형태와 겉은 **구조**·**외피** 탭에서 정합니다 — 구조·동 수·평면은 **구조 › 구조**, 치수는 **구조 › 규격**, 그다음 **외피 › 피복 및 환기**와 **외피 › 커튼**. 회전은 **위치** 탭에 있습니다. 이 값들은 모두 냉난방 부하 계산과 3D 모델의 입력이 되며, 모델은 값을 바꾸는 대로 따라 바뀝니다.

**외피** 탭에 있는 외피 설정:

- **피복 및 환기**
    - **외피 (전체)** — 바깥 피복입니다. 늘 있으므로 자재만 고릅니다.
    - **내부 피복** (토글) — 안쪽 두 번째 피복: **피복 레이어**(자재)와 **에어갭** (m).
    - **측벽 보강** (토글) — **피복 레이어**, **위치**(X− · X+ · Y+ · Y−), **깊이** (m, 벽 바깥으로 나온 거리).
    - **정면 보강** (토글) — **위치**(Y+ · Y−), **깊이** (m).
    - **외부 측면 환기** (토글) — 측벽을 따라 나는 측창. **1단** 또는 **2단**이며, 2단이면 단마다 높이와 시작 높이(m)를 따로 정합니다.
    - **외부 천창 환기** (토글) — 천창. **위치**는 **중심** 또는 **좌우**.
- **커튼**
    - **천장 보온 커튼** (토글) — **1중** 또는 **2중**.
    - **측벽 보온 커튼** (토글) — 측면 환기의 단 구성을 따릅니다.
    - **차광 커튼** (토글) — **투과율**: 완전히 닫았을 때 통과하는 빛의 비율(0.30이면 10분의 3이 통과). 비워 두면 0.50으로 가정합니다.

여기서 켠 환기창과 커튼은 **외피 생성** 표시가 붙은 구성요소로 나타납니다 — 설정 창의 **구성요소** 탭과, 하나를 골랐을 때의 설정 창에서 — 거기서 움직일 액추에이터를 연결합니다.

### 구조 타입 { #structure-type }

**구조 › 구조**에서 고릅니다.

| 화면 | 값 | 설명 |
|------|----|------|
| **단동** | `single` | 동마다 독립된 구조물입니다. 동이 둘 이상이면 **간격 (m)**만큼 떨어져 한 줄로 섭니다. |
| **연동** | `connected` | 여러 동이 측벽을 공유해 한 건물을 이룹니다. 간격 칸이 없습니다. |

| `sandwich_panel` | 샌드위치 판넬 | 0.45 | 0% (불투명) | 외피 (전체) · 측벽 보강 / 내부 피복 |
| `concrete` | 콘크리트 | 3.1 | 0% (불투명) | 외피 (전체) · 측벽 보강 |
| `brick` | 벽돌 | 2.4 | 0% (불투명) | 외피 (전체) · 측벽 보강 |

### 동 설정 { #bay-configuration }

- **구조 › 규격**
    - **프리셋** — **표준 아치형**
    - **경간 (m)** — 동 하나의 폭
    - **처마 높이 (m)** — 바닥에서 처마까지
    - **용마루 높이 (m)** — 바닥에서 용마루까지. 처마 높이와의 차이가 지붕 높이입니다.
    - **길이 (m)** — 건물 길이
    - **지붕 유형** — **아치형**, **박공 지붕**, **박공 2**(동 하나에 용마루 둘), **평지붕**
- **구조 › 구조**
    - **동 수** (N) — 1~20
    - **간격 (m)** — 동과 동 사이 거리. **단동**일 때만 있습니다.
    - **구역** — 동이 둘 이상일 때 나타납니다. 동 사이 경계를 눌러 구역을 나누거나 합칩니다. 지도 위젯과 구역별 환경 제어가 이 구역을 씁니다.
- **위치 › 위치** — **회전** (°), 0~359, 숫자로 입력(시설을 옮기려면 지도에서 끕니다)

### 평면 그리기 { #plan-drawing }

층이 둘 이상이거나 평면이 단순한 직사각형이 아니면 **구조 › 구조 › 평면 그리기**를 엽니다. 층이 하나인 직사각형 시설은 쓰지 않아도 되고, 나머지 화면은 그대로입니다.

무대가 위에서 본 평면으로 바뀝니다. 위쪽이 북쪽입니다. 설정 창에는 층, 도구, 고른 항목의 값이 나오고, 맨 아래 **평면 닫기**로 평면을 나갑니다.

- **위층 추가** — 새 층은 비어 있고 아래층 외곽이 밑그림으로 보입니다. **아래층 복사**를 누르면 외형·구역·경계가 같게 시작합니다. 작물과 바닥 구멍은 복사하지 않고, 곡면·박공 지붕은 새 층으로 올라갑니다. **층고 (m)**만 적으면 층 높이는 아래층에서 계산합니다. 지울 수 있는 층은 맨 위 층뿐입니다.
- **외형 그리기** — 맞은편 두 모서리를 누릅니다. **점으로 그리기**는 점을 하나씩 찍고, 첫 점을 다시 누르면 닫힙니다. 점은 기존 모서리, 직각, 0.5 m 눈금 순으로 붙습니다. 같은 층 외형끼리는 겹칠 수 없습니다. ㄱ자 온실은 직사각형 둘을 맞붙여 그립니다. 곡면·박공 지붕은 직사각형 외형에만 둘 수 있습니다.
- **구역 나누기** — 벽 한쪽을 누르고 맞은편 벽을 누릅니다. 넓은 쪽이 원래 구역을 이으므로 그 구역의 구획은 그대로입니다.
- 두 구역 사이 선을 누르면 **벽**, **커튼**, **트임**을 고르거나 **구역 합치기**를 할 수 있습니다. 맞닿은 두 외형 사이 선도 같습니다.
- **바닥 구멍** — 계단이나 층 사이가 트인 공간에 씁니다. 2층부터 있고, 그 층에서 맞은편 두 모서리를 누릅니다.
- **실행 취소**로 한 단계씩 되돌립니다. **시설 저장**을 누르기 전에는 저장되지 않습니다. 열어 보기만 하고 닫으면 시설은 그대로입니다.

평면을 바꿔도 장치 좌표는 옮겨지지 않습니다. 구역이 달라지는 장치가 있으면 저장 전에 개수를 알려 줍니다.

평면을 저장하면 지도 도형은 전 층 외형에서 유도되고, 위의 구조·동 수·경간·길이·높이·지붕 유형은 잠깁니다. 평면 그리기에서 바꿉니다. **구조 › 구역** 에는 그린 구역이 나옵니다. **환경 제어는 아직 이 구역을 쓰지 않습니다.** 저장된 치수와 기존 구역으로 그대로 동작하며, 용량 미리보기의 바닥 면적·체적·투광·외피는 평면 값이고(구역을 합치면 바닥 합계와 같습니다), 난방·냉방·환기 면적은 저장된 치수 기준의 참고값입니다.

위층에 장치를 놓으려면 **3D에 표시**(도구 막대 **보기** 메뉴)에서 그 층을 고른 뒤 바닥에 놓습니다. 그 층 바닥 밖이나 바닥 구멍 위는 안내와 함께 놓이지 않습니다.

코디네이터와 구획은 저장된 기존 구역으로 이어집니다.

- 나눈 구역의 작물은 그 폭을 맡는 기존 구역의 코디네이터 후보가 됩니다.
- 위층 구역과 기존 폭 밖 구역은 이을 코디네이터가 없습니다. **구조 › 구역**, 평면, 저장 알림, 구획의 구역 선택지에서 알려 줍니다.
- 위층 구역의 구획은 구역을 정하지 않은 코디네이터에게도 제어 후보가 아니며, 구획 화면이 "위층 구획은 환경제어 대상이 아닙니다" 라고 알려 줍니다.
- 위층 장치는 환경 제어 입력에서 빠집니다. 위층 센서 값은 1층 제어값에 섞이지 않고, 위층 장치는 코디네이터가 움직이지 않습니다. 화면과 수동 조작에는 계속 나옵니다.
- 구역 총량은 나눌 때 원래 구역에 남고, 합칠 때 단위가 같으면 더합니다.

## 공학 계산 { #engineering-calculations }

시설의 외피 치수·자재를 기반으로 냉난방 및 환기 용량의 1차 참고치를 계산합니다 (±5~10% 오차, 기계설비 견적 단계 참고용).

치수·자재를 바꾸면 자동으로 다시 계산되어 **구조** 탭의 **수용량 미리보기**에 표시됩니다. 계산 항목은 아래와 같습니다.

| 계산 항목 | 단위 | 설명 |
|----------|------|------|
| 바닥 | m² | 건물이 차지하는 바닥 면적 |
| 부피 | m³ | 내부 공기 부피 |
| 유리 피복 | m² | 외피 피복 면적 (측벽 + 지붕 + 양 끝벽) |
| 환기구 열림 | m² | 환기구·개구부의 총 열림 면적 |
| 난방 | kW | 외피 관류 손실 + 침기 손실 |
| 냉방 | kW | 일사 부하 + 작물 증산 부하 |
| ACH | /h | 시간당 환기 횟수 — 자연환기와 팬을 합한 값 |

난방·냉방은 계산된 부하를 보여 줍니다. 액추에이터에 용량을 적어 두면 그 합계가 대신 표시되고, 값 위에 마우스를 올리면 그 정격 합계와 계산값을 비교해 볼 수 있습니다.

### 자연환기 풍압 시뮬레이션 { #natural-ventilation-wind-pressure-simulation }

`/api/geo/facility/<uuid>/wind` 엔드포인트를 통해 건물 형상과 풍향·풍속을 입력받아 환기 성능을 시뮬레이션합니다.

질의 값은 `speed`(풍속 m/s, 기본 3.0), `dir`(기상 표준 풍향 0~359°, 0은 북에서 불어오는 바람, 기본 0), `pct`(개구부 개방률 0~100%, 기본 100)입니다.

응답은 유효 환기 횟수(시간당) — 총 유입량과 총 유출량 중 작은 쪽 — 와 그 두 합계, 그리고 개구부마다 열린 면적·풍압계수·시간당 통기량·공기가 들어오는지 나가는지를 알려줍니다. 바람을 맞는 개구부는 양압을 받아 공기를 들이고, 바람을 등진 개구부는 흡인을 받아 내보내며, 바람과 나란한 개구부는 거의 통기하지 않습니다. 천창은 풍향과 무관하게 보아 풍속의 일정 비율만큼 환기합니다.

같은 풍향 판독은 환경 제어가 개구부에 내리는 명령에도 가중치로 쓰입니다.

| 바람 | 개구부 명령에 걸리는 가중치 |
|------|----------------------------|
| 0.5 m/s 미만 | 걸지 않음 — 모든 개구부가 명령한 위치로 갑니다 |
| 0.5 ~ 3.0 m/s | 풍압에 비례해 서서히 들어오므로, 약하고 불안정한 바람은 명령을 거의 바꾸지 않습니다 |
| 3.0 m/s 이상 | 온전히 걸립니다 |

천창은 풍향과 무관하게 열기를 빼는 역할이므로 깎지 않고, 향한 방향을 알 수 없는 개구부도 명령한 위치 그대로 둡니다. 바람을 맞는 측창은 명령대로 열리고, 바람을 등진 측창은 줄어들지만 20% 아래로는 내려가지 않습니다.

시뮬레이션이 함께 돌려주는 가중치는 풍향만 반영한 온전한 값이며, 입력한 `speed` 로는 완화되지 않습니다.

## 센서·액추에이터 바인딩 { #sensor-actuator-binding }

시설 내 AoT 장치를 역할에 맞게 연결합니다.

### 센서 역할 { #sensor-roles }

센서는 역할 이름을 따로 고르지 않습니다. 센서 행에서 정하는 값이 곧 그 센서의 역할입니다 — 3D나 설정 창의 **구성요소** 탭에서 센서를 고르면 설정 창에 그 행이 나옵니다.

| 칸 | 고르는 값 | 뜻 |
|----|-----------|----|
| **— 채널 선택 —** | Input·Function 장치의 측정 채널 | 한 장치의 채널을 여러 개 고를 수 있습니다(예: 온습도계의 온도·습도). 다른 장치의 채널을 고르면 센서 전체가 그 장치로 옮겨 갑니다. |
| 측정 항목 | **— 자동 —** · **온도** · **습도** · **CO2** · **VPD** · **일사량** · **풍속** · **풍향** · **돌풍** · **강수량** | **— 자동 —**은 채널에서 항목을 추정합니다. 틀리게 잡히면 직접 고릅니다. 이름이 "speed" 뿐인 돌풍 채널(최대 돌풍을 그렇게 내는 기상대가 있습니다)은 직접 **돌풍**으로 골라야 합니다 — 아니면 풍속으로 읽힙니다. |
| 위치 | **실내** · **실외** | 실내 센서는 시설의 실내값이 되고(여럿이면 가중 평균), 실외 센서는 바깥 조건이 됩니다. |
| 우선순위 (**실외**일 때만) | **메인 센서** · **백업 센서** | 백업 센서는 메인 센서 값이 끊겼을 때만 씁니다. 둘을 평균하지 않습니다. 같은 순위 안에서도 예보 모델 입력(Open-Meteo 등)은 실측 센서와 평균하지 않고, 실측이 주지 못하는 값만 채웁니다. 강수량은 순위와 상관없이 신선한 실측이 예보를 이깁니다. |

한 장치의 채널 하나만 골라도 나머지가 버려지지는 않습니다. 그 장치에서 어떤 측정 항목의 후보 채널이 정확히 하나뿐이면 고르지 않은 채널도 함께 읽습니다 — 그래서 일사량 채널만 묶은 기상대도 온도·습도·풍속·풍향·강수량을 그대로 내놓습니다. 반대로 한 장치가 같은 항목을 여러 채널로 내보내면(온도 채널을 여섯 개 내보내는 콘솔) 자동으로 채우지 않습니다. 서로 다른 자리의 값을 한데 평균하면 안 되기 때문이며, 쓸 채널을 직접 고르면 됩니다. 직접 고른 채널이 언제나 우선하고, 같은 **위치**의 다른 센서에서 이미 고른 항목은 두 번 끌어오지 않습니다.

### 액추에이터 역할 { #actuator-roles }

센서가 아닌 행에는 그 구성요소를 움직일 장치를 고르는 **액추에이터** 칸(**— 없음 —** 또는 Output)이 있습니다. 액추에이터 하나가 여러 구성요소를 움직일 수 있습니다. 통합환경제어가 그 장치를 무엇으로 쓰는지는 구성요소 종류로 정해집니다.

| 구성요소 | 행의 설정 | 제어에서의 역할 |
|----------|-----------|-----------------|
| **팬** | 액추에이터 · **팬 역할**(**순환 팬** / **배기 팬** / **흡기 팬**) | 고른 팬 역할 (정하지 않으면 순환 팬) |
| **히터** | 액추에이터 | 난방 (3D 도구 이름은 **냉난방기**) |
| **가습기** | 액추에이터 | 가습 |
| **커튼** | 액추에이터 | 보온 커튼 (**외피**에서 켠 천장·측벽 보온 커튼도 이 종류) |
| **차광 커튼** | 액추에이터 | 차광 (**외피**에서 켠 차광 커튼) |
| **창호** | 액추에이터 | 개구부, 천창으로 다룸 (**외피**에서 켠 천창도 이 종류) |
| **측창** | 액추에이터 | 개구부, 측창 (외기를 직접 들임) |
| **출입문** | 액추에이터 | 개구부, 측창처럼 다룸 |
| **설비** | 액추에이터 | 통합환경제어에 등록되지 않음 |
| **관수 레이어** | 액추에이터 — 그 레이어의 **급수원**(펌프·주 밸브) | 스프링클러가 달려 있으면 가습 수단으로 등록, 점적만 있으면 환경 제어에 쓰지 않음 |
| **관수 밸브** | 액추에이터 — 레이어 안의 한 **구역** | 관수 레이어와 같음 |
| **메인 배관** | 없음 | 3D에서 배관을 골라 지우기 위한 행 |

**등록 방법:**

1. 무대를 **3D**로 둡니다.
2. 도구 막대의 **추가** 메뉴(**개구부**, **시설물**, **센서**, **관수**)로 위치를 클릭해 배치하거나, 설정 창의 **구성요소** 탭을 열어 **추가** 옆에서 유형을 고른 뒤 **추가**를 클릭합니다.
3. 3D나 구성요소 탭에서 구성요소를 고릅니다. 설정 창에서 센서는 **— 채널 선택 —**으로 측정 채널을 고르고 측정 항목과 **실내**/**실외**를 지정합니다. 그 밖의 구성요소는 구동할 액추에이터를 고릅니다.
4. 저장된 시설이면 잠시 뒤 스스로 저장됩니다(**저장됨 HH:MM**). 새 시설은 **시설 저장**을 누릅니다.

### 기상 예보 연결 { #weather-forecast-bindings }

시설의 예보 값(추워지기 전에 미리 데우는 것 같은 선제 제어에 쓰입니다)은 **연결** 탭의 **날씨**에서 가져옵니다. 각 행은 **기온(°C)** 같은 측정 항목 하나를 Input 채널 하나에 묶습니다.

**Open-Meteo Hourly Forecast** 입력을 쓰려면 **Open-Meteo 예보 입력에서 추천 연결 채우기** 를 누르세요. 항목마다 채널 하나씩 표에 채워집니다.

| 측정 항목 | 채워지는 채널 |
|---|---|
| 기온 | Temperature +3h |
| 습도 | Window Max Humidity |
| 풍속 | Window Max Wind |
| 강수확률 | Window Max Rain Probability |
| 강수량 | Window Max Hourly Rain |
| 일사량 | Solar +1h |

- 같은 항목에 연결이 여러 개면 평균되므로 항목마다 채널 하나만 채웁니다.
- 채워진 행은 1시간(3600초)보다 오래된 값을 쓰지 않도록 설정됩니다. 예보 입력은 30분마다 갱신되므로 두 번 놓친 값은 더 이상 쓰지 않습니다.
- 버튼은 표만 채웁니다. 내용을 확인한 뒤 **시설 저장** 을 누르세요.
- Open-Meteo 시간별 예보 입력이 여러 개면 버튼 옆 목록에서 쓸 입력을 고릅니다. 활성화된 것이 없으면 먼저 추가하라는 안내가 나옵니다.
- 이 입력을 쓰는 같은 항목의 행이 이미 있으면 그 행을 갱신합니다(직접 지은 행 이름은 유지). 다른 입력을 쓰는 행은 건드리지 않으며 새 값과 평균됩니다.

## 통합 뷰 (Integration) { #integration-view }

`/api/geo/facility/<uuid>/integration` 엔드포인트는 시설에 바인딩된 모든 센서·액추에이터의 현재 상태를 통합하여 반환합니다. AoT_facility 위젯의 환경 패널이 이 API를 사용합니다. 팬 액추에이터 항목에는 액추에이터의 풍량 사양, 비어 있으면 팬 피팅에 적힌 풍량에서 읽은 정격 풍량(`rated_m3h`)이 실립니다. 시간별 예보 입력(**Open-Meteo Hourly Forecast**)의 채널은 센서로 자동 해석되지 않고, 그런 입력은 시설 센서로 저장할 수도 없습니다 — 몇 시간 뒤 값이 지금 값으로 읽히기 때문입니다. 예보는 **연결** 아래 **기상** 탭에 연결하세요.

## 장치 점검 { #device-check }

시설에 연결된 액추에이터를 짧게 작동시켜 명령이 전달되고 센서가 반응하는지 확인하는 진단 워크플로우입니다. 시설을 저장한 뒤에 사용할 수 있습니다.

1. **검토** 탭의 **장치 점검**에서 점검할 장치를 선택하고(**전체 선택** 가능) **점검 시작** 클릭
2. 시스템이 선택한 액추에이터를 차례로 켰다 끄며 실내 센서의 반응을 기록합니다.
3. 각 장치의 결과 상태가 표시됩니다.
   - **보통**: 명령이 전달되고 센서가 예상 방향으로 반응함
   - **검토 필요**: 센서 반응이 없거나 예상과 반대 방향 (센서 위치·장치 배선 확인)
   - **응답 없음**: 명령 전달 실패 (장치 연결 확인 필요)
4. 장치마다 **판정**(보통 / 센서 의심 / 장치 고장 / 외부 교란 / 건너뛰기)을 고르고 **판정 적용**을 클릭하면 결과가 제어 알고리즘 설정에 바로 반영됩니다.

## AI 조언 패널

시설 화면에는 AI 조언 패널이 없습니다. 앱 안의 AI와 연결된 다른 AI가 낸 조언은 **AI → 요청** 화면(`/ai`)의 **AI 조언**에 모입니다. 채택은 동의한다는 기록일 뿐, 아무것도 실행하지 않습니다. [AI 기능 개요](../ai/overview.md)를 참고하세요.

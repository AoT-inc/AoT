# 지도 디자인 도구

`/geo/design` 페이지는 농장을 지도 위에 배치하는 곳입니다 — 대지 경계를 그리고, 재배 구역을 나누고, 건물을 배치하고, 센서·밸브가 실제로 어디에 있는지 정확히 표시합니다. 여기서 그린 내용은 그대로 대시보드의 [AoT 지도](../Data-Viewing.md#widget-map) 위젯에 나타나므로, 위젯을 꾸미기 전에 이 페이지부터 제대로 설정해두는 게 좋습니다.

---

## 예시로 알아보기: 새 하우스 배치하기

바깥에서 안쪽 순서로 진행하는 전형적인 첫 작업입니다.

1. **대지** — **대지** 모드에서 전체 대지 둘레를 폴리곤으로 그립니다. 속성 패널에서 이름을 붙이면 그리는 즉시 자동 저장됩니다.
2. **구역** — **구역** 모드로 전환해 대지 경계 안쪽에 재배 구역(화단) 폴리곤을 그리고 이름을 붙입니다(예: "1동").
3. **시설** — 시설은 여기서 그리지 않고 시설 화면에서 만듭니다. **시설** 모드로 전환해 설정 드로어의 **시설 설계** 옆 **열기** 버튼(또는 `/geo/facility`로 직접 이동)을 누른 뒤 **+ 새 시설** → 이 지도 선택 → **지도에 배치** → **시설 저장** 순서로 진행합니다 — [시설 등록 흐름](facility.md#facility-registration-flow)을 참고하세요. 저장하면 시설 외곽 도형이 이 지도의 시설 레이어에 생깁니다.
4. **장비** — **장비** 모드로 전환해 펌프·밸브 몇 개와 그 사이를 잇는 배관을 추가합니다(아래 [장비 모드](#equipment) 참고 — 배관/관수 자동 생성 도구가 있습니다).
5. **장치** — 장치 모드(모드 패널에는 **A**로 표시됨)로 전환해 실제 입력/출력/함수 장치를 배치합니다(아래 [장치 모드](#device-a) 참고).
6. **대시보드에서 확인** — 이 지도를 가리키는 AoT 지도 위젯을 추가하면 방금 그린 도형·마커가 그대로 나타나고, 장치 마커를 클릭하면 실시간 값과 제어 버튼이 뜹니다.

이 순서를 강제하는 규칙은 없습니다(구역이 없는 상태에서 장치부터 배치해도 동작합니다). 다만 바깥→안쪽 순서로 그리면 구역을 그린 뒤에 배치한 설비·장치가 자동으로 그 구역에 연결되므로 더 편합니다 — 이 자동 연결이 정확히 어떻게 동작하고 무엇은 안 되는지는 [편집 모드](#editing-modes)를 참고하세요.

## 화면 구성 { #screen-layout }

```
┌──────┬──────────────────────────────────┬────────────┐
│      │                                  │            │
│  좌측 │          지도 캔버스               │  설정      │
│  도구 │    (MapLibre GL 벡터 렌더링)       │  드로어    │
│  모음 │                                  │            │
│      │  ┌────────────────────────────┐  │  (모드별)  │
│      │  │ 모드 탭 (대지/구역/시설/…)   │  │            │
└──────┴──┴────────────────────────────┴──┴────────────┘
```

**모드 탭은 지도 아래 가로 막대**에, **그 모드의 설정은 지도 오른쪽 드로어**에 있습니다. 드로어는 지도를 덮지 않고 옆으로 밀어내므로, 설정을 만지는 동안에도 그 결과가 지도에 그대로 보입니다. 드로어를 연 채로 지도를 움직이거나 도형을 클릭할 수도 있습니다. 폰에서는 드로어가 화면 전체를 덮고, 위쪽 손잡이를 누르면 아래로 내려가 지도가 보입니다.

## 편집 모드 { #editing-modes }

지도 아래 모드 탭에서 편집 대상을 선택합니다 — **6가지 모드**가 있습니다: 대지, 구역, 시설, 구획, 장비, 그리고 장치(탭에는 "AoT device"의 줄임말인 **A**로 표시됩니다). 모드마다 그릴 수 있는 도형과 속성이 다릅니다. 탭을 누르면 그 모드의 설정 드로어가 함께 열립니다.

### Site (대지) { #site }

대지 최상위 경계를 정의합니다.

- **그리기**: 사각형, 원, 폴리곤.
- **속성**: 이름, 테마 색상 — 색상 변경은 자동 저장됩니다.
- **스위치**: **지도에 표시**는 다른 모드에서 작업하는 동안 이 종류의 도형을 숨깁니다. **길이 라벨 표시**는 각 변의 실측 길이를 지도에 띄웁니다.
- **특수 기능**: VWorld/CSV 필지 가져오기(아래 [필지 가져오기](#parcel-import) 참고).

### Zone (구역) { #zone }

대지 내 재배동·관리 구역을 정의합니다.

- **그리기**: 사각형, 원, 폴리곤.
- **속성**: 이름, 테마 색상.

!!! 참고
    구역을 그린다고 해서 그것을 둘러싼 대지와 자동으로 연결되지는 **않습니다** — 이 연결은 추적되지 않습니다. 반대 방향은 자동입니다: 구역이나 대지 **안쪽에** 배치한 장비·장치는 자동으로 그 구역에 연결됩니다(아래 참고). 그래서 설비·장치를 배치하기 전에 구역부터 그려두는 순서가 더 수월합니다. 도형이 겹치는 자리에서는 그것을 품은 **가장 작은** 도형으로 연결됩니다 — 보통 둘러싼 대지가 아니라 구역 쪽입니다.

### Facility (시설)

물리적 건물(온실, 창고, 설비동)을 배치합니다.

- **그리기**: 선, 사각형, 원, 폴리곤, 마커, 라벨 — 건물 외곽선은 폴리곤으로 그립니다.
- **속성**: 이름, 테마 색상.
- **특수 기능**: **시설 설계** 옆 **열기** 버튼은 `/geo/facility`로 이동합니다. 시설을 만들고 저장하는 일, 배치·3D 모델링·공학 계산·대지 선택은 모두 그 페이지에서 이뤄지며 여기서는 하지 않습니다. 이 모드에서 직접 그린 폴리곤은 일반 도형으로 남을 뿐 시설 화면의 시설이 되지 않습니다. [시설 등록 흐름](facility.md#facility-registration-flow)을 참고하세요.

### 구획 { #plot }

**어디에 무엇이 있는가**를 기록합니다. 구역(Zone)이 "이 자리는 3-1 구역"이라면, 구획은 "그 3-1 구역의 이 부분에 3월 20일부터 상추가 있다"입니다.

- **그리기**: 사각형, 원, 폴리곤.
- **속성**: 종류, 대상, 품종, 구획 이름, 프로그램, 시작일, 예상 종료일, 색상.

**식생 전용이 아닙니다.** 구획에는 **종류**가 있습니다 — 식생 · 가축 · 시설 · 기타. 종류를 고르면 프로그램 선택지가 그 종류로 좁혀집니다.

**프로그램을 붙이면** 현재 단계·목표 환경·예상 종료일이 자동으로 따라옵니다. [관리 프로그램](programs.md)을 참고하세요.

!!! 참고 "구역과 달리 수명이 있습니다"
    구획은 끝나는 날이 있습니다 — 노지 두둑이면 3~9개월, 과수면 30년입니다. 그래서 다른 도형과 **다른 곳에 저장되며**, 종료해도 기록이 지워지지 않고 이력으로 남습니다. "이 자리에 최근 3년간 뭐가 있었나"(연작 장해·윤작 판단)에 답할 수 있는 근거가 됩니다.

**겹쳐 그려도 됩니다.** 간작·혼작은 정상이므로 구획끼리 겹치는 것을 막지 않습니다. 면적 비율의 합이 100%를 넘어도 오류가 아닙니다.

**상위 구역을 고르지 않습니다.** 그냥 그리면 되고, 어느 구역에 속하는지는 위치로 자동 판정됩니다 — 설비·장치와 같은 방식입니다.

#### 구역을 여러 구획으로 나누기 { #split }

한 구역을 몇 개로 갈라 심을 때, 조각을 하나씩 그리지 않고 **나누게** 할 수 있습니다. 구획 모드로 들어가면 분할 폼이 구획의 대상·품종 칸 위에 바로 나와 있습니다.

- **나눌 도형** — 지도에 이미 그려 둔 구역·대지 중에서 고릅니다. 아직 저장하지 않은 도형은 목록에 없습니다(먼저 저장하세요).
- **나누는 기준** — **등분**(몇 개로 자를지)이나 **띠 폭**(한 조각을 몇 cm 로 할지) 중 하나입니다. **등분에 1을 넣으면 나누지 않습니다** — 구역 전체가 구획 하나가 됩니다(가장자리 여백을 줬으면 그만큼 안으로 들어옵니다). 밭 하나를 통째로 한 작기로 쓸 때 이렇게 하면 됩니다. **띠 폭**을 고르면 "정확한 조각 수(선택)" 칸이 함께 나타납니다 — 비우면 지금까지처럼 그 폭으로 채울 수 있는 만큼 자동으로 개수가 정해지고, 채우면 정확히 그 개수만 그 폭으로 자르고 남는 치수는 양쪽 여백이 됩니다(균등분할이 아닙니다 — 예: "5줄만, 정확히 40cm 간격으로" 처럼 개수와 간격을 둘 다 직접 정할 때 씁니다).
- **방향** — **등분**을 고르거나, **띠 폭**에서 "정확한 조각 수"를 같이 채웠을 때만 보입니다(둘 다 "N개를 어느 방향으로 늘어놓을지"의 문제이기 때문입니다). **긴 변**(기본)은 조각이 밭의 긴 방향을 따르고, **짧은 변**은 그 반대쪽을 등분해 더 정방형에 가까운 조각을 냅니다. 두둑이 아니라 서로 다른 작물을 나눠 심을 구획이 목적이면 짧은 변이 편할 수 있습니다. **자유 각도**를 고르면 각도 슬라이더가 나타나 원하는 방향으로 직접 돌릴 수 있습니다 — 슬라이더를 움직이는 동안 구역 중심을 지나는 기준선이 지도 위에서 그 각도로 즉시 돌아가고, 잠깐 멈추면 분할 조각도 그 각도로 다시 그려집니다.
- **가장자리 여백** — 농기계가 돌 자리를 도형 안쪽으로 남깁니다. 필요 없으면 0 입니다.
- **구획별 폭 직접 조정** — 위 모드들은 모두 조각의 폭이 서로 같습니다. 이 토글을 켜면 조각마다 다른 폭을 줄 수 있습니다 — 이미 나온 균등 분할에서 시작해 조각마다 숫자 칸(m 단위)이 하나씩 나오고, 조각을 더하거나 뺄 수 있는 버튼도 함께 나옵니다(최소 1개). 방향은 이때도 그대로 적용됩니다 — 폭 목록은 각 조각의 두께만 정할 뿐, 자르는 축의 방향을 정하지는 않습니다. 마지막에 입력한 조각이 남는 자리보다 크면 거부하지 않고 들어가는 만큼 자동으로 줄이며, 아래 요약 줄에 그 사실을 알립니다. 지도의 점선 조각마다 번호가 붙어 입력칸과 맞춰 볼 수 있습니다.
- **대상·품종·구획 이름·시작일·색** — 만들어질 조각 전부에 같은 값이 들어갑니다. 구획 이름에는 조각 번호가 뒤에 붙습니다(`시험구 1`, `시험구 2`, …).

**값을 바꾸면 지도가 곧바로 따라옵니다.** 제안이 **점선**으로 그려지고, 폼 아래에 조각 수·조각 폭·길이 범위·방향이 뜹니다. 조각이 가늘고 길면(대략 4:1을 넘으면) 종횡비와 함께 경고로 뜹니다 — 방향을 짧은 변으로 바꿔 보라는 신호입니다. 미리보기를 따로 확정하는 단계는 없습니다 — 드로어가 지도를 가리지 않으므로 **화면에 보이는 것이 곧 제안**입니다. 마음에 들면 **구획 만들기**를 누르고, 아니면 그냥 드로어를 닫으면 됩니다(아무것도 저장되지 않습니다).

!!! 참고 "조각은 기본으로 밭의 긴 방향을 따릅니다"
    정북 기준으로 자르면 비정형 밭에서는 두둑이 밭을 비스듬히 가로질러 자투리만 생깁니다. 그래서 도형의 **가장 긴 변**을 따라 자르고, 비뚤어진 가장자리는 잘라냅니다. 조각마다 길이가 다른 것은 그 때문이고, 두둑으로 쓰기에 너무 짧은 조각(2m 미만)은 버립니다 — 버린 개수도 함께 표시됩니다. 띠 폭을 지정하는 두둑 분할에서는 고랑 방향이 실제 작업 방향과 맞아야 하므로 방향을 바꿀 수 없습니다.

#### 두둑 배치는 노트에 적습니다 { #bed-layout }

"여기 몇 줄 심을 수 있나"를 AI에게 물으면 **두둑 위에만 심는 실제 방식**으로 셉니다. 밭 전체에 균일하게 깔아 세면 실측에서 24% 과다추정이었습니다(폭 28.4m 기준: 균일 배치 71줄 → 두둑 배치 54줄).

그 배치를 **입력란이 아니라 구획 노트에 문장으로** 남깁니다. AI가 배치를 모르면 균일 배치 숫자를 조용히 내밀지 않고 **먼저 되묻고**, 정해진 내용을 노트로 적어 두라고 안내합니다. 다음 대화는 그 노트를 읽습니다.

!!! 참고 "왜 입력란이 아닌가"
    "두둑 폭"을 물으면 **고랑을 뺀 윗면**으로 답하는 사람과 **고랑까지 포함한 한 세트**로 답하는 사람이 갈립니다. 같은 밭이 `120+40`으로도 `160+0`으로도 기록되고, **에러 없이 두둑 수만 달라집니다.** 숫자 칸은 "어느 의미로 적었는지"를 담지 못합니다. 게다가 배치는 시작일 뿐이고 멀칭·지주·관수 관행이 뒤따르는데, 그걸 전부 칸으로 만들 수는 없습니다 — 그래서 노트가 있습니다.

AI에게 셈을 시킬 때 쓰는 값은 둘입니다.

- **두둑 간격** — 두둑 중심에서 다음 두둑 중심까지, **고랑을 포함한** 하나의 숫자입니다(120cm 두둑 + 40cm 고랑이면 `160`). 농부는 두둑과 고랑을 따로 세지 않으므로 하나로 묻는 편이 갈리지 않습니다.
- **두둑당 줄 수** — 작물에 따라 다릅니다. 고추는 한 줄, 상추·배추는 두세 줄입니다. 간격만으로는 줄 수를 알 수 없어 이 값이 함께 있어야 합니다.

두 값은 **함께** 줘야 합니다. 평평하게 심는 밭이라면 대신 줄 간격을 씁니다.

#### 온실 동의 작물 옮기기 { #migrating-crops-from-facility-bays }

기존에 시설(온실) 동에 적어 둔 작물 이름은 백필 스크립트로 구획으로 옮길 수 있습니다. 관리자에게 문의하세요 — 기하는 그 시점의 모양을 **복사**해 오므로, 나중에 동 수를 바꿔도 과거 작기가 따라 움직이지 않습니다.

### Equipment (설비) { #equipment }

펌프·밸브·배관·관수 배치를 담당합니다. 이 모드는 세 개의 하위 탭으로 나뉩니다.

- **장치** — **급수원**(하천/물탱크/펌프), **필터**(디스크/스크린/모래), **밸브**(유니온/어댑터/인라인/리듀서), **연결**(석션/엘보/티/리듀서 — 별도 그리기 모드가 아니라 배관 이음쇠 항목입니다) 카테고리로 묶인 점 마커 카탈로그입니다. 항목을 고르고 지도를 클릭해 배치합니다.
- **배관** — **기준선** 또는 **주 배관**을 그리고 **간격과 각도**(분기 간격·각도·오프셋)를 설정한 뒤 **가지 배관 만들기**의 **생성**을 클릭하면, 구역 경계에 맞춰 잘린 평행 분기 배관을 자동으로 만들고 메인 배관과 교차하는 지점에서 분할해줍니다. **90도 분기**를 켜면 기준선을 따르지 않고 주 배관에 직각으로 가지를 놓고, **초기화**는 만들어진 배관을 지워 처음부터 다시 할 수 있게 합니다.
- **관수** — **스프링클러** 또는 **점적** 중 선택하고 간격·유량·압력을 설정한 뒤(반경은 스프링클러에만 있습니다) **생성**을 클릭하면, 하나씩 배치하지 않아도 구역 전체에 살수 지점이나 토출구를 자동으로 배열합니다. **초기화**로 다시 지울 수 있습니다.

구역이나 대지 폴리곤 안쪽에 배치한 장비는 자동으로 해당 구역에 연결됩니다 — 이 재확인은 지도를 불러올 때와 도형을 편집할 때 일어나므로, 방금 배치한 마커는 새로고침하거나 살짝 옮기기 전까지는 통계 패널에 구역 연결이 반영되지 않을 수 있습니다.

### Device (장치) { #device-a }

등록된 AoT 입력·출력·함수 장치의 실제 위치를 표시하고 지도에 연결합니다. 이 모드에서는 **장치 종류**(**입력**/**출력**/**함수**/**장치**)를 먼저 고릅니다. 실제 작업 흐름은 다음과 같습니다.

1. **선택 목록**의 **열기**를 클릭해 실제 등록된 장치 목록을 엽니다(출력은 채널별로 표시).
2. 장치를 켜면 (지금 보고 있는 위치가 아니라) **현재 지도 화면의 중심**에 마커가 나타납니다. 이를 드래그해 실제 위치로 옮기면 새 위치가 자동 저장됩니다.
3. 장치를 끄면 마커가 제거됩니다.

**마커가 아니라 도형을 장치에 연결하기**: 이미 배치된 장치 마커를 클릭하면 "활성화"됩니다(색이 바뀌고 활성화됐다는 토스트 알림이 뜹니다) — 이 상태에서 다음에 그리는 도형은 종류에 상관없이 자동으로 그 장치에 연결됩니다(단순 도형이 아니라). 팬의 작동 범위나 특정 장치에 딸린 스프링클러 구역처럼, 장치의 위치 마커와는 별도로 그 장치에 연결된 영역을 그릴 때 사용하세요.

**점이 아니라 자리를 장치에 맡기기**: 지도에서 구역이나 대지를 선택하면 드로어에 **장치 배정** 줄이 나타납니다 — **배정**은 그 자리를 어느 장치가 맡는지 기록합니다. **장치 없는 자리**의 **보기**를 누르면 아직 배정이 없는 구역이 나열됩니다. **장치 구역으로 나누기**는 구역이나 대지를 여러 조각으로 자릅니다 — **등분** 또는 **띠 폭**에, **방향**(긴 변·짧은 변·사용자 각도)과 **가장자리 여백 (cm)**을 고릅니다. 구획 분할과 달리 띠 폭으로 자를 때도 방향을 고를 수 있고, 조각은 50 cm 미만으로 나올 때만 버려집니다. **구역 이름**에 이름을 적고 **장치 구역 만들기**를 눌러야 저장되며, 누르기 전에는 아무것도 저장되지 않습니다. 각 조각은 그 안에 마커가 들어온 장치에 연결되고, 안에 마커가 없거나 둘 이상인 조각은 연결하지 않고 그대로 알려 줍니다. **이 종류의 장치만 연결**을 쓰면 입력·출력·함수·Device Unit 중 하나로 연결 대상을 좁힐 수 있고, 기본값 **모든 종류**는 전부를 대상으로 삼습니다. 지도에 구역이나 대지가 하나도 없으면 폼 대신 먼저 그리라는 안내 문장이 나옵니다.

**지도나 장치의 탭이 다른 접근 그룹에 배정돼 있으면** 위치 저장이 거부됩니다 — 마커를 놓는 것, 끄는 것, 드래그하는 것이 모두 같은 저장을 거칩니다. 화면에는 아무 표시가 없습니다. 마커는 놓은 자리에 그대로 있다가, 새로고침하면 서버에 기록된 자리로 되돌아갑니다.

*특징:* [AoT 지도](../Data-Viewing.md#widget-map) 위젯의 대시보드 화면에서 장치 마커를 클릭하면 실시간 값과(출력의 경우) On/Off 제어가 표시됩니다 — 그래서 여기서 장치 위치를 정확히 배치하는 것이 중요합니다.

### 그리기 도구

사용 가능한 도구는 모드에 따라 다릅니다: 대지·구역 모드는 **사각형, 원, 폴리곤**을, 시설·장비·장치 모드는 여기에 더해 **선, 마커, 라벨**을 제공합니다. 그리기 도구에는 키보드 단축키가 없으며 도구 모음 버튼으로만 조작합니다.

- **편집(Edit)** — 기존 도형의 꼭짓점을 드래그해 모양을 바꿉니다.
- **삭제(Delete)** — 도형을 클릭해 제거합니다. 도형이 겹쳐 있으면 클릭할 때마다 커서 아래에서 가장 위에 있는 도형 하나만 삭제되므로, 아래 도형을 지우려면 다시 한번 클릭하세요.

## 필지 가져오기 { #parcel-import }

한국 토지 데이터(VWorld)를 이용해 대지 경계를 손으로 그리지 않고 빠르게 가져올 수 있습니다. **대지** 모드에서 설정 드로어의 **주소로 추가** 옆 **검색** 버튼을 누르면 창이 열리는데, **주소 입력** 탭(주소를 하나 이상 입력, VWorld PNU API 사용)과 **CSV 일괄** 탭(한 줄에 주소 하나, 첫 번째 열만) 중 하나를 씁니다. 어느 쪽이든 같은 미리보기로 이어집니다 — 지도 위에 그려지는 찾은 필지들, 맞닿은 결과를 하나의 대지로 합치는 선택적 **인접 필지 통합** 체크박스(켜야만 합쳐집니다), 그리고 **대지로 저장** 버튼. 이미 가져온 필지를 다시 가져오면 중복 생성되지 않고 건너뜁니다. 다른 접근 그룹에 배정된 지도에는 저장이 거부되며, 그 필지들은 이유 없이 상태줄에 **실패**로 집계됩니다.

전체 과정과 API는 [필지 가져오기 상세](parcel-import.md)를 참고하세요.

## 레이어 제어 { #layer-control }

우측 상단 **레이어** 패널에서 표시할 레이어를 켜고 끕니다.

- **기본 지도**: 등록된 GIS 레이어 제공자 중 하나를 고릅니다 — 한 번에 하나만 켜집니다.
- **오버레이**: 등록된 오버레이 레이어(기상 레이더 등)를 각각 표시/숨김
- **도형**: 대지·구역·시설·구획·설비·장치 도형을 표시/숨김 — 각 모드 설정 드로어의 **지도에 표시** 스위치와 같은 것입니다.

새 레이어 제공자를 등록하려면 [GIS 레이어](layers.md)를 참고하세요.

## 통계 패널 { #statistics-panel }

지도 아래 **설계 정보** 영역이 스스로 채워집니다 — 따로 누를 버튼은 없습니다.

- **설계 요약** — 대지 수, 구역 수, 배관 총 길이, 토출구 수, AoT 장치 수
- **대지별, 그 안의 구역별** — 면적(m²), 주 배관·가지 배관의 길이와 개수, 토출구 수, 유량(L/h·L/min), 배치에서 센 이음쇠(티·엘보·말단), 그 자리에 속한 입력·출력·로직 장치 수. 값이 0인 줄은 표시하지 않습니다.
- **배관 상세** — 주 배관·가지 배관 하나마다 한 줄: 번호, 길이, 그 배관에 달린 토출구 수, 유량
- 대지가 둘 이상이면 대지 선택기와 **필터 적용**으로 위 내용을 고른 대지만으로 좁힐 수 있습니다.

패널에서 대지·구역 이름을 클릭하면 지도가 그 도형으로 이동합니다. 면적은 m² 로 표시됩니다.

## 지도 잠금 { #map-lock }

지도 우측 상단 **잠금** 버튼을 클릭하면 지도 이동/줌을 잠급니다. 대시보드에 배치된 AoT 지도 위젯에서 실수로 지도가 이동되는 것을 방지합니다.


## 지도 삭제 { #deleting-a-map }

지도 위젯이 아직 그 지도를 보고 있으면 삭제가 거부되고, 어느 위젯인지
알려 줍니다. 위젯을 지우거나 다른 지도로 바꾼 뒤에 삭제하십시오.

지도를 지우면 그 안의 도형·시설도 함께 사라집니다. 예전에는 위젯이 그
지도를 보고 있어도 그냥 지워졌고, 남은 위젯은 오류 없이 **빈 지도**를
보여줬습니다 — 사용자가 원인을 알 방법이 없었습니다. 도형과 장치 참조는
데이터베이스가 연쇄 정리하지만, 위젯의 지도 참조는 그 정리가 닿지 않는
자리에 있습니다.

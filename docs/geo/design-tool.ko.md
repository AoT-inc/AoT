# 지도 디자인 도구

`/geo/design` 페이지는 농장을 지도 위에 배치하는 곳입니다 — 부지 경계를 그리고, 재배 구역을 나누고, 건물을 배치하고, 센서·밸브가 실제로 어디에 있는지 정확히 표시합니다. 여기서 그린 내용은 그대로 대시보드의 [AoT 지도](../Data-Viewing.md#widget-map) 위젯에 나타나므로, 위젯을 꾸미기 전에 이 페이지부터 제대로 설정해두는 게 좋습니다.

---

## 예시로 알아보기: 새 하우스 배치하기

바깥에서 안쪽 순서로 진행하는 전형적인 첫 작업입니다.

1. **Site(부지)** — **Site** 모드에서 전체 부지 둘레를 폴리곤으로 그립니다. 속성 패널에서 이름을 붙이면 그리는 즉시 자동 저장됩니다.
2. **Zone(구역)** — **Zone** 모드로 전환해 부지 경계 안쪽에 재배 구역(화단) 폴리곤을 그리고 이름을 붙입니다(예: "1동").
3. **Facility(시설)** — **Facility** 모드로 전환해 구역 안쪽에 건물 외곽선을 그립니다. 이름을 붙여 저장한 뒤 **시설 디자인** 버튼(또는 `/geo/facility`로 직접 이동)을 눌러 3D 설정을 진행합니다 — 이 부분은 [시설 관리](facility.md)를 참고하세요. 이 페이지에서는 외곽선을 그리는 것까지만 다룹니다.
4. **Equipment(설비)** — **Equipment** 모드로 전환해 펌프·밸브 몇 개와 그 사이를 잇는 배관을 추가합니다(아래 [Equipment 모드](#equipment) 참고 — 배관/관수 자동 생성 도구가 있습니다).
5. **장치** — 장치 모드(모드 패널에는 **A**로 표시됨)로 전환해 실제 입력/출력/함수 장치를 배치합니다(아래 [Device 모드](#device-a) 참고).
6. **대시보드에서 확인** — 이 지도를 가리키는 AoT 지도 위젯을 추가하면 방금 그린 도형·마커가 그대로 나타나고, 장치 마커를 클릭하면 실시간 값과 제어 버튼이 뜹니다.

이 순서를 강제하는 규칙은 없습니다(구역이 없는 상태에서 장치부터 배치해도 동작합니다). 다만 바깥→안쪽 순서로 그리면 구역을 그린 뒤에 배치한 설비·장치가 자동으로 그 구역에 연결되므로 더 편합니다 — 이 자동 연결이 정확히 어떻게 동작하고 무엇은 안 되는지는 [편집 모드](#editing-modes)를 참고하세요.

## 화면 구성

```
┌──────┬──────────────────────────────────┬────────────┐
│      │                                  │            │
│  좌측 │          지도 캔버스               │  설정      │
│  도구 │    (MapLibre GL 벡터 렌더링)       │  드로어    │
│  모음 │                                  │            │
│      │  ┌────────────────────────────┐  │  (모드별)  │
│      │  │ 모드 탭 (필지/구역/시설/…)   │  │            │
└──────┴──┴────────────────────────────┴──┴────────────┘
```

**모드 탭은 지도 아래 가로 막대**에, **그 모드의 설정은 지도 오른쪽 드로어**에 있습니다. 드로어는 지도를 덮지 않고 옆으로 밀어내므로, 설정을 만지는 동안에도 그 결과가 지도에 그대로 보입니다. 드로어를 연 채로 지도를 움직이거나 도형을 클릭할 수도 있습니다. 폰에서는 드로어가 화면 전체를 덮고, 위쪽 손잡이를 누르면 아래로 내려가 지도가 보입니다.

## 편집 모드 { #editing-modes }

지도 아래 모드 탭에서 편집 대상을 선택합니다 — **6가지 모드**가 있습니다: Site, Zone, Facility, 구획, Equipment, 그리고 Device(탭에는 "AoT device"의 줄임말인 **A**로 표시됩니다). 모드마다 그릴 수 있는 도형과 속성이 다릅니다. 탭을 누르면 그 모드의 설정 드로어가 함께 열립니다.

### Site (부지)

부지 최상위 경계를 정의합니다.

- **그리기**: 사각형, 원, 폴리곤.
- **속성**: 이름, 테마 색상, 불투명도 — 색상 변경은 자동 저장됩니다.
- **특수 기능**: VWorld/CSV 필지 가져오기(아래 [필지 가져오기](#parcel-import) 참고).

### Zone (구역)

부지 내 재배동·구획·관리 구역을 정의합니다.

- **그리기**: 사각형, 원, 폴리곤.
- **속성**: 이름, 테마 색상.

!!! 참고
    Zone을 그린다고 해서 그 안에 있는 Site와 자동으로 연결되지는 **않습니다** — 이 연결은 추적되지 않습니다. 반대 방향은 자동입니다: Zone이나 Site **안쪽에** 배치한 Equipment·Device는 자동으로 그 구역에 연결됩니다(아래 참고). 그래서 설비·장치를 배치하기 전에 구역부터 그려두는 순서가 더 수월합니다.

### Facility (시설)

물리적 건물(온실, 창고, 설비동)을 배치합니다.

- **그리기**: 선, 사각형, 원, 폴리곤, 마커, 라벨 — 건물 외곽선은 폴리곤으로 그립니다.
- **속성**: 이름, 테마 색상.
- **특수 기능**: 저장 후 **시설 디자인** 버튼(또는 `/geo/facility`)에서 3D 모델링, 공학 계산, 상위 구역 선택을 진행합니다 — 이 작업은 모두 그 페이지에서 이뤄지며 여기서는 하지 않습니다. [시설 관리](facility.md)를 참고하세요.

### 구획 { #plot }

**어디에 무엇이 있는가**를 기록합니다. 구역(Zone)이 "이 자리는 3-1 구역"이라면, 구획은 "그 3-1 구역의 이 부분에 3월 20일부터 상추가 있다"입니다.

- **그리기**: 사각형, 원, 폴리곤.
- **속성**: 종류, 대상, 품종, 구획 이름, 프로그램, 시작일, 예상 종료일, 색상.

**식생 전용이 아닙니다.** 구획에는 **종류**가 있습니다 — 식생 · 가축 · 시설 · 기타. 종류를 고르면 프로그램 선택지가 그 종류로 좁혀집니다.

**프로그램을 붙이면** 현재 단계·목표 환경·예상 종료일이 자동으로 따라옵니다. [관리 프로그램](programs.md)을 참고하세요.

!!! 참고 "구역과 달리 수명이 있습니다"
    구획은 끝나는 날이 있습니다 — 노지 두둑이면 3~9개월, 과수면 30년입니다. 그래서 다른 도형과 **다른 곳에 저장되며**, 종료해도 기록이 지워지지 않고 이력으로 남습니다. "이 자리에 최근 3년간 뭐가 있었나"(연작 장해·윤작 판단)에 답할 수 있는 근거가 됩니다.

**겹쳐 그려도 됩니다.** 간작·혼작은 정상이므로 구획끼리 겹치는 것을 막지 않습니다. 면적 비율의 합이 100%를 넘어도 오류가 아닙니다.

**상위 구역을 고르지 않습니다.** 그냥 그리면 되고, 어느 구역에 속하는지는 위치로 자동 판정됩니다 — 설비·장치와 같은 방식입니다.

#### 구역을 여러 구획으로 나누기 { #split }

한 구역을 몇 개로 갈라 심을 때, 조각을 하나씩 그리지 않고 **나누게** 할 수 있습니다. 구획 모드로 들어가면 분할 폼이 구획의 대상·품종 칸 위에 바로 나와 있습니다.

- **나눌 도형** — 지도에 이미 그려 둔 구역·대지 중에서 고릅니다. 아직 저장하지 않은 도형은 목록에 없습니다(먼저 저장하세요).
- **나누는 기준** — **등분**(몇 개로 자를지)이나 **띠 폭**(한 조각을 몇 cm 로 할지) 중 하나입니다. **등분에 1을 넣으면 나누지 않습니다** — 구역 전체가 구획 하나가 됩니다(가장자리 여백을 줬으면 그만큼 안으로 들어옵니다). 밭 하나를 통째로 한 작기로 쓸 때 이렇게 하면 됩니다. **띠 폭**을 고르면 "정확한 조각 수(선택)" 칸이 함께 나타납니다 — 비우면 지금까지처럼 그 폭으로 채울 수 있는 만큼 자동으로 개수가 정해지고, 채우면 정확히 그 개수만 그 폭으로 자르고 남는 치수는 양쪽 여백이 됩니다(균등분할이 아닙니다 — 예: "5줄만, 정확히 40cm 간격으로" 처럼 개수와 간격을 둘 다 직접 정할 때 씁니다).
- **방향** — **등분**을 고르거나, **띠 폭**에서 "정확한 조각 수"를 같이 채웠을 때만 보입니다(둘 다 "N개를 어느 방향으로 늘어놓을지"의 문제이기 때문입니다). **긴 변**(기본)은 조각이 밭의 긴 방향을 따르고, **짧은 변**은 그 반대쪽을 등분해 더 정방형에 가까운 조각을 냅니다. 두둑이 아니라 서로 다른 작물을 나눠 심을 구획이 목적이면 짧은 변이 편할 수 있습니다. **자유 각도**를 고르면 각도 슬라이더가 나타나 원하는 방향으로 직접 돌릴 수 있습니다 — 슬라이더를 움직이는 동안 구역 중심을 지나는 기준선이 지도 위에서 그 각도로 즉시 돌아가고, 잠깐 멈추면 분할 조각도 그 각도로 다시 그려집니다.
- **가장자리 여백** — 농기계가 돌 자리를 도형 안쪽으로 남깁니다. 필요 없으면 0 입니다.
- **구획별 폭 직접 조정** — 위 모드들은 모두 조각의 폭이 서로 같습니다. 이 토글을 켜면 조각마다 다른 폭을 줄 수 있습니다 — 이미 나온 균등 분할에서 시작해 조각마다 숫자 칸(m 단위)이 하나씩 나오고, 조각을 더하거나 뺄 수 있는 버튼도 함께 나옵니다(최소 2개). 방향은 이때도 그대로 적용됩니다 — 폭 목록은 각 조각의 두께만 정할 뿐, 자르는 축의 방향을 정하지는 않습니다. 마지막에 입력한 조각이 남는 자리보다 크면 거부하지 않고 들어가는 만큼 자동으로 줄이며, 아래 요약 줄에 그 사실을 알립니다. 지도의 점선 조각마다 번호가 붙어 입력칸과 맞춰 볼 수 있습니다.
- **대상·품종·구획 이름·시작일·색** — 만들어질 조각 전부에 같은 값이 들어갑니다. 구획 이름에는 조각 번호가 뒤에 붙습니다(`시험구 1`, `시험구 2`, …).

**값을 바꾸면 지도가 곧바로 따라옵니다.** 제안이 **점선**으로 그려지고, 폼 아래에 조각 수·조각 폭·길이 범위·방향이 뜹니다. 조각이 가늘고 길면(대략 4:1을 넘으면) 종횡비와 함께 경고로 뜹니다 — 방향을 짧은 변으로 바꿔 보라는 신호입니다. 미리보기를 따로 확정하는 단계는 없습니다 — 드로어가 지도를 가리지 않으므로 **화면에 보이는 것이 곧 제안**입니다. 마음에 들면 **구획 만들기**를 누르고, 아니면 그냥 드로어를 닫으면 됩니다(아무것도 저장되지 않습니다).

!!! 참고 "조각은 기본으로 밭의 긴 방향을 따릅니다"
    정북 기준으로 자르면 비정형 밭에서는 두둑이 밭을 비스듬히 가로질러 자투리만 생깁니다. 그래서 도형의 **가장 긴 변**을 따라 자르고, 비뚤어진 가장자리는 잘라냅니다. 조각마다 길이가 다른 것은 그 때문이고, 두둑으로 쓰기에 너무 짧은 조각(2m 미만)은 버립니다 — 버린 개수도 함께 표시됩니다. 띠 폭을 지정하는 두둑 분할에서는 고랑 방향이 실제 작업 방향과 맞아야 하므로 방향을 바꿀 수 없습니다.

#### 두둑 배치는 노트에 적습니다 { #bed-layout }

"여기 몇 줄 심을 수 있나"를 AI에게 물으면 **두둑 위에만 심는 실제 방식**으로 셉니다. 밭 전체에 균일하게 깔아 세면 실측에서 24% 과다추정이었습니다(폭 28.4m 기준: 균일 배치 71줄 → 두둑 배치 54줄).

그 배치를 **입력란이 아니라 구획 노트에 문장으로** 남깁니다. AI가 배치를 모르면 균일 배치 숫자를 조용히 내밀지 않고 **먼저 되묻고**, 정해진 내용을 노트로 적어 두라고 안내합니다. 다음 대화는 그 노트를 읽습니다.

!!! 참고 "왜 입력란이 아닌가"
    "두둑 폭"을 물으면 **고랑을 뺀 윗면**으로 답하는 사람과 **고랑까지 포함한 한 세트**로 답하는 사람이 갈립니다. 같은 밭이 `120+40`으로도 `160+0`으로도 기록되고, **에러 없이 두둑 수만 달라집니다.** 숫자 칸은 "어느 의미로 적었는지"를 담지 못합니다. 게다가 배치는 시작일 뿐이고 멀칭·지주·관수 관행이 뒤따르는데, 그걸 전부 칸으로 만들 수는 없습니다 — 그래서 노트가 있습니다.

AI에게 셈을 시킬 때 쓰는 값은 둘입니다.

- **두둑 간격** — 두둑 중심에서 다음 두둑 중심까지, **고랑을 포함한** 하나의 숫자입니다(120cm 두둑 + 40cm 고랑이면 `160`). 농부는 두둑과 고랑을 따로 세지 않으므로 하나로 묻는 편이 갈리지 않습니다.
- **두둑당 줄 수** — 작물에 따라 다릅니다. 고추는 한 줄, 상추·배추는 두세 줄입니다. 간격만으로는 줄 수를 알 수 없어 이 값이 함께 있어야 합니다.

두 값은 **함께** 줘야 합니다. 평평하게 심는 밭이라면 대신 줄 간격을 씁니다.

#### 온실 bay 의 작물 옮기기

기존에 시설(온실) bay 에 적어 둔 작물 이름은 백필 스크립트로 구획으로 옮길 수 있습니다. 관리자에게 문의하세요 — 기하는 그 시점의 모양을 **복사**해 오므로, 나중에 동 수를 바꿔도 과거 작기가 따라 움직이지 않습니다.

### Equipment (설비) { #equipment }

펌프·밸브·배관·관수 배치를 담당합니다. 이 모드는 세 개의 하위 탭으로 나뉩니다.

- **Device** — 물 공급(하천/저수조/펌프), 필터(디스크/스크린/모래), 밸브(유니온/어댑터/인라인/리듀서), Connection(석션/엘보/티/리듀서 — 별도 그리기 모드가 아니라 배관 이음쇠 항목입니다) 카테고리로 묶인 점 마커 카탈로그입니다. 항목을 고르고 지도를 클릭해 배치합니다.
- **Pipe(배관)** — **기준선(Reference Line)** 또는 **메인 배관(Main Pipe)**을 그리고 분기 간격·각도·오프셋을 설정한 뒤 **생성(Generate)**을 클릭하면, 구역 경계에 맞춰 잘린 평행 분기 배관을 자동으로 만들고 메인 배관과 교차하는 지점에서 분할해줍니다.
- **Irrigation(관수)** — 스프링클러 또는 점적(Drip) 중 선택하고 간격·반경·유량·압력을 설정한 뒤 **생성**을 클릭하면, 하나씩 배치하지 않아도 구역 전체에 살수 지점이나 이미터를 자동으로 배열합니다.

Zone이나 Site 폴리곤 안쪽에 배치한 설비는 자동으로 해당 구역에 연결됩니다 — 이 재확인은 지도를 불러올 때와 도형을 편집할 때 일어나므로, 방금 배치한 마커는 새로고침하거나 살짝 옮기기 전까지는 통계 패널에 구역 연결이 반영되지 않을 수 있습니다.

### Device (장치) { #device-a }

등록된 AoT 입력·출력·함수 장치의 실제 위치를 표시하고 지도에 연결합니다. 이 모드에도 하위 탭(Input/Output/Function)이 있습니다. 실제 작업 흐름은 다음과 같습니다.

1. **Selection list(선택 목록)**를 클릭해 실제 등록된 장치 목록을 엽니다(출력은 채널별로 표시).
2. 장치를 켜면 (지금 보고 있는 위치가 아니라) **현재 지도 화면의 중심**에 마커가 나타납니다. 이를 드래그해 실제 위치로 옮기면 새 위치가 자동 저장됩니다.
3. 장치를 끄면 마커가 제거됩니다.

**마커가 아니라 도형을 장치에 연결하기**: 이미 배치된 장치 마커를 클릭하면 "활성화"됩니다(색이 바뀌고 활성화됐다는 토스트 알림이 뜹니다) — 이 상태에서 다음에 그리는 도형은 종류에 상관없이 자동으로 그 장치에 연결됩니다(단순 도형이 아니라). 팬의 작동 범위나 특정 장치에 딸린 스프링클러 구역처럼, 장치의 위치 마커와는 별도로 그 장치에 연결된 영역을 그릴 때 사용하세요.

*특징:* [AoT 지도](../Data-Viewing.md#widget-map) 위젯의 대시보드 화면에서 장치 마커를 클릭하면 실시간 값과(출력의 경우) On/Off 제어가 표시됩니다 — 그래서 여기서 장치 위치를 정확히 배치하는 것이 중요합니다.

## 도구 모음

### 좌측 도구

| 아이콘 | 기능 |
|--------|------|
| + / − | 줌 인/아웃 |
| 전체화면 | 전체화면 전환 |
| 검색 | 주소/좌표 검색 |
| 내 위치 | GPS 현재 위치 이동 |
| 초기화 | 기본 위치로 복귀 |

### 그리기 도구

사용 가능한 도구는 모드에 따라 다릅니다: Site·Zone 모드는 **사각형, 원, 폴리곤**을, Facility·Equipment·Device 모드는 여기에 더해 **선, 마커, 라벨**을 제공합니다. 그리기 도구에는 키보드 단축키가 없으며 도구 모음 버튼으로만 조작합니다.

- **편집(Edit)** — 기존 도형의 꼭짓점을 드래그해 모양을 바꿉니다.
- **삭제(Delete)** — 도형을 클릭해 제거합니다. 도형이 겹쳐 있으면 클릭할 때마다 커서 아래에서 가장 위에 있는 도형 하나만 삭제되므로, 아래 도형을 지우려면 다시 한번 클릭하세요.

## 피처 저장

### 자동 저장

도형을 그리거나 편집하거나 삭제하는 즉시 자동으로 저장됩니다 — 별도의 "확정" 단계는 없습니다. 변경 사항이 정말 저장됐는지 확인하고 싶다면 페이지를 새로고침해보는 것이 확실한 방법입니다.

### 수동 저장

상단 **Save** 버튼을 누르면 현재 상태 전체를 강제로 저장합니다. 이 버튼에는 키보드 단축키가 없습니다.

## 필지 가져오기 { #parcel-import }

한국 토지 데이터(VWorld)를 이용해 부지 경계를 빠르게 가져올 수 있습니다.

### 주소로 가져오기

1. 상단 도구에서 **필지 가져오기** 버튼 클릭
2. 주소 입력 후 검색 (VWorld PNU API 사용)
3. 결과 목록에서 해당 필지 선택
4. **부지로 저장** 클릭 → Site 피처 자동 생성

### CSV 일괄 가져오기

여러 필지를 한번에 가져올 때 사용합니다.

CSV 형식:
```csv
address,name
경기도 화성시 송산면 ...,1번 온실 부지
경기도 화성시 송산면 ...,2번 온실 부지
```

1. **필지 가져오기 → CSV 가져오기** 선택
2. CSV 파일 업로드
3. 미리보기 확인 후 **가져오기** 실행

자세한 내용은 [필지 가져오기 상세](parcel-import.md)를 참고하세요.

## 레이어 제어

우측 상단 **레이어** 패널에서 표시할 레이어를 켜고 끕니다.

- **기본 레이어**: 등록된 GIS 레이어 제공자 중 선택
- **오버레이**: Site, Zone, Facility, Device 도형을 각각 표시/숨김
- **기상 레이어**: 등록되어 있다면 RainViewer 레이더, OpenWeather 오버레이

새 레이어 제공자를 등록하려면 [GIS 레이어](layers.md)를 참고하세요.

## 지도 잠금

지도 우측 상단 **잠금** 버튼을 클릭하면 지도 이동/줌을 잠급니다. 대시보드에 배치된 AoT 지도 위젯에서 실수로 지도가 이동되는 것을 방지합니다.


## 지도 삭제

지도 위젯이 아직 그 지도를 보고 있으면 삭제가 거부되고, 어느 위젯인지
알려 줍니다. 위젯을 지우거나 다른 지도로 바꾼 뒤에 삭제하십시오.

지도를 지우면 그 안의 도형·시설도 함께 사라집니다. 예전에는 위젯이 그
지도를 보고 있어도 그냥 지워졌고, 남은 위젯은 오류 없이 **빈 지도**를
보여줬습니다 — 사용자가 원인을 알 방법이 없었습니다. 도형과 장치 참조는
데이터베이스가 연쇄 정리하지만, 위젯의 지도 참조는 그 정리가 닿지 않는
자리에 있습니다.

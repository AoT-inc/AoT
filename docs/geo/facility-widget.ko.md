# AoT_facility 위젯

`AoT_facility` 위젯은 대시보드에 시설(건물)의 3D 뷰와 실내외 환경 데이터를 함께 표시하는 위젯입니다.

---

## 위젯 추가

1. 대시보드에서 **Add Widget → AoT_facility** 선택
2. 설정에서 표시할 시설 선택 (`/geo/facility`에서 등록된 시설)
3. **Save** 클릭

---

## 화면 구성

### A. 3D 뷰

Three.js로 렌더링된 시설 건물 모델입니다.

- **마우스 왼쪽 버튼 드래그**: 회전
- **마우스 오른쪽 버튼 드래그**: 이동
- **스크롤**: 줌
- **Preset 배지**: 현재 적용된 환경 프리셋 표시
- **Structure 배지**: `단동` 또는 `연동` 구조 표시

3D 모델은 `/geo/facility` 에서 설정한 외피 파라미터(베이 치수, 피복 자재 등)에 따라 자동 생성됩니다.

### B. 환경 데이터 패널

바인딩된 센서의 실시간 값을 6개 셀에 표시합니다.

| 셀 | 데이터 | 단위 |
|----|--------|------|
| 실내 온도 | 실내 온도 센서 | °C |
| 실내 습도 | 실내 습도 센서 | %RH |
| 실내 CO₂ | CO₂ 센서 | ppm |
| 실외 온도 | 기상 데이터 또는 외부 센서 | °C |
| 풍속/풍향 | 기상 데이터 또는 풍속 센서 | m/s |
| 일사량 | 기상 데이터 또는 일사 센서 | W/m² |

값이 없는 경우 `—` 로 표시됩니다.

### C. AI 조언 패널 (선택)

설정에서 **Show AI Advice** 활성화 시 표시됩니다.

- 긴급도 색상: **빨간** (즉시 조치) / **주황** (주의) / **초록** (정상)
- AI가 감지한 이상 징후 또는 최적화 제안

---

## 위젯 설정 옵션

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| Facility | 표시할 시설 선택 | — |
| Refresh Period | 환경 데이터 갱신 주기 (초) | 30 |
| Show AI Advice | AI 조언 패널 표시 | Off |

---

## 데이터 갱신

위젯은 설정된 주기마다 `/api/geo/facility/<uuid>/integration` 엔드포인트를 호출하여 환경 데이터를 갱신합니다.

- 센서 바인딩이 없는 시설은 `—` 만 표시됩니다.
- 외부 기상 데이터(Open-Meteo)는 시설 위치의 GPS 좌표를 기반으로 자동으로 가져옵니다.

---

## 시설 미등록 상태

시설이 아직 `/geo/facility`에 등록되지 않은 경우 위젯에 "No facilities registered" 메시지가 표시됩니다.

등록 방법:
1. `/geo/design` → Facility 모드 → 건물 폴리곤 그리기 및 저장
2. `/geo/facility` → 해당 시설 선택 → 외피 설정 → Save

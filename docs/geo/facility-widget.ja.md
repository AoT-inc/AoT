# AoT_facility ウィジェット

`AoT_facility` ウィジェットは、施設の3Dビュー、リアルタイムの環境値、そして統合環境制御（IEC）機能が連携されていれば目標値の編集とアクチュエーター制御までを、ダッシュボード上にまとめて表示します。

---

## ウィジェットを追加する

1. ダッシュボードで **Add Widget → AoT Facility** を選択します。
2. 設定で **IEC Function** を選択します — 施設そのものではなく、`env_coordinator` 機能を選びます。施設はその機能の設定から自動的に特定されます。
3. **IEC Function** を空欄にすると、有効化されている最初の `env_coordinator` 機能が自動的に選ばれます。該当する機能が一つもない場合は、最も最近更新された施設にフォールバックします（この場合は表示専用です — 連携された機能がないと、ステータスストリップ・目標値・制御はいずれも表示されません）。
4. **Save** をクリックします。

---

## 画面レイアウト

### 0. ステータスストリップ

**Show Status Strip** がオンのとき表示されます。`/api/aot/facility/<uuid>/status` を5秒ごとに取得するバッジです。

| レベル | 意味 |
|------|------|
| `IDLE` | 連携されたIEC機能がない、または報告する内容がない |
| `ACTIVE` | 連携された機能が直近の制御サイクルを実行した |
| `WARN` | 連携された機能が有効化されていない、または直近のサイクル報告が途絶えている（stale） |
| `EMERGENCY` | センサーの状態が悪化 — 施設のセンサーの半分未満しか正常応答していない |

バッジの横には、その状態になっている理由と、稼働中／全体のアクチュエーター数を含むタイムスタンプが表示されます。

### A. 3Dビュー

Three.jsでレンダリングされた建物モデルです。`/geo/facility` で設定した外皮パラメータ（棟の寸法、被覆資材など）から自動生成されます。

- **右クリックドラッグ**: 回転
- **左クリックドラッグ**: 平行移動
- **スクロール**: ズーム
- **Presetバッジ**: 施設の構造プリセット
- **「connected × N」バッジ**: 複数棟が連結された（連棟）構造のとき表示
- **「double layer」バッジ**: 外皮が二重被覆のとき表示

### B. 環境

リアルタイムの値を表示する7つのセルです。制御モードで目標値編集がオン、かつ閲覧者に制御権限（`edit_settings`）がある場合、最初の4つはクリックして目標値編集画面を開けます。

| セル | 目標値を設定できるか |
|----|----|
| VPD | できる |
| 室内温度 | できる |
| 室内湿度 | できる |
| CO₂ | できる |
| 屋外温度 | できない — 気象データまたは外部センサー |
| 風速 | できない — 気象データまたは風向風速計 |
| 日射量 | できない — 気象データまたはPARセンサー |

データがないセルには `—` が表示されます。編集可能なセルには現在の目標値も表示されます — これは手動での上書きがあればその値、なければ連携された[プログラム](programs.md)の生育段階が示す値、つまり制御が実際に従っている値（effective target）そのものです。別に保存されていて制御と食い違いかねない数値ではありません。

### D. アクチュエーター制御

**Show Actuator Grid** がオンのとき表示されます。施設に紐づくアクチュエーターのスライダー・トグルのグリッドで、**読み取り専用の表示ではなく、実際に動作する制御面です**。**Show Emergency Stop** を有効にすると、ここに「ALL STOP」ボタンが表示されます。

### E. AIアドバイス

!!! warning "実験的機能 — 本番環境ではオフのままにする"
    このパネルは現在、**ハードコードされたテキストのモック（仮の）デモカード**を表示するだけで、実際のアドバイスではありません。ただし **Approve** ボタンは `/api/geo/facility/<uuid>/apply` を通じて実際のアクチュエーター命令を送信します。実際のアドバイザーのバックエンドが接続されるまでは **Show AI Advice** を有効にしないでください。

## ウィジェット設定

### General

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| Period (seconds) | リアルタイムデータの更新間隔。`0`で自動更新を無効化。 | 60 |
| IEC Function | 連携する `env_coordinator` 機能。施設はここから自動的に決まります。 | (自動選択) |
| Show AI Advice (§ E) — EXPERIMENTAL | 上記の警告を参照 — 本番環境では有効にしないでください。 | Off |

### Integrated Environment Control (IEC)

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| Show Status Strip (§ 0) | 緊急／警告／稼働中／待機のバッジ。制御モードのみ。 | On |
| Show Setpoints (§ B/C) | クリックで開く温度／湿度／CO₂／VPDの目標値編集。制御モードのみ。 | On |
| Show Actuator Grid (§ D) | アクチュエーターのスライダー・トグル。制御モードのみ。 | On |
| Show Emergency Stop | アクチュエーターグリッドの「ALL STOP」ボタン。 | Off |

### 3D Rendering

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| Render Mode | `Default`（半透明の被覆）・`Solid`（不透明、オーバードロー削減）・`Wireframe`（輪郭線のみ）・`Performance`（モバイル向けの簡易シェーディング＋低解像度）から選択。 | Default |

### Sensor Labels

3Dシーン上の各センサーの横にリアルタイムの測定値を表示するラベルです。

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| Show Sensor Labels | | On |
| Max Channels Shown | ラベル1つに表示する値の数（1〜5）。超過分は「+」に折りたたまれます。 | 1 |
| Decimals | ラベルの値の小数点以下桁数（0〜3）。 | 1 |
| Label Size (em) | 文字サイズ（0.5〜2.0）。 | 0.85 |
| Label Background | CSSカラー。 | `rgba(15,23,42,0.78)` |
| Label Text Color | CSSカラー。 | `#f8fafc` |
| Vertical Offset (m) | センサーの上、ラベルを固定する高さ（0.0〜2.0）。 | 0.25 |
| Label Opacity | 0.0〜1.0。 | 0.7 |
| Enable Sensor Popup | ラベルをクリックすると直近24時間のグラフがポップアップ表示されます。 | On |

## データの更新

ウィジェットは設定された **Period** ごとに `/api/geo/facility/<uuid>/integration` を呼び出して環境データを更新し、ステータスストリップがオンの場合は **Period とは無関係に** `/api/aot/facility/<uuid>/status` を5秒ごとに呼び出します。

- センサーが割り当てられていない施設は `—` のみを表示します。
- 外部の気象データ（Open-Meteo）は、施設のGPS座標に基づいて自動的に取得されます。

---

## 施設がない場合

- **IEC Functionは選んだが、その機能に施設が設定されていない、または施設が一つも登録されていない場合**: 「No facility selected. Register one at `/geo/facility`.」
- **システム全体に登録された施設が一つもない場合**: 「No facilities registered.」

施設の登録方法:

1. `/geo/design` → Facilityモード → 建物のポリゴンを描いて保存
2. `/geo/facility` → 施設を選択 → 外皮を設定 → Save

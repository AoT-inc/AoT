# AoT_facility ウィジェット

`AoT_facility` ウィジェットは、施設の3Dビュー、リアルタイムの環境値、そして統合環境制御（IEC）機能が連携されていれば目標値の編集とアクチュエーター制御までを、ダッシュボード上にまとめて表示します。

---

## ウィジェットを追加する { #adding-the-widget }

1. ダッシュボードで **ウィジェットを追加 → AoT 施設** を選択します。
2. 設定で **IEC機能** を選択します — 施設そのものではなく、`env_coordinator` 機能を選びます。施設はその機能の設定から自動的に特定されます。
3. **IEC機能** を空欄にすると、有効化されている最初の `env_coordinator` 機能が自動的に選ばれます（有効化されたものがなければ名前順で最初の機能）。`env_coordinator` 機能が一つもない場合、または選んだ機能に施設が設定されていない場合は、最も最近更新された施設にフォールバックします。連携された機能がないとき、ステータスストリップは "No IEC function linked to this facility" という理由とともに `IDLE` を表示します（センサーの状態が悪ければより高いレベル）が、目標値の編集とアクチュエーターパネルはそのまま動作します — どちらも施設に直接作用するためです。
4. **保存** をクリックします。

## 画面レイアウト { #screen-layout }

### 0. ステータスストリップ { #0-status-strip }

**ステータスストリップを表示** がオンのとき表示されます。`/api/aot/facility/<uuid>/status` を5秒ごとに取得するバッジです。

| レベル | 意味 |
|------|------|
| `IDLE` | 連携されたIEC機能がない、または報告する内容がない |
| `ACTIVE` | 連携された機能が直近の制御サイクルを実行した、または稼働中のアクチュエーターが1つ以上ある |
| `WARN` | 連携された機能が有効化されていない、サイクル周期の3倍（最低5分）以内にサイクル報告がない、施設のセンサーの一部が応答していない、VPDが目標から0.15 kPa以上外れている、またはCO₂が目標より10 %以上高い |
| `EMERGENCY` | 施設のセンサーの半分未満しか正常応答していない、VPDが目標から0.45 kPa以上外れている、または室内温度が安全限界を外れている |
| `ERR` | ステータス取得そのものが失敗 — タイムスタンプの位置に「接続エラー」が表示される |

バッジの横には、連携された機能の名前、その状態になっている理由と、稼働中／全体のアクチュエーター数を含むタイムスタンプが表示されます。

### A. 3Dビュー

Three.jsでレンダリングされた建物モデルです。`/geo/facility` で設定した外皮パラメータ（棟の寸法、被覆資材など）から自動生成されます。

- **右クリックドラッグ**: 回転
- **左クリックドラッグ**: 平行移動
- **スクロール**: ズーム
- **Presetバッジ**: 施設の構造プリセット
- **「連棟 xN」バッジ**: 複数棟が連結された（連棟）構造のとき表示
- **「二重被覆」バッジ**: 外皮が二重被覆のとき表示
- **レイヤーボタン**: 外皮・窓・空調・センサー・照明・灌水の表示をオン／オフ
- **下端**: ドラッグしてビューの高さを変更。高さとカメラ角度はこのブラウザに記憶されます

### B. 環境 { #b-environment }

リアルタイムの値を表示する7つのセルです。**設定値を表示** がオン、かつ閲覧者に制御権限（`edit_settings`）がある場合、そのうち2つはクリックして範囲の編集画面を開けます。

| セル | 範囲を編集できるか |
|----|----|
| VPD | できない — 目標は連携された[プログラム](programs.md)で設定する |
| 室内温度 | できる — 目安範囲とハード安全限界 |
| 室内湿度 | できる — 目安範囲とハード安全限界 |
| CO₂ | できない — 目標は連携された[プログラム](programs.md)で設定する |
| 屋外温度 | できない — 気象データまたは外部センサー |
| 風 | できない — 気象データまたは風向風速計 |
| ソーラー | できない — 気象データまたはPARセンサー |

データがないセルには `—` が表示されます。VPDとCO₂のセルには現在の目標値も表示されます — これは制御が連携されたプログラムの生育段階から読むのと同じ方法で求めた値（effective target）で（その段階の目標が曲線に従う場合は「曲線に従います」と表示）、別に保存されていて制御と食い違いかねない数値ではありません。室内温度と室内湿度のセルは、目標値ではなくそれぞれの目安範囲を表示します。4つのセルはいずれも、値がその目標や範囲からどれだけ外れているかで色が付きます。

編集画面にはセルごとに2組あります — VPDの目標を温度と湿度に分解するときに収まる幅である **目安範囲** と、目標に関わらず保護動作を強制する **ハード安全限界** です。目標はここでは設定できません — 目標をこの編集画面から送ると拒否され、プログラムで設定する値であることが示されます。

### D. アクチュエーター制御 { #d-actuator-control }

**アクチュエーターグリッドを表示** がオンのとき表示されます。施設に紐づくアクチュエーターを種類別にまとめて表示します — **窓**、**保温**、**遮光**、**灌水**、**その他**（アクチュエーターのないグループは非表示、一つもなければ「登録されたアクチュエーターがありません」と表示）。制御権限（`edit_settings`）を持つ閲覧者にとっては、**読み取り専用の表示ではなく、実際に動作する制御面です**。各行の操作方法はアクチュエーターの駆動方式によって異なります。

| アクチュエーター | 操作 |
|------------------|------|
| 位置型（例: 開閉ペアのモーター） | 0〜100 % スライダー。トラック上の点が現在位置を示し、その上に最後の目標値（誰が設定したかにより **手動** または **システム**）と **現在位置** が表示されます。 |
| PWM | 0〜100 % デューティ比スライダー。 |
| オン/オフ | **ON** / **OFF** ボタン。 |

スライダーは指を離したとき、ボタンは押したときにコマンドを送信します。安全ゲートが作動している間 — たとえば強風時 — ゲートが強制する値と矛盾するコマンドは拒否され、アクチュエーターはそのままの位置にとどまります。ウィジェットにメッセージは出ないので、行が壊れていると判断する前にゲートを確認してください。ゲートと矛盾しないコマンド（風速ゲート中に暖房をオンにするなど）は手動適用としてそのまま実行されます。行のハンドルをドラッグすると同じグループ内で順序を変えられ、順序は施設ごとに保存されます。`edit_settings` 権限のない閲覧者には同じ行が読み取り専用で表示され、スライダー・ボタン・ハンドルは出ません。値は **周期 秒** ごとに更新されます。

**緊急停止を表示** がオンのとき、グリッドの下に **緊急停止** ボタンが置かれます — 既定はオフで、制御権限を持つ閲覧者にだけ表示されます。押すと確認を求めたうえで、この施設のすべてのアクチュエーターを安全状態に送ります。自動制御も一緒に止まります — 連携された有効な機能には、その機能の **緊急停止** をそのまま送り、次の制御サイクルを60秒間保留してアクチュエーターをすぐに戻せないようにします。連携された有効な機能がない場合は、出力を直接安全状態に送ります。結果は、到達したアクチュエーター数とともにメッセージで表示されます（[緊急停止と安全状態](../ai/env-control.md#emergency-stop)）。

### E. AIアドバイス { #e-ai-advice }

!!! warning "実験的機能 — 本番環境ではオフのままにする"
    このパネルは現在、**ハードコードされたテキストのモック（仮の）デモカード**を表示するだけで、実際のアドバイスではありません。ただし **承認して適用** ボタンは `/api/geo/facility/<uuid>/apply` を通じて実際のアクチュエーター命令を送信します。実際のアドバイザーのバックエンドが接続されるまでは **AIアドバイスを表示** を有効にしないでください。

## ウィジェット設定 { #widget-settings }

### 一般

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| 周期 秒 | リアルタイムデータの更新間隔。`0`で自動更新を無効化。 | 60 |
| IEC機能 | 連携する `env_coordinator` 機能。施設はここから自動的に決まります。 | (自動選択) |
| AIアドバイスを表示 (§ E) — 実験的機能 | 上記の警告を参照 — 固定文のデモカードで、カードがアクチュエーター命令を送ることはありません。 | Off |

### 統合環境制御 (IEC)

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| ステータスストリップを表示 (§ 0) | 緊急／警告／稼働中／待機のバッジ。 | On |
| 設定値を表示 (§ C) | § B のセルをクリックして開く、温度・湿度の目安範囲と安全限界の編集。`edit_settings` 権限が必要。 | On |
| アクチュエーターグリッドを表示 (§ D) | アクチュエーター制御パネル。 | On |
| 緊急停止を表示 | アクチュエーターグリッド（§ D）の下の ALL STOP ボタン。`edit_settings` 権限が必要。 | Off |

### 3Dレンダリング

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| レンダーモード | **デフォルト (半透明)**（半透明の被覆）・**単色 (不透明)**（不透明、オーバードロー削減）・**ワイヤーフレーム**（輪郭線のみ）・**パフォーマンス (モバイル)**（モバイル向けの簡易シェーディング＋低解像度）から選択。 | デフォルト (半透明) |

### センサーラベル

3Dシーン上の各センサーの横にリアルタイムの測定値を表示するラベルです。

| オプション | 説明 | デフォルト |
|--------|-------------|---------|
| センサーラベルを表示 | | On |
| 最大表示チャンネル数 | ラベル1つに表示する値の数（1〜5）。超過分は「+」に折りたたまれます。 | 1 |
| 小数点桁数 | ラベルの値の小数点以下桁数（0〜3）。 | 1 |
| ラベルサイズ (em) | 文字サイズ（0.5〜2.0）。 | 0.85 |
| ラベル背景 | CSSカラー。 | `rgba(15,23,42,0.78)` |
| ラベル文字色 | CSSカラー。 | `#f8fafc` |
| 垂直オフセット (m) | センサーの上、ラベルを固定する高さ（0.0〜2.0）。 | 0.25 |
| ラベルの不透明度 | 0.0〜1.0。 | 0.7 |
| センサーポップアップを有効化 | ラベルをクリックすると直近24時間のグラフがポップアップ表示されます。 | On |

## データの更新 { #data-refresh }

ウィジェットは最初の表示時に一度、その後は設定された **周期 秒** ごとに（ブラウザのタブが非表示の間はスキップ）`/api/aot/facility/<uuid>/runtime` を呼び出して環境値とアクチュエーターの状態を更新し、ステータスストリップがオンの場合は **周期とは無関係に** `/api/aot/facility/<uuid>/status` を5秒ごとに呼び出します。

アクチュエーターの状態は常にライブで読み取られます。環境値は、連携された機能が有効でサイクルを報告している間はその機能の直近の制御サイクルから取得されるため、そのサイクルと同じ新しさです。そうした機能がない場合は、応答を待たせずに背後で作成されます — ダッシュボードを開いた直後はセルがまだ `—` のことがあり、次の取得で埋まります。

- センサーが割り当てられていない施設は `—` のみを表示します。
- 屋外の値は施設の屋外センサー・気象Inputから取得されます。設定されていない項目は共有の外部環境コンテキストで補われ、そのコンテキストが10分以内の場合のみ使われます。

## 施設がない場合 { #no-facility }

選んだIEC機能に施設が設定されていない場合は最も最近更新された施設にフォールバックするため、案内メッセージは **システムに施設が一つも登録されていないときだけ** 表示されます: 「施設が選択されていません。次の場所で登録してください: `/geo/facility`.」

施設の登録方法:

1. `/geo/design` → **施設** モード → 建物のポリゴンを描いて保存
2. `/geo/facility` → 施設を選択 → 外皮を設定 → **施設を保存**

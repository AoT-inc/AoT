# GIS 入門

初めてAoT GISシステムを使う方向けのクイックセットアップガイドです。以下の手順に沿って進めれば、10分以内にデバイスの位置を示す地図を表示できます。

---

## 前提条件

- AoTがインストール済みで、管理者アカウントでログインしていること
- Inputデバイスが1台以上登録されていること（デバイスがなくても地図自体は作成できます）

---

## Step 1: グローバルGIS設定

メニュー **設定 → 地図**（`/geo/design`）を開き、ページタイトルの下の **設定** ボタンをクリックすると **GIS設定** ウィンドウが開きます。以前のアドレス `/geo/setting` はこのページへ転送されるだけです。

### デフォルトの位置を設定する

1. ウィンドウを開く前に、デフォルトとして表示したい位置とズームまで地図を動かしておきます（検索バーに住所を入力しても構いません）。
2. ウィンドウの **デフォルト開始位置** で **位置情報を取得** をクリックすると、現在の表示の **緯度**・**経度**・**ズームレベル** が入力されます。値を直接入力することもできます。
3. **保存** をクリックします。

### テーマカラー（任意）

**デザインテーマ設定** で階層ごとの色を変更できます。

| 要素 | デフォルト | 説明 |
|---------|---------|-------------|
| サイトの色 | 赤系 | サイト境界の色 |
| ゾーンの色 | 緑系 | ゾーンの色 |
| 施設色 | グレー | 施設建物の色 |
| 機器色 | 青系 | 機器の色 |
| デバイスの色 | 紫系 | AoTデバイスマーカーの色 |

---

## Step 2: 地図レイヤーを登録する（任意）

標準のOSM以外に航空写真や国内地図が必要な場合は、GISレイヤーを登録します。

メニュー **設定 → GIS入力** を開くか、`/geo/layer` にアクセスします。

**例: VWorld（韓国の地籍図・航空写真）を追加する場合:**

1. ページ上部の **GISサービスを選択** ドロップダウンから `VWorld` を選択します。
2. **追加** をクリックします。
3. 新しく作成された項目の**設定（歯車）アイコン**をクリックします。
4. VWorldのAPIキーを入力して保存します。
5. **有効化** をクリックして有効化します。

詳細は [GIS Layer Management（GISレイヤー管理）](layers.md) を参照してください。

---

## Step 3: 最初の地図デザインを作成する

メニュー **設定 → 地図** を開くか、`/geo/design` にアクセスします。

### 新しい地図を作成する { #create-a-new-map }

1. **地図デザイン** の地図ドロップダウンで **新しい地図を作成** を選ぶと、新しい地図がすぐに作成されます。
2. **編集** ボタンで地図名を変更します。

### サイト境界を描く

1. 地図下のモードタブで **サイト** モードを選択します。
2. 描画ツールからポリゴンを選択します。
3. 地図をクリックして頂点を配置し、最後の点を最初の点につなげてポリゴンを完成させます。
4. プロパティパネルでサイト名を入力します。図形は描いた時点で自動保存されます。

**より速い方法 — VWorldの筆地インポートを使う:**

1. サイト設定ドロワーで **住所から追加** 横の **検索** ボタンをクリックします。
2. 住所を入力して **検索** をクリックします。
3. プレビューで見つかった筆地を確認します。
4. **サイトとして保存** をクリックします。

### ゾーンを設定する

1. **ゾーン** モードに切り替えます。
2. サイトの内側にゾーンのポリゴンを描きます。
3. ゾーン名（例:「1棟」「栽培ゾーンA」）を入力します。

---

## Step 4: デバイスを配置する

1. モードタブでデバイスモード（**A**）に切り替えます。
2. **機器の種類** で **入力**・**出力**・**機能**・**デバイス** のいずれかを選び、**選択リスト** の **開く** ボタンをクリックします。
3. 配置したいデバイスのスイッチをオンにすると、現在の地図表示の中心にマーカーが表示されます。
4. マーカーをデバイスが実際に設置されている場所までドラッグします。新しい位置は自動保存されます。

詳しくは [Design Tool — Deviceモード](design-tool.md#device-a) を参照してください。

---

## Step 5: ダッシュボードウィジェットを追加する

1. ダッシュボードに移動します。
2. **ウィジェットを追加 → AoT マップ** を選択します。
3. ウィジェット設定の **地図を選択** で、Step 3で作成した地図を選びます。
4. **保存** をクリックします。

地図上にデバイスマーカーが表示されます。マーカーをクリックすると、リアルタイムの値と制御スイッチが表示されます。

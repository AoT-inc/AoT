# GIS 시작하기

처음 AoT GIS 시스템을 사용하는 분을 위한 빠른 설정 가이드입니다. 아래 순서대로 따라하면 10분 안에 장치 위치가 표시되는 지도를 만들 수 있습니다.

---

## 사전 요구 사항

- AoT 설치 완료 및 관리자 계정 로그인
- 하나 이상의 Input 장치 등록 (장치가 없어도 지도는 만들 수 있습니다)

---

## 1단계: 전역 GIS 설정

메뉴 **설정 → 지도**(`/geo/design`)로 이동해 페이지 제목 아래 **설정** 버튼을 클릭하면 **지리 정보 설정** 창이 열립니다. 예전 주소 `/geo/setting`은 이 페이지로 넘겨 줄 뿐입니다.

### 기본 위치 설정

1. 창을 열기 전에 지도를 기본으로 보여 줄 위치와 줌으로 옮겨 둡니다(검색창에 주소를 입력해도 됩니다).
2. 창의 **기본 시작 위치**에서 **위치 가져오기** 버튼을 클릭하면 현재 화면의 **위도**·**경도**·**줌 레벨**이 채워집니다. 값을 직접 입력해도 됩니다.
3. **저장** 버튼을 클릭합니다.

### 테마 색상 (선택)

**디자인 테마 설정**에서 계층별 색상을 바꿀 수 있습니다.

| 요소 | 기본값 | 설명 |
|------|--------|------|
| 대지 색상 | 빨간계열 | 대지 경계 색상 |
| 구역 색상 | 초록계열 | 구역 색상 |
| 시설 색상 | 회색 | 시설 건물 색상 |
| 장비 색상 | 파란계열 | 설비 색상 |
| 장치 색상 | 보라계열 | AoT 장치 마커 색상 |

---

## 2단계: 지도 레이어 등록 (선택)

기본 OSM 지도 외에 항공사진이나 국내 지도가 필요하면 GIS 레이어를 등록합니다.

메뉴 **설정 → 지리 정보 입력** 또는 `/geo/layer`로 이동합니다.

**VWorld(국내 지적도/항공)를 추가하는 예:**

1. 페이지 위쪽 **GIS 서비스 선택** 드롭다운에서 `VWorld`를 선택합니다.
2. **추가** 버튼을 클릭합니다.
3. 생성된 항목 오른쪽 **설정(기어 아이콘)**을 클릭합니다.
4. VWorld API 키를 입력하고 저장합니다.
5. **활성화** 버튼으로 활성화합니다.

자세한 내용은 [GIS 레이어 관리](layers.md)를 참조하세요.

---

## 3단계: 첫 번째 지도 디자인

메뉴 **설정 → 지도** 또는 `/geo/design`으로 이동합니다.

### 새 지도 만들기 { #create-a-new-map }

1. **지도 디자인**의 지도 선택 드롭다운에서 **새 지도 생성**을 선택하면 새 지도가 바로 만들어집니다.
2. **편집** 버튼을 클릭해 지도 이름을 바꿉니다.

### 대지 경계 그리기

1. 지도 아래 모드 탭에서 **대지** 모드를 선택합니다.
2. 그리기 도구에서 폴리곤을 선택합니다.
3. 지도 위에서 클릭하여 대지 꼭짓점을 찍고, 마지막 점을 처음 점에 연결하여 완료합니다.
4. 속성 패널에서 대지 이름을 입력합니다. 도형은 그리는 즉시 자동 저장됩니다.

**VWorld 필지 가져오기를 사용하면 더 빠릅니다:**

1. 대지 설정 드로어에서 **주소로 추가** 옆의 **검색** 버튼을 클릭합니다.
2. 주소를 입력하고 **검색**을 클릭합니다.
3. 미리보기에서 찾은 필지를 확인합니다.
4. **대지로 저장** 버튼을 클릭합니다.

### 구역 설정

1. **구역** 모드로 전환합니다.
2. 대지 안에 구역 폴리곤을 그립니다.
3. 구역 이름(예: "1동", "재배구역A")을 입력합니다.

---

## 4단계: 장치 배치

1. 모드 탭에서 장치 모드(**A**)로 전환합니다.
2. **장치 종류**에서 **입력**·**출력**·**함수**·**장치** 중 하나를 고른 뒤, **선택 목록**의 **열기** 버튼을 클릭합니다.
3. 목록에서 배치할 장치의 스위치를 켜면 현재 지도 화면의 중심에 마커가 나타납니다.
4. 마커를 장치가 실제로 있는 위치로 드래그합니다. 새 위치는 자동 저장됩니다.

자세한 내용은 [디자인 도구 — 장치 모드](design-tool.md#device-a)를 참고하세요.

---

## 5단계: 대시보드 위젯 추가

1. 대시보드로 이동합니다.
2. **위젯 추가 → AoT 지도**를 선택합니다.
3. 위젯 설정의 **지도 선택**에서 3단계에서 만든 지도를 고릅니다.
4. **저장**합니다.

지도 위에 장치 마커가 표시되고, 마커를 클릭하면 실시간 값과 제어 스위치가 나타납니다.

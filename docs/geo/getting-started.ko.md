# GIS 시작하기

처음 AoT GIS 시스템을 사용하는 분을 위한 빠른 설정 가이드입니다. 아래 순서대로 따라하면 10분 안에 장치 위치가 표시되는 지도를 만들 수 있습니다.

---

## 사전 요구 사항

- AoT 설치 완료 및 관리자 계정 로그인
- 하나 이상의 Input 장치 등록 (장치가 없어도 지도는 만들 수 있습니다)

---

## 1단계: 전역 GIS 설정

메뉴 **Gear → Configure → GIS Settings** 또는 `/geo/setting`으로 이동합니다.

### 기본 위치 설정

1. 지도에서 원하는 위치로 이동하거나 검색창에 주소를 입력합니다.
2. **줌 레벨**을 기본값으로 저장할 수준으로 맞춥니다.
3. **Save** 버튼을 클릭합니다.

### 테마 색상 (선택)

| 요소 | 기본값 | 설명 |
|------|--------|------|
| Site | 파란계열 | 부지 경계 색상 |
| Zone | 초록계열 | 구역 색상 |
| Facility | 주황계열 | 시설 건물 색상 |
| Equipment | 회색 | 설비 색상 |
| Device | 빨간계열 | AoT 장치 마커 색상 |

---

## 2단계: 지도 레이어 등록 (선택)

기본 OSM 지도 외에 항공사진이나 국내 지도가 필요하면 GIS 레이어를 등록합니다.

메뉴 **GIS → Layer** 또는 `/geo/layer`로 이동합니다.

**VWorld(국내 지적도/항공)를 추가하는 예:**

1. 오른쪽 상단 **Input Type** 드롭다운에서 `VWorld`를 선택합니다.
2. **Add** 버튼을 클릭합니다.
3. 생성된 항목 오른쪽 **설정(기어 아이콘)**을 클릭합니다.
4. VWorld API 키를 입력하고 저장합니다.
5. **Activate** 버튼으로 활성화합니다.

자세한 내용은 [GIS 레이어 관리](layers.md)를 참조하세요.

---

## 3단계: 첫 번째 지도 디자인

메뉴 **GIS → Design** 또는 `/geo/design`으로 이동합니다.

### 새 지도 만들기

1. 왼쪽 패널 상단의 **+ New Map** 버튼을 클릭합니다.
2. 지도 이름을 입력하고 확인합니다.

### 부지 경계 그리기

1. 상단 모드 패널에서 **Site** 모드를 선택합니다.
2. 도구 모음에서 **폴리곤 그리기**를 선택합니다.
3. 지도 위에서 클릭하여 부지 꼭짓점을 찍고, 마지막 점을 처음 점에 연결하여 완료합니다.
4. 오른쪽 속성 패널에서 부지 이름을 입력하고 **Save**합니다.

**VWorld 필지 가져오기를 사용하면 더 빠릅니다:**

1. 상단 도구에서 **필지 가져오기** 버튼을 클릭합니다.
2. 주소를 입력하여 검색합니다.
3. 결과 목록에서 해당 필지를 선택합니다.
4. **부지로 저장** 버튼을 클릭합니다.

### 구역 설정

1. **Zone** 모드로 전환합니다.
2. 부지 내에 구역 폴리곤을 그립니다.
3. 구역 이름(예: "1동", "재배구역A")을 입력하고 저장합니다.

---

## 4단계: 장치 배치

1. **Device** 모드로 전환합니다.
2. 도구 모음에서 **마커 배치**를 선택합니다.
3. 장치가 실제로 있는 위치를 클릭합니다.
4. 오른쪽 패널에서 연결할 **AoT 장치**를 드롭다운으로 선택합니다.
5. **Save**합니다.

---

## 5단계: 대시보드 위젯 추가

1. 대시보드로 이동합니다.
2. **Add Widget → AoT_map**을 선택합니다.
3. 위젯 설정에서 3단계에서 만든 지도를 선택합니다.
4. **Save**합니다.

지도 위에 장치 마커가 표시되고, 마커를 클릭하면 실시간 값과 제어 스위치가 나타납니다.

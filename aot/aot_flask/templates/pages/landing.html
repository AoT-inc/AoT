AoT

Open-Source Monitoring & Facility Automation
오픈소스 모니터링·시설 자동화 시스템

AoT is open-source software for monitoring sensors and remotely controlling devices (irrigation, ventilation, lighting) from a map-based interface, with a built-in AI assistant. It is not tied to any particular purpose or kind of site — greenhouses and livestock barns, but equally parks, public infrastructure, and traffic. Anyone can install it on their own server or a device such as a Raspberry Pi and run it free of charge.

AoT는 센서 값을 실시간으로 모니터링하고, 관수·환기·조명 같은 장치를 지도 기반 화면에서 원격 제어할 수 있게 해주는 오픈소스 소프트웨어입니다. 특정 용도나 장소에 매이지 않습니다 — 온실·축사는 물론 공원·시설물·교통에도 그대로 쓸 수 있습니다. 누구나 자신의 서버나 라즈베리 파이 같은 장치에 직접 설치해 무료로 운영할 수 있습니다.

AoT를 만든 이유

AoT는 라즈베리 파이 같은 소형 컴퓨터부터 Docker 환경까지, 다양한 하드웨어에서 동작하는 오픈소스 환경 모니터링·제어 시스템입니다. 여러 시설을 한 번에 다룰 수 있도록, 모든 장치와 센서가 지도 위에 실제 위치를 갖는 GIS 기반 디지털 트윈을 중심에 두었습니다.

그 위에 MCP(Model Context Protocol) 기반 AI가 얹혀 있습니다. AI가 지도와 측정값을 직접 읽어 상황을 진단하고, 장비를 움직이는 동작은 사용자 승인을 받아 실행합니다. Claude Desktop 같은 외부 AI 클라이언트를 AoT에 직접 연결할 수도 있습니다.

AoT는 소프트웨어를 특정 회사나 클라우드에 종속시키지 않고, 누구나 자신의 서버에 설치해 직접 소유하고 운영할 수 있어야 한다는 방향을 가지고 만들어졌습니다. 소프트웨어 자체는 무료로 공개되어 있으며, 필요할 때 설치·설정을 돕는 실비 성격의 서비스만 별도로 존재합니다.

GIS 디지털 트윈

모든 장치·센서·구조물이 지도 위 실제 위치를 갖는 지도·시설 중심 인터페이스로, 여러 지점을 한눈에 파악할 수 있습니다.

{{_('AI Assistant')}}

자연어로 장치를 제어하거나 스케줄을 만들고, 시스템 상태를 질의할 수 있습니다. 상태를 바꾸는 동작은 사용자 승인 후 실행됩니다.

MCP 서버

표준 MCP 프로토콜로 시스템 전체를 도구로 노출합니다. Claude Desktop 등 외부 AI 클라이언트를 직접 연결할 수 있습니다.

입력 · 출력 · 함수

센서 측정값 수집(입력), 장치 제어(출력), PID·시퀀스·조건부 등 상위 자동화(함수)까지 세 가지 컨트롤러가 제어의 토대를 이룹니다.

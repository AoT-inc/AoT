    ダッシュボードの構成~

    ダッシュボードは、必要なものだけを1つの画面に集めておく場所であり、ユーザーが毎日いちばんよく見る画面です。 ダッシュボードは すべてのユーザーで共有されます。 そのため、「誰が、何のために見るのか」に合わせてタブを分けることがポイントです。

    ウィジェットの中では AoT マップ ウィジェットが中心です。地図の上で現場の値を見て、サイト・ゾーン・施設・区画の間を移動し、 出力をオン・オフし、記録を残すことを1か所で行います。この章の 手順 4・手順 5 で地図のウィジェットを扱います。

    この章を終えると~

    • 使う人に合わせてダッシュボードのタブを分け、ウィジェットを配置できる
    • 地図のウィジェットで現場を見て回り、値を確認し、出力を操作できる

    始める前に~

    • センサーの値を受信している AoT（センサーの接続）。機能や地図も設定してあれば、使えるウィジェットが増えます
    • ダッシュボードを編集できるアカウント（管理者または編集者）

    手順~

    1. タブを分ける~

    最初はタブが1つだけあります。ダッシュボード画面の上部にある + をクリックすると、タブがもう1つ追加されます （名前は「ダッシュボード {番号}」）。歯車アイコンをクリックし、 ダッシュボード設定 で名前を変更します。タブの名前は重複できません。タブはドラッグして順序を変えられます。

    管理者は、ダッシュボード設定 の グループを選択 で、そのタブを操作できるグループを決められます。グループを選ばなければ、 誰でも操作できます。

    最初は、次のように分けることをおすすめします。

    タブ 見る人 載せるもの
    現場の概要 全員 地図、主要な値のゲージをいくつか、関数ステータス
    点検 管理者 センサーごとのグラフ、シーケンスやタイマーのウィジェット
    施設別 施設の担当者 施設のウィジェット、その施設のグラフ

    1つのタブにグラフが多すぎると、表示が遅くなります。グラフが6つを超える場合は、タブを分けてください。

    2. ウィジェットを追加する~

    1. タブの歯車アイコンで ダッシュボード設定 を開き、下部のボタンを確認します。ロック解除 ボタンが表示されていればタブはロックされているので、クリックしてロックを解除します。 ロックが解除されていると、同じ場所に ロック ボタンが表示されます。ロックされている間は、ウィジェットを追加したり移動したりできません。
    2. ウィジェットを追加 の一覧からウィジェットを選びます。設定の項目が開きます。
    3. 名前 にはウィジェットの種類の名前（例：「関数ステータス」）が入っています。同じ種類のウィジェットを複数使う場合は、何を表示しているかが分かる名前に変更します。
    4. ユーザーオプション の項目を入力し、一番下の ウィジェットを追加 をクリックします。

    ある種類のウィジェットを 初めて 追加するときは、「10秒ほどお待ちください」の画面が表示され、ウェブ画面が1回再起動します。 待っているとダッシュボードに戻り、ウィジェットが配置されています。

    ウィジェットはヘッダーをドラッグして移動し、右下の角をドラッグしてサイズを変更します。位置は自動的に保存されます。 ウィジェットの設定は、変更するとすぐに保存されます。変更が気に入らない場合は 元に戻す をクリックすると、設定ウィンドウを開いたときの状態に戻ります。 作業が終わったら、誰かが誤って動かさないように、ダッシュボード設定で ロック をクリックします。ロックは誤操作を防ぐ仕組みにすぎず、 権限ではありません。編集権限のある人なら誰でも解除できます。

    3. よく使うウィジェット~

    ウィジェット 表示するものとできること 必ず選ぶもの
    AoT マップ 現場の地図と、その上の値・出力。詳しくは 手順 4・手順 5 地図を選択
    AoT グラフ 複数の値の時間による変化。拡大したり期間ボタンで過去の値を見たりし、リセットで現在に戻ります。夜間の網掛けやエクスポートをオンにできます データソース（入力・機能・出力・ノートのタグ）、表示期間
    AoT サーキュラーゲージ、ゲージ (ソリッド) 1つの値を針・バーと色の区間で表示 測定、最小値と最大値、色の区間
    関数ステータス 1つの機能の現在の状態。詳細 でオプションを開いて変更できます（有効になっている機能では変更できないものがあります） 機能（条件付き機能とカスタム機能。シーケンスには下のウィジェットを使います）
    シーケンスコントローラー 順次灌水全体をオン・オフし、動かす曜日と時間帯を決めます。時間帯は共通または曜日ごと シーケンス機能
    AoTタイマー 1つの出力をオン・オフするか、運転・休止を決めた回数だけ繰り返します。サーバーで動くので、画面を閉じても続きます 出力
    AoT 区画 区画の一覧と、各区画の段階・目標に対する現在の値・積算温度 地図・サイト
    AoT 施設 施設の 3D モデル、環境の値、目標値、デバイスの状態 施設の環境制御の機能
    カレンダー 予約した日程・ノート・お知らせをカレンダーで表示 表示方法（月・週・一覧）
    お知らせ＆ノート掲示板 お知らせとノートを見たり書いたりします 表示する場所
    MCP承認リクエスト AI が出した操作のリクエストを承認・拒否します（AI・MCP 接続） なし

    4. 地図のウィジェットを置く~

    1. ウィジェットを追加 で AoT マップ を選びます。
    2. 地図を選択 で表示する地図を選びます。空欄のままにすると、最後に編集した地図が表示されます。 地図に配置したデバイスはすべて自動で表示されるため、デバイスを別に選ぶ必要はありません（地図の構成）。
    3. 必要に応じて次の項目を設定します。最初はそのままでもかまいません。
    4. ラベルを表示：地図上の名前・値の文字全体をオン・オフします
    5. 図形一覧：地図に描く図形の種類（サイト・ゾーン・区画・施設・設備・デバイス）。最初は区画だけがオンになっています
    6. デバイスフィルター：地図で非表示にする入力・出力・機能。空欄なら、すべて表示されます
    7. データ転送周期：ウィジェット・値・出力の状態を読み直す間隔
    8. ラベルスタイル：ズームの程度に応じて表示するラベル、センサーの表示方法（円・文字）、ウィンドウを開いたときに最初に表示するタブ
    9. ほかに データのみ表示（地図を非表示）、AI アドバイスを表示、現地時刻を表示、測定パネル、3Dマップ(ベクターモード) などの設定もあります。折りたたまれた節はクリックして開きます
    10. ウィジェットを追加 をクリックし、サイズを大きめにします。地図のウィジェットは、ほかのウィジェットより大きく置くのがおすすめです。

    地図を選択 を変更すると、保存しておいた表示位置が最初に戻ります。

    5. 地図のウィジェットを使う~

    見て回る

    • 左側のツール：拡大・縮小、コンパス、フルスクリーン、住所を検索、現在地、表示をリセット、サイト一覧。 表示をリセット をクリックすると地図が傾いてゆっくり1周し、もう一度クリックするとその位置で止まります
    • サイト一覧：この地図のサイトが表示されます。サイトをクリックするとその中のゾーンが展開され、もう一度クリックすると地図がそのサイトに 移動し、サイトのウィンドウが開きます。ゾーンをクリックするとゾーンのウィンドウが開きます。制御権限があれば、ドラッグして順序を変えられます
    • 右側のツール：レイヤー（ベースマップ を1つ選び、登録されたオーバーレイ・図形・ラベルをオン・オフする）、距離測定、ノートを追加（地図をクリックしてその位置にノート）、 入力・出力・区画・施設のラベルのオン・オフ
    • ウィジェットのタイトル行の 地図をロック は地図をドラッグや拡大できないように固定し、コントロールを非表示 はツールバーを隠します。 ダッシュボードのロックとは別に動作します
    • 移動したり拡大したりした表示は自動で保存され、次に開いたときはその位置から始まります

    値を見る

    • センサーの表示をクリックすると、その入力のすべてのチャネルと24時間のグラフ、通信の状態が表示されます
    • ゾーンをクリックするとゾーンのウィンドウが開き、現況 / 環境・制御 / 概要 のタブに分かれています。現況には区画・環境の値・ノートが表示され、 リスク要因や灌水の情報はあるときだけ表示されます。環境・制御にはセンサーごとのグラフとそのゾーンの出力・機能の一覧が、概要には写真や面積などの情報があります
    • サイトをクリックするとサイトのウィンドウが開きます。現況にはサイト内のゾーン・施設の一覧と、今日のアドバイス・無応答の装置の数が表示されます
    • 地図上の施設の名札をクリックすると施設のウィンドウが開きます。複数の棟がある場合は、棟を選んで見ます。環境制御の機能がつながった施設には 施設の詳細 タブもあります
    • 区画をクリックすると、段階・環境・設定を見られます
    • ウィンドウ上部の 上位へ をクリックすると、ゾーン → サイト → サイト一覧のように1つ上の階層に上がります

    出力を操作する

    • 出力の表示は、地図をある程度拡大すると表示されます。クリックするとウィンドウに 制御、履歴、ノート一覧 が順に表示されます。 オン・オフする出力はスイッチ、窓・カーテンは 閉じる / 停止 / 開く、 明るさのように強さを決める出力はスライダーで操作します
    • オン・オフする出力の 設定 をクリックすると、開始時刻 と 運転時間 を決めて予約できます。運転時間を 00:00 にすると、 オフにするまでオンのままになります。同じウィンドウで今の予約の状況を見て、今すぐオフ で止められます
    • 地図でクリックした操作は すぐに実行されます。 承認の段階があるのは AI が出したリクエストだけです。クリックする前に対象の出力を確認してください
    • スイッチ・スライダー・予約のボタンは、制御権限のあるユーザーにだけ表示されます。モニター・ゲスト・キオスクのロールは閲覧だけができます

    スマートフォンでは

    ウィンドウを開くと地図が全画面になり、ウィンドウは縦向きの画面では下から上がってきて、横向きの画面では横に付きます。 パソコンやタブレットでは、ウィンドウが横に付き、地図はそのまま使えます。

    6. スマートフォンで見る~

    幅の狭い画面では、ウィジェットが2列に並べ直されます。地図、シーケンス、タイマー、区画、施設のウィジェットは、 スマートフォンでは画面の幅いっぱいに表示され、ほかのウィジェットも設定の モバイルで全幅 で同じようにできます。スマートフォンでウィジェットを 移動しても、パソコンの画面の配置は変わりません。

    確認~

    タブをロックした状態で、初めて見る人が説明なしで現場の状態を説明できれば 完了です。

    • 同じ名前のウィジェットが複数なく、複製したときの名前がそのまま残っているウィジェットもない
    • 関数ステータスのウィジェットに「読み込みに失敗しました」や「無効化しました」が表示されていない（削除した機能や無効にした機能を指しているときに表示されます）
    • スマートフォンで開いても、ダッシュボードが読みやすい

    現場 A~

    タブ ウィジェット
    現場 A の概要 地図（サイト全体）、ゲージ（3-1 と 3-2 の土壌水分、温室の温度と湿度）、関数ステータス（温室の環境制御）
    現場 A 灌水 シーケンスコントローラー（露地の順次灌水、3-2 の追加供給）、グラフ（土壌水分 3-1 と 3-2）
    現場 A 温室 施設のウィジェット、グラフ（温度、湿度、VPD）、関数ステータス

    グラフには 実際に動いている機能とセンサーだけ を入れます。無効にした機能を指すグラフには、空の線しか描かれません。

    現場 B~

    タブ ウィジェット
    現場 B 温室 地図、ゲージ（VPD、温度、湿度、風速）、グラフ（温室の環境）、関数ステータス（環境制御）

    現場 B はタブ1つで十分です。温室の横にある壁掛けの画面には、このタブをランディングページにしたモニター用アカウントで表示しています。

    うまくいかないとき~

    症状 確認すること
    ウィジェットを追加の一覧が表示されない タブがロックされているか、アカウントに編集権限がありません
    地図のウィジェットにデバイスが表示されない デバイスを地図に配置していないか、デバイスフィルター に入れて非表示にしています（センサーの接続 手順 7）
    地図のウィジェットにサイト・ゾーンの図形が表示されない ウィジェットの設定の 図形一覧 でサイト・ゾーンをオンにします
    地図で出力のスイッチが表示されない 制御権限のないロールです
    地図のウィジェットが見当違いの場所を表示する ドラッグして動かした表示が保存されています。サイト一覧 でサイトをクリックして戻ります
    ゲージが空になっている 値が最大経過時間より古くなっています。センサーの値が途切れていないか確認します
    ページの表示が遅い 1つのタブのグラフの数を減らし、更新の間隔を長くしてください
    一部の人だけタブを操作できない、またはタブが表示されない タブにグループが割り当てられています（主な設定 手順 3）

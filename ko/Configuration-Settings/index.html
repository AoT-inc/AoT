    System Configuration

    Page: [관리] -> 설정

    설정 메뉴는 오른쪽 상단의 관리을 클릭한 후 "설정" 링크를 선택하면 접근할 수 있으며, 시스템 전반에 걸친 다양한 설정을 구성할 수 있는 영역입니다.

    일반 설정~

    Page: [관리] -> 시스템 관리 -> 일반 설정

    설정 설명
    언어 웹 사용자 인터페이스에서 표시될 언어를 설정합니다.
    HTTPS 강제 사용 웹 브라우저가 SSL/HTTPS를 사용하도록 요구합니다. http:// 요청은 https://로 리디렉션됩니다.
    성공 알림 숨기기 페이지 상단에 표시되는 모든 성공 알림 박스를 숨깁니다.
    정보 알림 숨기기 페이지 상단에 표시되는 모든 정보 알림 박스를 숨깁니다.
    경고 알림 숨기기 페이지 상단에 표시되는 모든 경고 알림 박스를 숨깁니다.
    통계 전송 거부 익명 사용 통계 전송을 비활성화합니다. 이 기능은 개발에 도움이 되므로 가능하면 유지해 주세요.

    시계열 데이터베이스 설정~

    Page: [관리] -> 시스템 관리 -> 일반 설정

    측정값은 시계열 데이터베이스에 저장됩니다. 현재 AoT에서 사용할 수 있는 옵션은 InfluxDB 1.x와 InfluxDB 2.x입니다. InfluxDB 1.x는 32비트 및 64비트 운영 체제 모두에서 작동하지만, 2.x는 64비트 운영 체제에서만 작동합니다. 따라서 32비트 운영 체제를 사용하는 경우 InfluxDB 1.x를 사용해야 합니다. AoT 설치 중 influxDB 1.x, 2.x 또는 설치하지 않음을 선택할 수 있습니다. InfluxDB를 설치하지 않은 경우에는 AoT가 측정값을 저장하고 조회할 수 있도록 별도의 설치 주소와 인증 정보를 지정해야 합니다.

    Docker로 설치할 경우, 설치 후 InfluxDB Docker 컨테이너에 연결하기 위해 호스트 이름을 "aot_influxdb"로 변경해야 합니다.

    설정 설명
    데이터베이스 사용할 influxdb 버전을 선택합니다.
    보존 정책 보존 정책을 선택합니다. 기본값은 v1.x는 "autogen", v2.x는 "infinite"입니다.
    호스트 이름 시계열 서버에 연결할 호스트 이름입니다. 기본값은 "localhost"입니다.
    포트 시계열 데이터베이스의 포트입니다. 기본값은 8086입니다.
    데이터베이스 이름 AoT가 저장하고 조회할 데이터베이스 이름(v1.x) 또는 버킷(v2.x)입니다. 기본값은 "aot_db"입니다.
    사용자 이름 데이터베이스에 접근하기 위한 사용자 이름입니다(인증이 필요한 경우). 기본값은 "aot"입니다.
    비밀번호 데이터베이스에 접근하기 위한 비밀번호입니다(인증이 필요한 경우).

    업그레이드 설정~

    Page: [관리] -> 시스템 관리 -> 일반 설정

    설정 설명
    인터넷 테스트 IP 주소 인터넷 연결 활성 여부를 테스트할 때 사용할 IP 주소입니다.
    인터넷 테스트 포트 인터넷 연결 활성 여부를 테스트할 때 사용할 포트입니다.
    인터넷 테스트 타임아웃 인터넷 연결 테스트 시의 타임아웃 시간입니다.
    업데이트 확인 2일마다 자동으로 업데이트를 확인하고 웹 인터페이스를 통해 알림을 표시합니다. 새 업데이트가 있는 경우, 설정(관리)과 업그레이드 메뉴가 빨간색으로 표시됩니다.

    에너지 사용 설정~

    Page: [관리] -> 시스템 관리 -> 일반 설정

    정확한 에너지 사용 통계를 계산하려면, 전기 시스템의 몇 가지 특성을 알아야 합니다. 이 변수들은 릴레이를 통해 전기 장치를 작동시키는 전기 시스템의 특성을 설명해야 합니다.

    Note

    전류 센서를 사용하지 않는 경우, 정확한 에너지 사용 계산을 위해 각 출력에 대해 정확한 전류 사용량을 설정해야 합니다 (출력 설정 참조).

    설정 설명
    최대 전류(A) 한 번에 허용되는 최대 전류를 설정합니다. 출력이 켜질 경우 활성 장치들의 총합이 이 값을 초과하면 손상을 방지하기 위해 출력을 켤 수 없습니다.
    전압(V) 출력을 통해 스위칭되는 교류(AC) 전압입니다. 일반적으로 120 또는 240입니다.
    kWh당 비용 kWh당 전기 요금을 입력합니다.
    통화 단위 전기 요금에 사용되는 통화 단위입니다.
    검침일 전기 계량기를 확인하는 날짜(1~30일)입니다. 전기 요금 청구일과 일치해야 합니다.
    사용량/비용 보고서 생성 에너지 사용량 보고서를 생성할 시점을 정의합니다. 현재는 출력 시간 기반 계산 방식만 지원됩니다.
    보고서 생성 주기 사용량/비용 보고서를 자동으로 생성할 주기를 설정합니다.
    보고서 생성 요일/일자 보고서를 생성할 요일(Daily: 1~7, 월요일=1) 또는 월별 생성일(1~28)을 설정합니다.
    보고서 생성 시간(시) 보고서를 생성할 시간을 0~23 사이에서 설정합니다.

    컨트롤러 샘플링 주기 설정~

    Page: [관리] -> 시스템 관리 -> 일반 설정

    입력, 출력, 함수용 각 컨트롤러는 주기적으로 동작합니다. 각 컨트롤러가 응답할 수 있는 가장 빠른 속도는 해당 컨트롤러의 샘플링 주기로 결정됩니다. 컨트롤러는 해당 주기 동안 루프를 일시 중지합니다. 예를 들어 출력 컨트롤러의 샘플링 주기가 1초로 설정되어 있다면, 출력 on/off 명령은 최대 1초 내에 반응합니다.

    설정 설명
    최대 전류 한 번에 허용되는 최대 전류(A)를 설정합니다. 만약 출력을 켜는 명령이 현재 켜져 있는 장치들과 합쳐서 이 값을 초과하게 된다면, 출력은 손상을 방지하기 위해 켜지지 않습니다.
    전압 출력을 통해 스위칭되는 교류(AC) 전압입니다. 일반적으로 120 또는 240입니다.
    kWh당 비용 kWh당 전기 요금을 입력합니다.
    통화 단위 전기 요금을 지불할 때 사용하는 통화 단위입니다.
    검침일 전기 계량기를 확인하는 날짜(1~30일)입니다. 전기 요금 청구일과 일치해야 합니다.
    사용량/비용 보고서 생성 에너지 사용량 보고서가 생성될 시점을 정의합니다. 현재는 출력 시간 기반 계산 방식만 지원됩니다.

    설정 설명

    측정값 설정~

    Page: [관리] -> 시스템 관리 -> 측정

    AoT의 내장 타입 및 수식을 넘어 기능을 확장할 수 있도록 새로운 측정값, 단위, 변환식을 생성할 수 있습니다. 측정값을 만들기 전에 단위를 먼저 생성해야 하며, 이는 측정값을 생성할 때 단위를 선택해야 하기 때문입니다. 이미 존재하는 측정값에 추가 단위를 지정할 수도 있습니다. 예: altitude는 이미 존재하지만 fathom 단위를 추가하고 싶다면 먼저 fathom 단위를 만든 후, fathom이 선택된 상태로 altitude 측정값을 생성하면 됩니다.

    설정 설명
    측정값 ID 입력 모듈의 measurements_dict에서 사용할 측정값의 ID (예: "length", "width", "speed")
    측정값 이름 측정값의 일반 이름 (예: "길이", "무게", "속도")
    측정값 단위 측정값과 관련된 단위를 모두 선택합니다.
    단위 ID 입력 모듈의 measurements_dict에서 사용할 단위의 ID (예: "K", "g", "m")
    단위 이름 단위의 일반 이름 (예: "킬로그램", "미터")
    단위 약어 단위의 약어 (예: "kg", "m")
    변환 기준 단위 변환의 기준이 되는 단위
    변환 대상 단위 변환할 단위
    변환식 한 단위를 다른 단위로 변환하는 데 사용할 식입니다. 소문자 "x"가 포함되어야 하며 (예: "x/1000+20", "250*(x/3)"), 실제 측정값이 해당 x로 대체됩니다.

    사용자 설정~

    Page: [관리] -> 시스템 관리 -> 사용자

    AoT의 로그인 시스템이 활성화되기 위해서는 최소한 하나의 관리자(Admin) 사용자가 필요합니다. 관리자 사용자가 존재하지 않으면, 웹 서버는 관리자 생성 폼으로 리디렉션됩니다. 이는 AoT를 처음 시작할 때 표시되는 첫 번째 페이지입니다. 관리자 사용자가 생성된 후에는 사용자 설정 페이지에서 추가 사용자를 생성할 수 있습니다.

    설정 설명
    사용자 이름 2자에서 64자 사이의 사용자 이름을 선택합니다. 대소문자를 구분하지 않으며 모두 소문자로 변환됩니다.
    이메일 해당 계정에 연결할 이메일 주소입니다.
    비밀번호/재입력 8자 이상, 문자·숫자·기호만 포함된 비밀번호를 선택합니다. 흔히 쓰이는 비밀번호는 길이 조건을 만족해도 거부됩니다. [보안](Security.ko.md#password-requirements) 참조.
    키패드 코드 키패드를 이용해 로그인할 때 사용할 4자리 이상의 숫자 코드입니다 (선택 사항).
    역할 사용자의 권한을 설정하기 위한 역할입니다. 아래의 기본 4가지 역할에 대한 설명을 참조하세요.
    테마 웹 사용자 인터페이스에 적용할 테마입니다. 색상, 디자인 요소 등을 포함합니다.

    역할~

    역할은 각 사용자의 권한을 정의합니다. 사용자가 AoT의 특정 영역을 볼 수 있는지 또는 편집할 수 있는지를 결정하는 4개의 기본 역할이 제공됩니다. 기본 역할 외에도 사용자 정의 역할을 생성할 수 있습니다.

    역할 관리자 편집자 모니터 게스트

    설정 편집 X X

    카메라 보기 X X X
    통계 보기 X X X

    컨트롤러 편집 권한은 조건문, 그래프, LCD, 메서드, PID, 출력, 입력의 편집을 보호합니다.

    통계 보기 권한은 사용 통계, 시스템 정보, 에너지 사용 페이지의 보기를 보호합니다.

    라즈베리파이 설정~

    Page: [관리] -> 시스템 관리 -> 라즈베리파이

    라즈베리파이 설정은 AoT가 실행되는 Linux 시스템의 일부를 구성합니다.

    PWM 출력 및 PWM, RPM, DHT22, DHT11, HTU21D 입력을 사용하려면 pigpiod가 필요합니다.

    설정 설명
    기능 활성화/비활성화 raspi-config 명령을 통해 웹 UI에서 활성화 및 비활성화할 수 있는 시스템 인터페이스입니다.
    pigpiod 샘플링 속도 pigpiod 서비스가 작동할 샘플링 속도입니다. 숫자가 낮을수록 더 빠른 PWM 주파수를 사용할 수 있지만, Pi Zero에서는 프로세서 부하가 크게 증가할 수 있습니다. pigpiod는 필요하지 않은 경우 완전히 비활성화할 수도 있습니다 (위의 참고 사항 참조).

    알림 설정~

    Page: [관리] -> 시스템 관리 -> 알림

    알림 설정은 이메일 알림을 보내기 위한 자격 증명을 설정합니다.

    설정 설명
    SMTP 호스트 이메일을 보낼 때 사용할 SMTP 서버입니다.
    SMTP 포트 SMTP 서버와 통신할 포트입니다 (SSL은 465, TSL은 587).
    SSL 활성화 SSL을 활성화하려면 체크하고, TSL을 활성화하려면 체크 해제합니다.
    SMTP 사용자 이메일을 보낼 사용자 이름입니다. 이름만 입력하거나 전체 이메일 주소를 입력할 수 있습니다.
    SMTP 비밀번호 사용자의 비밀번호입니다.
    보내는 이메일 보내는 이메일 주소로 설정할 값입니다. 이 값은 실제 사용자 이메일 주소여야 합니다.
    최대 이메일 수 (시간당) 시간당 보낼 수 있는 최대 이메일 수를 설정합니다. 한 시간 내에 이 숫자를 초과하는 알림이 발생하면, 초과된 알림은 삭제됩니다.
    테스트 이메일 보내기 테스트 이메일을 보내 이메일 구성을 테스트합니다.

    카메라 설정~

    Page: [관리] -> 시스템 관리 -> 카메라

    AoT는 여러 대의 카메라를 동시에 사용할 수 있습니다. 각 카메라는 카메라 설정에서 설정한 후 소프트웨어 전반에서 사용할 수 있습니다.

    Note

    제조사별 하드웨어 및 소프트웨어 차이로 인해 일부 옵션(예: 색조 또는 화이트 밸런스)은 특정 카메라에서 사용할 수 없을 수 있습니다.

    설정 설명
    유형 카메라가 Raspberry Pi 카메라인지 USB 카메라인지 선택합니다.
    라이브러리 카메라와 통신하기 위해 사용할 라이브러리를 선택합니다. Raspberry Pi 카메라는 picamera를 사용하며, USB 카메라는 fswebcam으로 설정해야 합니다.
    장치 카메라에 연결할 장치를 지정합니다. fswebcam 라이브러리만 이 옵션을 사용합니다.
    출력 스틸 이미지 캡처(타임랩스 포함) 중에 활성화될 출력을 설정합니다.
    출력 지속 시간 이미지 캡처 전에 출력이 활성화될 시간을 설정합니다.
    이미지 회전 이미지를 회전할 각도를 설정합니다.
    ... 이미지 너비, 이미지 높이, 밝기, 대비, 노출, 게인, 색조, 채도, 화이트 밸런스. 이러한 옵션은 직관적입니다. 모든 옵션이 모든 카메라에서 작동하지 않을 수 있습니다.
    사전 명령 스틸 이미지가 캡처되기 전에 'root' 사용자로 실행할 명령입니다.
    사후 명령 스틸 이미지가 캡처된 후 'root' 사용자로 실행할 명령입니다.
    수평 반전 이미지를 수평으로 뒤집거나 미러링합니다.
    수직 반전 이미지를 수직으로 뒤집거나 미러링합니다.

    진단 설정~

    Page: [관리] -> 시스템 관리 -> 진단

    시스템에서 비호환 구성으로 인해 문제가 발생할 수 있습니다. 이는 시스템의 일부(입력, 출력 등)가 잘못 구성되었거나 데이터베이스 업그레이드가 제대로 처리되지 않은 업데이트, 또는 기타 예기치 못한 문제로 인해 발생할 수 있습니다. 문제의 원인을 파악하거나 문제 자체를 해결하기 위해 진단 작업을 수행해야 할 때가 있습니다. 아래 옵션은 문제를 완화하기 위한 것입니다. 예를 들어, 데이터 -> 대시보드 페이지에서 오류를 일으키는 잘못 구성된 대시보드 요소로 인해 해당 페이지에 접근할 수 없는 경우, 모든 대시보드 요소를 삭제하는 것이 다시 접근할 수 있는 가장 경제적인 방법일 수 있습니다. 단, 이 경우 기존의 모든 대시보드 요소를 다시 추가해야 합니다.

    설정 설명
    모든 대시보드 삭제 데이터 -> 대시보드 페이지에 저장된 모든 대시보드를 삭제합니다.
    모든 입력 삭제 설정 -> 입력 페이지의 모든 입력을 삭제합니다.
    모든 노트 및 태그 삭제 더보기 -> 노트 페이지의 모든 노트와 태그를 삭제합니다.
    모든 출력 삭제 설정 -> 출력 페이지의 모든 출력을 삭제합니다.
    설정 데이터베이스 삭제 aot.db 설정 데이터베이스를 삭제합니다 (경고: 이 작업은 모든 설정과 사용자를 삭제합니다).
    파일 삭제: .dependency .dependency 파일을 삭제합니다. 종속성 설치 페이지에 접근하는 데 문제가 있는 경우 시도해 보세요.
    파일 삭제: .upgrade .upgrade 파일을 삭제합니다. 업그레이드 페이지에 접근하거나 업그레이드를 실행하는 데 문제가 있는 경우 시도해 보세요.
    InfluxDB 1.x 데이터베이스 재생성 InfluxDB 1.x 측정 데이터베이스를 삭제한 후 재생성합니다. 이 작업은 모든 측정 데이터를 삭제합니다!
    InfluxDB 2.x 데이터베이스 재생성 InfluxDB 2.x 측정 데이터베이스를 삭제한 후 재생성합니다. 이 작업은 모든 측정 데이터를 삭제합니다!
    이메일 카운터 초기화 시간당 이메일 카운터를 초기화합니다.
    종속성 설치 AoT 시스템 전체에 필요한 모든 종속성을 설치하는 스크립트를 시작합니다.
    마스터로 업그레이드 설정 config.py에서 FORCE_UPGRADE_MASTER를 True로 변경합니다. GitHub의 main 브랜치로 업그레이드하도록 업그레이드 시스템에 지시하는 방법으로, 로그인하여 config.py 파일을 수동으로 편집하지 않아도 됩니다.

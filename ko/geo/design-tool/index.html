    지도 디자인 도구~

    /geo/design 페이지는 부지·구역·시설·장치를 지도 위에 배치하고 관리하는 인터랙티브 편집 환경입니다.

    화면 구성~

    ┌─────────────────────────────────────────────────────┐
│  상단 모드 패널 (Site / Zone / Facility / ...)        │
├──────┬──────────────────────────────────┬────────────┤
│      │                                  │            │
│  좌측 │          지도 캔버스               │  우측 속성  │
│  도구 │    (MapLibre GL 벡터 렌더링)       │   패널     │
│  모음 │                                  │            │
├──────┴──────────────────────────────────┴────────────┤
│  하단 상태바 (좌표, 줌 레벨, 저장 상태)                │
└─────────────────────────────────────────────────────┘

    편집 모드 (7가지)~

    상단 모드 패널에서 편집 대상을 선택합니다. 모드마다 그릴 수 있는 도형과 속성이 다릅니다.

    Site (부지)~

    부지 최상위 경계를 정의합니다.

    • 그리기: 폴리곤
    • 속성: 이름, 색상, 불투명도
    • 특수 기능: VWorld/CSV 필지 가져오기 (아래 참조)

    Zone (구역)~

    부지 내 재배동·구획·관리 구역을 정의합니다.

    • 그리기: 폴리곤
    • 속성: 이름, 상위 부지 연결, 색상
    • 팁: Spatial Join을 사용하면 Zone 그리기 시 포함된 Site를 자동 감지합니다.

    Facility (시설)~

    물리적 건물(온실, 창고, 설비동)을 배치합니다.

    • 그리기: 폴리곤 (건물 외곽선)
    • 속성: 이름, 구조 타입, 상위 구역 연결
    • 특수 기능: 시설 저장 후 /geo/facility에서 3D 모델링 및 공학 계산을 진행할 수 있습니다.

    Equipment (설비)~

    시설 내 기계 설비(팬, 펌프, 난방기 등)를 배치합니다.

    • 그리기: 폴리곤 또는 마커
    • 속성: 이름, 장비 타입, 상위 시설 연결

    Device (장치)~

    AoT에 등록된 Input/Output 장치의 물리적 위치를 표시합니다.

    • 그리기: 마커
    • 속성: 연결할 AoT 장치 선택, 마커 색상
    • 대시보드 연동: 위젯에서 마커 클릭 시 실시간 값 및 제어 스위치 팝업 표시

    Connection (연결)~

    배관·배선·통신 경로를 표시합니다.

    • 그리기: 폴리라인
    • 속성: 이름, 연결 타입(물/전기/통신), 굵기, 색상
    • 자동 배관 생성: /api/geo/generate-pipes로 장치 간 최적 경로 자동 생성

    Infrastructure (인프라)~

    경계 표식, 도로, 기타 참조 형상을 표시합니다.

    • 그리기: 폴리곤, 폴리라인, 마커
    • 속성: 이름, 색상

    도구 단축키 설명

    삭제 Del 선택된 피처 삭제

    피처 저장~

    자동 저장 (델타)~

    피처를 추가·수정·삭제할 때마다 변경된 부분만 서버에 전송합니다. 수천 개의 피처가 있는 지도도 저장 지연 없이 작업할 수 있습니다.

    수동 저장~

    상단 Save 버튼 또는 Ctrl+S로 전체 상태를 강제 저장합니다.

    필지 가져오기~

    한국 토지 데이터(VWorld)를 이용해 부지 경계를 빠르게 가져올 수 있습니다.

    주소로 가져오기~

    1. 상단 도구에서 필지 가져오기 버튼 클릭
    2. 주소 입력 후 검색 (VWorld PNU API 사용)
    3. 결과 목록에서 해당 필지 선택
    4. 부지로 저장 클릭 → Site 피처 자동 생성

    CSV 일괄 가져오기~

    여러 필지를 한번에 가져올 때 사용합니다.

    CSV 형식: 

    address,name
경기도 화성시 송산면 ...,1번 온실 부지
경기도 화성시 송산면 ...,2번 온실 부지

    1. 필지 가져오기 → CSV 가져오기 선택
    2. CSV 파일 업로드
    3. 미리보기 확인 후 가져오기 실행

    레이어 제어~

    우측 상단 레이어 패널에서 표시할 레이어를 켜고 끕니다.

    • 기본 레이어: 등록된 GIS 레이어 제공자 중 선택
    • 오버레이: Site, Zone, Facility, Device 각각 표시/숨김
    • 기상 레이어: RainViewer 레이더, OpenWeather 오버레이

    통계 패널~

    Stats 버튼을 클릭하면 현재 지도의 통계를 확인합니다.

    • 부지 총 면적 (m²/㎡/평)
    • 구역 수 및 면적
    • 시설 수
    • 배치된 장치 수

    지도 잠금~

    지도 우측 상단 잠금 버튼을 클릭하면 지도 이동/줌을 잠급니다. 대시보드에 배치된 AoT_map 위젯에서 실수로 지도가 이동되는 것을 방지합니다.

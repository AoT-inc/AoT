    AoT_map 위젯~

    AoT_map은 여러 동·구역에 흩어진 센서와 장치를 지도 한 장 위에서 보고 바로 제어하는 대시보드 위젯입니다. 예를 들어 온실 5동에 관수 밸브 20개, 온습도 센서 10개가 설치되어 있다면, 이 위젯 하나로 전체 배치를 한눈에 보고, 색이 다른 장치를 클릭해 바로 켜고 끄고, 각 지점의 최근 측정값과 AI 조언까지 확인할 수 있습니다. MapLibre GL 기반이라 3D 지형·시설 렌더링과 부드러운 확대/축소를 지원합니다.

    위젯 추가하기~

    1. 대시보드에서 위젯 추가 → AoT Map을 선택합니다.
    2. 설정에서 표시할 지도를 선택합니다(비워두면 가장 최근에 수정한 지도를 사용).
    3. 저장을 클릭합니다.

    주요 기능~

    장치 마커~

    /geo/design에서 장치(Device) 모드로 배치한 입력·출력·함수 장치가 지도 위에 마커로 표시됩니다.

    • 마커 색상: 장치의 활성/비활성/오류 상태에 따라 자동으로 바뀝니다.
    • 마커 겹침 정리: 확대 수준이 낮아 마커가 겹치면 개수 배지가 있는 그룹으로 합쳐 표시하고, 확대하면 다시 개별 마커로 펼쳐집니다.
    • 장치 아이콘: 장치 종류(온도 센서·릴레이·펌프 등)에 따라 다른 아이콘을 사용합니다.

    팝업으로 바로 제어하기~

    마커를 클릭하면 팝업이 열려 다음을 보여줍니다.

    • 장치 이름
    • 최근 측정값(입력 장치)
    • On/Off 토글 스위치(출력 장치, 편집 권한이 있는 사용자에게만 표시)
    • 마지막 업데이트 시각

    스위치를 조작하면 즉시 해당 장치를 켜고 끕니다. 시설(Facility) 마커를 클릭하면 3D 미리보기와 환경 데이터 요약을 볼 수 있습니다 — 자세한 내용은 3D 시설 팝업을 참고하세요.

    실시간 갱신~

    위젯은 설정된 주기(기본 5초)마다 장치 상태를 자동으로 새로고침합니다. 마커 색상과 측정값 라벨이 실시간으로 업데이트되며, 팝업이 열려 있어도 값이 계속 갱신됩니다.

    지도 위 도구 버튼~

    지도 좌측 또는 우측 모서리에 다음 도구 버튼이 표시됩니다.

    버튼 기능
    +/- 확대/축소
    전체화면 위젯을 전체화면으로 표시
    검색 주소 검색 후 해당 위치로 이동
    내 위치 브라우저 GPS 위치로 이동
    초기화 처음 저장된 위치·확대 수준으로 되돌리기
    사이트 목록 등록된 사이트·구역 목록에서 선택해 바로 이동

    이 외에 위젯 제목 표시줄에는 지도 잠금(이동·확대 잠금)과 컨트롤 숨김(도구 버튼 숨기기) 아이콘이 있습니다. 이 둘은 설정 화면이 아니라 위젯 제목 표시줄에서 바로 켜고 끄는 토글입니다.

    설정 옵션~

    새로고침~

    옵션 설명
    새로고침 주기(초) 장치 상태를 다시 불러오는 간격. 0으로 설정하면 자동 새로고침을 끕니다. (기본 5초)
    유효 측정값 최대 나이(초) 이보다 오래된 측정값은 화면에 표시하지 않습니다. (기본 300초)
    입력 갱신 간격(초) 측정값을 자동으로 다시 가져오는 간격. (기본 300초)

    지도~

    옵션 설명
    지도 선택 표시할 저장된 지도를 선택합니다. 비워두면 가장 최근에 수정한 지도를 사용합니다.
    위도/경도, 확대 수준 지도를 선택하지 않았을 때 사용할 대체 위치와 확대 수준입니다.
    활성 오버레이 레이어 / 선택된 기본 지도 위젯이 마지막으로 선택한 레이어·기본 지도를 기억해두는 값입니다. 직접 입력하는 항목이 아니며, 지도 화면의 레이어 선택기를 조작하면 자동으로 채워집니다.

    참고

    지도 선택을 다른 지도로 바꾸면 위도/경도·확대 수준 값은 자동으로 초기화됩니다(새 지도 기준으로 다시 맞추기 위함).

    3D 지도~

    옵션 설명
    기본 피치(0~60) 지도를 처음 열었을 때의 3D 기울기 각도.
    기본 베어링(-180~180) 지도를 처음 열었을 때의 회전 각도.
    사용자 지정 벡터 스타일 URL 커스텀 MapLibre 스타일 JSON을 쓰고 싶을 때만 입력합니다. 비워두면 GIS 입력 설정을 따릅니다.
    시설 렌더 모드 시설(건물) 3D 모델을 그리는 방식: 기본(반투명) / 솔리드(불투명) / 와이어프레임 / 성능(모바일용, 부하 최소화).

    장치 선택~

    옵션 설명
    입력 / 출력 / 함수 지도에 표시할 장치를 종류별로 선택합니다. 아무것도 선택하지 않으면 장치가 표시되지 않으니, 지도에 아무것도 안 보인다면 여기부터 확인하세요.

    측정값 패널~

    옵션 설명
    입력 / 출력 / 함수 지도 옆 데이터 패널에 표시할 측정값을 종류별로 선택합니다.

    AI~

    옵션 설명
    AI 조언 표시 이 지도가 속한 시설·사이트에 대한 최신 AI 조언 요약을 지도 상단에 클릭 가능한 칩으로 표시합니다. (전역 AI가 설정되어 있어야 합니다)

    라벨~

    옵션 설명
    라벨 표시 사이트·구역·장치·센서 라벨 전체를 켜고 끄는 마스터 스위치입니다. 입력/출력/함수별 세부 표시는 지도 우측의 라벨 컨트롤러에서 따로 조정합니다.
    라벨 겹침 방지 켜면 화면에서 겹치는 라벨을 자동으로 숨깁니다.
    라벨 간격(px) 겹침 판정에 더할 여유 간격. 0(기본값)은 실제로 겹칠 때만 묶고, 장치가 촘촘한 현장에서 더 일찍 묶고 싶다면 10~30 정도로 올립니다.
    라벨 글자 크기(em) 모든 지도 라벨의 글자 크기.
    시설 중심 라벨 꺼짐(기본값): 야외 중심 — 사이트·구역 라벨이 항상 보이고, 시설·센서 라벨은 확대했을 때만 나타납니다. 켜짐: 시설 중심 — 시설·센서 라벨이 우선하고, 축소하면 사이트·구역 라벨은 서로 합쳐집니다.

    센서 라벨 스타일~

    시설에 센서가 연결된 경우에만 나타나는 라벨의 모양을 설정합니다(표시 여부 자체는 위 라벨 표시 마스터 스위치를 따릅니다).

    옵션 설명
    센서 마커 스타일 원형(첫 측정값을 정수로 표시, 구간 색상 적용) 또는 텍스트(전체 값 표시).
    표시할 최대 채널 수 라벨 하나에 표시할 측정값 개수. 초과분은 "+"로 접힙니다.
    소수 자릿수 라벨 값의 소수점 자리 수.
    라벨 크기(em) 센서 라벨의 글자 크기.
    라벨 배경색 / 글자색 CSS 색상 값을 입력합니다(예: #f8fafc, rgba(15,23,42,0.78)).
    세로 오프셋(m) 센서 위치보다 얼마나 위쪽(미터)에 라벨을 띄울지.
    라벨 불투명도 0.0~1.0 사이 값으로 센서 라벨의 투명도를 조절합니다.
    센서 팝업 사용 켜면 센서 라벨을 클릭했을 때 최근 24시간 차트가 있는 상세 팝업이 열립니다.
    팝업 기본 탭 팝업을 열었을 때 처음 보여줄 탭: 개요 / 환경 및 제어 / 정보.

    도형 표시~

    디자인 도구에서 그린 폴리곤을 지도 위에 반투명 오버레이로 표시할지 종류별로 켜고 끕니다.

    옵션 설명
    사이트 도형 사이트 경계선(설정된 테마 색상).
    구역 도형 구역 경계선.
    시설 도형 건물 외곽선.
    장비 도형 배관 등 장비의 도형.
    장치 도형 장치가 차지하는 영역 도형.
    그 외 그린 도형 그리기 도구로 만든 자유 도형.
    장치 도형 불투명도(0~100) 위 장치 도형의 불투명도. 0은 투명, 100은 완전 불투명.

    기타~

    옵션 설명
    데이터만 표시(지도 숨김) 지도 배경과 오버레이를 감추고 옆의 측정값 패널만 보여줍니다.

    범례(Legend)~

    지도 우측 하단에 범례가 자동으로 표시됩니다. 별도 설정 없이 현재 켜져 있는 오버레이 레이어의 색상과 입력/출력 장치 아이콘을 설명하며, 범례 항목을 클릭하면 해당 레이어·장치 표시를 켜고 끌 수 있습니다.

    3D 시설 팝업~

    시설(Facility) 마커나 폴리곤을 클릭하면 간단한 3D 미리보기와 환경 데이터 요약이 팝업으로 표시됩니다. 전체 화면으로 자세히 보려면 AoT_facility 위젯을 사용하세요.

    여러 지도를 한 대시보드에~

    같은 대시보드에 AoT_map 위젯을 여러 개 추가하고 각각 다른 지도를 표시할 수 있습니다. 예를 들어 전체 부지를 보여주는 개요용 지도와, 특정 동만 확대한 지도를 나란히 배치할 수 있습니다.

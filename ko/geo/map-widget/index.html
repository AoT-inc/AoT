    AoT_map 위젯~

    AoT_map은 여러 동·구역에 흩어진 센서와 장치를 지도 한 장 위에서 보고 바로 제어하는 대시보드 위젯입니다. 예를 들어 온실 5동에 관수 밸브 20개, 온습도 센서 10개가 설치되어 있다면, 이 위젯 하나로 전체 배치를 한눈에 보고, 색이 다른 장치를 클릭해 바로 켜고 끄고, 각 지점의 최근 측정값과 AI 조언까지 확인할 수 있습니다. MapLibre GL 기반이라 3D 지형·시설 렌더링과 부드러운 확대/축소를 지원합니다.

    위젯 추가하기~

    1. 대시보드에서 위젯 추가 → AoT Map을 선택합니다.
    2. 설정에서 표시할 지도를 선택합니다(비워두면 가장 최근에 수정한 지도를 사용).
    3. 저장을 클릭합니다.

    주요 기능~

    장치 마커~

    /geo/design에서 장치(Device) 모드로 배치한 입력·출력·함수 장치가 지도 위에 마커로 표시됩니다.

    • 마커 색상: 장치의 활성/비활성/오류 상태에 따라 자동으로 바뀝니다.
    • 마커 겹침 정리: 확대 수준이 낮아 마커가 겹치면 개수 배지가 있는 그룹으로 합쳐 표시하고, 확대하면 다시 개별 마커로 펼쳐집니다.
    • 장치 아이콘: 장치 종류(온도 센서·릴레이·펌프 등)에 따라 다른 아이콘을 사용합니다.

    팝업으로 바로 제어하기~

    마커를 클릭하면 장치 종류에 맞는 창이 열립니다.

    입력(센서) — 값 키를 클릭하면 상세 창이 열립니다. 최근 24시간 그래프와 측정 항목별 현재값이 함께 나오며, 노트도 바로 작성할 수 있습니다. 이 창은 시설·구역 모달에서 센서를 열었을 때와 같은 창입니다.

    출력·함수 — 구역·시설과 같은 중앙 창이 열리며, 위에서부터 세 덩이입니다.

    1. 이력 — 최근 가동 기록 그래프. 켜기 전에 "지금까지 얼마나 돌았나"를 먼저 봅니다.
    2. 제어 — 장치 이름과 On/Off 토글(편집 권한이 있는 사용자에게만 표시), 그 아래에 작동 시간과 설정 버튼.
    3. 노트

    작동 시간은 한 칸이 두 상태를 번갈아 씁니다. 꺼져 있으면 마지막으로 작동한 시간(흐린 글씨), 켜는 순간 그 자리가 곧바로 흐르는 타이머로 바뀝니다(진한 글씨). 다른 창이나 예약으로 켜고 꺼도 이 창이 열려 있는 동안 계속 따라옵니다.

    개폐율 장치(창문·커튼 등)는 열림/정지/닫힘 버튼과 개방률 슬라이더가 함께 나옵니다.

    시설(Facility) 마커를 클릭하면 3D 미리보기와 환경 데이터 요약을 볼 수 있습니다 — 자세한 내용은 3D 시설 팝업을 참고하세요.

    구역/사이트 클릭 — 장치 목록으로 제어~

    구역(Zone)이나 사이트(Site) 도형을 클릭하면, 그 안에 배치된 센서·출력 장치를 한 번에 보는 팝업이 열립니다.

    • 센서: 여러 개면 탭으로 전환하며 최근 24시간 차트를 볼 수 있습니다.
    • 출력 장치 목록: On/Off 토글로 즉시 제어(편집 권한 필요), 드래그로 순서 변경. 작동 시간은 장치 창과 같은 규칙으로 표시됩니다(꺼짐=마지막 작동 / 켜짐=흐르는 타이머).
    • 설정(예약 켜기): 출력마다 있는 설정 버튼 — 아래 예약 켜기 참고.

    식생 구획 클릭 — 무엇이 심겨 있나~

    디자인 도구의 식생 모드에서 그린 구획을 지도에 표시하고, 클릭하면 그 작기의 운영 정보를 봅니다.

    • 작물·품종·재배 기간과 경과 일수.
    • 면적과 치수 — 가로·세로를 함께 보여줍니다. 면적만으로는 "몇 줄 심을 수 있나"에 답할 수 없기 때문입니다.
    • 관수 — 이 구획을 적시는 밸브와 각각의 적심 비율. 밸브 하나가 여러 작물을 적시고 한 작물이 두 밸브에 걸치기도 하므로, 밸브를 하나로 정하지 않고 겹치는 면적을 그대로 보여줍니다. 비율은 구획 면적 대비입니다("내 두둑이 얼마나 젖는가"). 아직 적실 수단이 없는 부분도 숨기지 않고 표시합니다.
    • 센서 — 구획 안의 센서를 보여주고, 없으면 상위 구역의 센서로 넘어갑니다.
    • 노트 — 다른 도형과 같은 공용 노트 블록입니다.

    관수량은 계산하지 않습니다

    겹친 영역에서 물은 물리적으로 공유되므로 작물별 요구량을 더하면 틀린 숫자가 나옵니다. 근거만 보여주고 판단은 사람이 합니다.

    구획 라벨(칩)은 줌 16 이상에서 나타납니다 — 라벨이 이미 많은 화면이라 항상 띄우면 겹칩니다. 레이어 컨트롤이나 설정의 식생 구획 표시 옵션으로 끄고 켤 수 있으며, 두 곳은 같은 값을 공유합니다.

    대표 측정 정하기~

    구역·시설 창의 [현황] → 현재 블록에는 그 안의 센서 값이 나란히 표시됩니다. 여기서 값을 클릭하면 그 측정이 대표가 되고, 배경이 칠해져 어느 것이 대표인지 남습니다. 다시 누르면 지정이 풀립니다(편집 권한 필요).

    지정한 대표 측정은 다음 세 곳이 함께 씁니다.

    • 지도 위의 구역 라벨·시설 칩에 뜨는 값
    • 사이트 요약 창의 구역·시설 줄에 뜨는 값
    • 그 창의 현재 블록(배경 표시)

    지정하지 않으면 VPD > 온도 > 습도 > CO₂ > 조도 > 풍속 순으로 자동 선택됩니다. 지정은 구역·시설마다 따로 저장되므로, 육묘장은 온도·노지는 토양수분처럼 자리마다 다르게 둘 수 있습니다. 지정한 센서가 값을 내지 못하는 동안에는 자동 선택으로 잠시 물러났다가, 센서가 돌아오면 지정이 그대로 살아납니다.

    예약 켜기~

    on/off 출력 장치의 설정 버튼을 누르면 시작·종료 시각을 지정하는 창이 열립니다. 구역 모달 · 시설 모달 · 장치 마커 팝업 어디서 열어도 같은 창입니다.

    • 종료 시각을 00:00으로 두면 수동으로 끌 때까지 계속 켜져 있습니다.
    • 시작 시각이 사실상 "지금"이면 즉시 켜고, 지정한 종료 시각에 자동으로 끕니다.
    • 시작 시각이 미래면 서버 스케줄러에 등록됩니다. 브라우저를 닫아도 예정대로 실행되며, 작업 예약 페이지에서 확인·수정·취소할 수 있습니다.
    • 서버 등록에 실패하면(예: MCP 서버 미설정) 현재 탭이 대기했다가 실행하는 방식으로 대신 진행할지 물어봅니다. 이 경우에만 탭을 닫으면 실행되지 않습니다.

    개방률을 다루는 장치(창문·커튼 등)에는 이 버튼이 없습니다 — "언제부터 언제까지 켬"이라는 의미가 성립하지 않기 때문입니다.

    실시간 갱신~

    위젯은 설정된 주기(기본 5초)마다 장치 상태를 자동으로 새로고침합니다. 마커 색상과 측정값 라벨이 실시간으로 업데이트되며, 팝업이 열려 있어도 값이 계속 갱신됩니다.

    지도 위 도구 버튼~

    지도 좌측 또는 우측 모서리에 다음 도구 버튼이 표시됩니다.

    버튼 기능
    +/- 확대/축소
    전체화면 위젯을 전체화면으로 표시
    검색 주소 검색 후 해당 위치로 이동
    내 위치 브라우저 GPS 위치로 이동
    초기화 처음 저장된 위치·확대 수준으로 되돌리기
    사이트 목록 등록된 사이트·구역 목록에서 선택해 바로 이동
    저작권(ⓘ) 현재 표시 중인 배경/오버레이 지도의 출처 표기를 보여줍니다. 지도를 처음 열거나 배경·오버레이를 바꿀 때 자동으로 펼쳐지고, 지도를 직접 조작하면(드래그·확대·터치) 접힙니다.

    이 외에 위젯 제목 표시줄에는 지도 잠금(이동·확대 잠금)과 컨트롤 숨김(도구 버튼 숨기기) 아이콘이 있습니다. 이 둘은 설정 화면이 아니라 위젯 제목 표시줄에서 바로 켜고 끄는 토글입니다.

    설정 옵션~

    설정 창의 구성 순서와 같습니다. 접힘 항목(장치 필터 · 측정값 패널 · 라벨 스타일 · 도형 · 3D 지도)은 눌러서 펼칩니다.

    기본~

    옵션 설명
    지도 선택 표시할 저장된 지도를 선택합니다. 비워두면 가장 최근에 수정한 지도를 사용합니다.
    라벨 표시 사이트·구역·시설·장치·센서 라벨 전체를 켜고 끄는 마스터 스위치입니다. 종류별 세부 표시는 지도 우측 도구의 레이어 → 라벨에서 따로 조정합니다.
    데이터만 표시(지도 숨김) 지도 배경과 오버레이를 감추고 옆의 측정값 패널만 보여줍니다.
    AI 조언 표시 이 지도가 속한 시설·사이트에 대한 최신 AI 조언 요약을 지도 상단에 클릭 가능한 칩으로 표시합니다(전역 AI가 설정되어 있어야 합니다).
    주기(초) 장치 상태를 다시 불러오는 간격. 0으로 두면 자동 새로고침을 끕니다. (기본 5초)

    참고

    지도 선택을 다른 지도로 바꾸면 위치·확대 수준이 자동으로 초기화됩니다(새 지도 기준으로 다시 맞추기 위함).

    장치 필터~

    옵션 설명
    입력 / 출력 / 함수 지도에서 숨길 장치를 종류별로 선택합니다(제외 목록). 아무것도 선택하지 않으면 /geo/design에 배치된 모든 장치가 표시됩니다 — 특정 장치만 지도에서 감추고 싶을 때만 사용하세요.

    측정값 패널~

    옵션 설명
    입력 / 출력 / 함수 지도 옆 데이터 패널에 표시할 측정값을 종류별로 선택합니다.

    라벨 스타일~

    이름 라벨(사이트·구역·시설)과 측정값 키(입력 센서 값)에 모두 적용됩니다. 표시 여부 자체는 위 라벨 표시 마스터 스위치를 따릅니다.

    옵션 기본값 설명
    라벨 겹침 방지 켜짐 켜면 겹치는 라벨을 자동으로 묶습니다. 이때 구체적인 대상이 남습니다 — 함수 > 입력 > 출력 > 장비 > 시설 > 구역 > 사이트 순으로 자리를 잡고, 밀려난 라벨은 이름 +N 배지로 표시되어 조용히 사라지지 않습니다.
    라벨 글자 크기 1.0 지도의 모든 라벨과 측정값 키의 글자 크기(em). 1.0~3.0.
    축소 시 라벨 숨기기 17 이 확대 수준보다 축소하면 시설·출력·입력·함수 라벨과 값 키를 숨깁니다. 사이트·구역 라벨은 위치를 가늠할 수 있도록 항상 표시되며, 입력 라벨이 숨겨지는 동안 구역 라벨이 대표값을 대신 냅니다(아래 구역 라벨 참고). 0으로 두면 숨기지 않습니다.
    시설 중심 라벨 꺼짐 꺼짐(기본값)은 야외 중심, 켜짐은 시설 중심으로 라벨의 줌 단계별 노출 규칙을 바꿉니다. 쌓임 순서(어느 라벨이 위로 오는지)는 이 값과 무관하게 항상 사이트 > 구역 > 시설 > 장비 > 출력 > 입력 > 함수입니다.
    센서 마커 스타일 원형 원형(대표 측정값을 정수로 표시, 측정 구간 색상 적용) 또는 텍스트(값과 단위를 함께 표시).
    센서 팝업 사용 켜짐 켜면 값 키를 클릭했을 때 최근 24시간 그래프가 있는 상세 창이 열립니다.

    참고

    마우스를 올리거나 클릭한 라벨은 종류와 무관하게 항상 맨 앞으로 올라옵니다. 클릭으로 연 라벨은 그 창이 닫힐 때까지 앞에 고정됩니다.

    구역 라벨 — 이름만 vs 대표값~

    구역 라벨은 입력 라벨이 보이지 않을 때만 대표값을 함께 냅니다.

    입력 라벨 상태 구역 라벨
    보임 이름만 (3-2)
    숨김 — 라벨 컨트롤러에서 껐거나, 위 축소 시 라벨 숨기기 기준보다 축소했거나 이름 + 대표값 + 측정 구간 색 (3-2 / 32.4°C), 주의·이상이면 모서리에 점

    입력 라벨이 이미 값을 말하고 있는데 구역 라벨이 또 말하면 같은 값이 두 번 뜨고 측정 구간 색이 두 겹으로 칠해져 어느 쪽이 기준인지 알 수 없기 때문입니다. 반대로 축소해서 입력 라벨이 사라지면 값이 가장 필요한 순간이므로 구역 라벨이 그 몫을 넘겨받고, 다시 확대하면 이름만으로 돌아갑니다.

    어떤 측정을 대표로 낼지는 대표 측정 정하기에서 구역마다 지정할 수 있습니다.

    도형~

    디자인 도구에서 그린 폴리곤을 지도 위에 반투명 오버레이로 표시할지 종류별로 켜고 끕니다.

    옵션 설명
    사이트 도형 사이트 경계선(설정된 테마 색상).
    구역 도형 구역 경계선.
    시설 도형 건물 외곽선.
    장비 도형 배관 등 장비의 도형.
    장치 도형 장치가 차지하는 영역 도형.
    식생 구획 표시 작기 구획(어디에 무엇이 심겼는가). 구획 라벨은 줌 16 이상에서 나타납니다.
    그 외 그린 도형 그리기 도구로 만든 자유 도형.
    장치 도형 불투명도 위 장치 도형의 불투명도(0~100). 0은 투명, 100은 완전 불투명.

    3D 지도(벡터 모드)~

    옵션 설명
    3D 지형 사용 고도에 따른 3D 지형(힐셰이드) 렌더링을 켭니다.
    시설 렌더 모드 시설(건물) 3D 모델을 그리는 방식: 기본(반투명) / 솔리드(불투명) / 와이어프레임 / 성능(모바일용, 부하 최소화).
    벡터 스타일 URL 커스텀 MapLibre 스타일 JSON을 쓰고 싶을 때만 입력합니다. 비워두면 GIS 입력 설정을 따릅니다.

    자동으로 저장되는 값~

    아래는 설정 창에 없는, 지도를 조작하면 알아서 기억되는 값입니다. 직접 입력하지 않습니다.

    값 언제 저장되나
    위치·확대 수준·피치·베어링 지도를 이동·확대·기울일 때
    활성 오버레이 레이어 / 선택된 기본 지도 지도의 레이어 선택기를 조작할 때
    라벨 종류별 표시 여부 도구 막대의 라벨 버튼이나 레이어 → 라벨 체크박스를 누를 때
    지도 잠금 / 컨트롤 숨김 해당 도구 버튼을 누를 때

    범례(Legend)~

    지도 우측 하단에 범례가 자동으로 표시됩니다. 별도 설정 없이 현재 켜져 있는 오버레이 레이어의 색상과 입력/출력 장치 아이콘을 설명하며, 범례 항목을 클릭하면 해당 레이어·장치 표시를 켜고 끌 수 있습니다.

    3D 시설 팝업~

    시설(Facility) 마커나 폴리곤을 클릭하면 간단한 3D 미리보기와 환경 데이터 요약이 팝업으로 표시됩니다. 전체 화면으로 자세히 보려면 AoT_facility 위젯을 사용하세요.

    여러 지도를 한 대시보드에~

    같은 대시보드에 AoT_map 위젯을 여러 개 추가하고 각각 다른 지도를 표시할 수 있습니다. 예를 들어 전체 부지를 보여주는 개요용 지도와, 특정 동만 확대한 지도를 나란히 배치할 수 있습니다.

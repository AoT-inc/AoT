    AoT_map 위젯~

    AoT_map 위젯은 대시보드에 인터랙티브 지도를 표시하는 위젯입니다. 장치 마커, 실시간 상태 폴링, 출력 제어 스위치를 지원합니다.

    위젯 추가~

    1. 대시보드에서 Add Widget → AoT_map 선택
    2. 설정 화면에서 표시할 지도 선택
    3. Save 클릭

    주요 기능~

    장치 마커~

    /geo/design 에서 Device 모드로 배치된 AoT 장치가 지도 위에 마커로 표시됩니다.

    • 마커 색상: 장치 활성/비활성/오류 상태에 따라 자동 변경
    • 마커 클러스터링: 줌아웃 시 인접한 마커를 그룹으로 합쳐 표시
    • 장치 아이콘: 장치 타입(온도 센서/릴레이/펌프 등)에 따른 아이콘

    팝업 제어~

    마커를 클릭하면 팝업이 열립니다.

    팝업에 표시되는 내용: - 장치 이름 - 최근 측정값 (Input 장치) - On/Off 토글 스위치 (Output 장치) - 마지막 업데이트 시각

    토글 스위치를 조작하면 /api/output/<id>/state API를 통해 즉시 장치를 제어합니다.

    실시간 폴링~

    위젯은 설정된 주기(기본 10초)마다 장치 상태를 자동 갱신합니다.

    • 마커 색상이 실시간으로 업데이트됩니다.
    • 팝업이 열린 상태에서도 값이 갱신됩니다.
    • 스톱워치: 출력 장치가 켜진 상태로 유지된 시간을 마커에 표시합니다.

    위젯 설정 옵션~

    옵션 설명 기본값
    Map 표시할 GeoMap 선택 —
    Refresh Rate 장치 상태 갱신 주기 (초) 10
    Show Legend 범례 표시 여부 On
    Lock Map 지도 이동/줌 잠금 Off
    Hide Controls 줌/검색 버튼 숨김 Off
    Geo Mode vector (MapLibre) 또는 raster (Leaflet) vector
    AI Advice AI 조언 요약 표시 Off

    Geo Mode 선택 기준~

    모드 설명 권장 상황
    vector MapLibre GL 기반, 3D·부드러운 줌 지원 기본값, 대부분의 경우
    raster Leaflet 기반, 하위 호환 구형 브라우저, WMS 전용

    지도 제어 버튼~

    위젯 내 지도에는 다음 컨트롤이 표시됩니다.

    버튼 기능
    +/- 줌 인/아웃
    검색 주소/좌표 검색 (raster 모드만)
    위치 GPS 현재 위치 이동
    잠금 지도 이동 잠금/해제
    숨김 컨트롤 버튼 토글
    RainViewer 강우 레이더 오버레이 켜기/끄기

    범례 (Legend)~

    지도 우측 하단에 장치 상태 범례가 표시됩니다.

    • 등록된 GIS 레이어 색상 표시
    • Input/Output 장치 아이콘 설명
    • 범례를 클릭하면 해당 레이어/장치 타입의 표시를 토글합니다.

    피처 오버레이 표시~

    디자인 도구에서 그린 Site·Zone·Facility 폴리곤이 지도 위에 반투명하게 표시됩니다.

    • Site: 부지 경계선 (설정된 테마 색상)
    • Zone: 구역 색상
    • Facility: 건물 외곽선
    • Connection: 배관/배선 경로

    3D 시설 팝업~

    시설(Facility) 마커 또는 폴리곤 클릭 시 간단한 3D 미리보기와 환경 데이터 요약이 팝업으로 표시됩니다. 전체 시설 보기는 AoT_facility 위젯을 사용하세요.

    여러 지도를 한 대시보드에~

    같은 대시보드에 AoT_map 위젯을 여러 개 추가하고 각각 다른 지도를 표시할 수 있습니다. 예: 전체 부지 개요 지도 + 특정 동 확대 지도.

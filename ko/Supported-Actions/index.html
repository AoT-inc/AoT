    Built-In Actions (System)~

    Actions: Pause~

    • Manufacturer: AoT
    • Works with: Functions

    self.run_all_actions() 사용 시 Action 실행 사이의 지연을 설정합니다.

    사용법: self.run_action("ACTION_ID")를 실행하면 설정된 시간만큼 일시정지를 만듭니다. self.run_all_actions()를 실행하면 모든 액션의 순차 실행 중에 일시정지가 삽입됩니다.

    OptionTypeDescription
    Duration (Seconds)Decimal일시정지 시간

    Camera: Capture Photo~

    • Manufacturer: AoT
    • Works with: Functions

    선택한 Camera로 사진 촬영.

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 Camera로 사진을 촬영합니다. self.run_action("ACTION_ID", value={"camera_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b"})를 실행하면 지정한 ID의 Camera로 사진을 촬영합니다. camera_id 값은 시스템에 실제로 존재하는 Camera ID로 바꾸는 것을 잊지 마세요.

    OptionTypeDescription
    CameraSelect Device촬영할 Camera 선택

    Create: Daemon Log Line~

    • Manufacturer: AoT
    • Works with: Functions

    데몬 로그에 로그 한 줄 기록.

    사용법: self.run_action("ACTION_ID")를 실행하면 Daemon 로그에 한 줄을 추가합니다. self.run_action("ACTION_ID", value={"log_level": "info", "log_text": "this is a log line"})를 실행하면 지정한 로그 레벨과 로그 텍스트로 액션을 실행합니다. 로그 텍스트를 지정하지 않으면 액션 메시지가 텍스트로 사용됩니다.

    OptionTypeDescription
    Log LevelSelect(Options: [Info | Warning | Error | Debug] (Default in bold)로그에 텍스트를 기록할 로그 레벨
    Log Line TextText - Default Value: Log Line Text데몬 로그에 삽입할 텍스트

    Create: Note~

    • Manufacturer: AoT
    • Works with: Functions

    선택한 Tag로 노트 생성.

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 태그와 노트로 노트를 생성합니다. self.run_action("ACTION_ID", value={"tags": ["tag1", "tag2"], "name": "My Note", "note": "this is a message"})를 실행하면 지정한 태그 목록과 노트로 액션을 실행합니다. 태그를 하나만 사용할 경우 리스트의 유일한 요소로 넣으세요(예: ["tag1"]). note를 지정하지 않으면 액션 메시지가 노트로 사용됩니다.

    OptionTypeDescription
    TagsSelect one or more tags
    NameText - Default Value: Name노트 이름
    NoteText - Default Value: Note노트 본문
    Include Message in NoteBoolean생성되는 노트에 action으로 전달된 메시지를 포함합니다.

    Display: Backlight: Color~

    • Manufacturer: AoT
    • Works with: Functions

    Set the display backlight color

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 디스플레이의 백라이트 색상을 변경합니다. self.run_action("ACTION_ID", value={"display_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b", "color": "255,0,0"})를 실행하면 지정한 ID와 색상으로 컨트롤러의 백라이트 색상을 변경합니다. display_id 값은 시스템에 실제로 존재하는 Function ID로 바꾸는 것을 잊지 마세요.

    OptionTypeDescription
    DisplaySelect Device백라이트 색상을 설정할 디스플레이 선택
    Color (RGB)Text - Default Value: 255,0,0R,G,B 값 형식의 색상(예: 따옴표 없이 "255,0,0")

    Execute: Bash/Shell Command~

    사용법: self.run_action("ACTION_ID")를 실행하면 bash 명령을 실행합니다. self.run_action("ACTION_ID", value={"user": "aot", "command": "/home/pi/my_script.sh on"})를 실행하면 지정한 명령과 사용자로 액션을 실행합니다.

    OptionTypeDescription

    Flow Meter: Clear Total (Kilowatt-hour)~

    • Manufacturer: AoT
    • Works with: Functions

    에너지 미터 Input에 저장된 총 kWh를 초기화합니다. Input에 Clear Total kWh 옵션이 있어야 합니다. 이는 총 kWh뿐만 아니라 기기의 모든 에너지 통계도 초기화합니다.

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 에너지 미터 Input의 총 kWh를 초기화합니다. self.run_action("ACTION_ID", value={"input_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b"})를 실행하면 지정한 ID의 에너지 미터 Input의 총 kWh를 초기화합니다. input_id 값은 시스템에 실제로 존재하는 Input ID로 바꾸는 것을 잊지 마세요.

    OptionTypeDescription
    ControllerSelect Device전력계 Input 선택

    Flow Meter: Clear Total (Volume)~

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 유량계 Input의 총 유량을 초기화합니다. self.run_action("ACTION_ID", value={"input_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b"})를 실행하면 지정한 ID의 유량계 Input의 총 유량을 초기화합니다. input_id 값은 시스템에 실제로 존재하는 Input ID로 바꾸는 것을 잊지 마세요.

    LED: Kasa RGB Bulb: Change Color~

    • Manufacturer: AoT
    • Works with: Functions

    Kasa RGB 전구의 LED 색상을 변경합니다. Kasa RGB Bulb Output을 선택하세요.

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 Kasa RGB 전구를 선택한 색상(Hue), 채도(Saturation), 밝기(Brightness)로 설정합니다. self.run_action("ACTION_ID", value={"output_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b", "hue": 10, "saturation": 50, "brightness": 25})를 실행하면 지정한 ID의 Kasa RGB Bulb Output의 hue(0 - 360), saturation(0 - 100), brightness(0 - 100)를 설정합니다. output_id 값은 시스템에 실제로 존재하는 Output ID로 바꾸는 것을 잊지 마세요.

    OptionTypeDescription
    ControllerSelect Device전력계 Input 선택
    Hue (Degree)Integer설정할 색상(hue), 각도 (0 - 360)
    Saturation (Percent)Integer - Default Value: 50설정할 채도 (%, 0 - 100)
    Brightness (Percent)Integer - Default Value: 50설정할 밝기 (%, 0 - 100)

    LED: Neopixel: Change Pixel Color~

    • Manufacturer: AoT
    • Works with: Functions

    Neopixel LED 스트립의 LED 색상을 변경합니다. Neopixel LED Strip Controller, 픽셀 번호, 색상을 선택하세요.

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 LED를 선택한 색상으로 설정합니다. self.run_action("ACTION_ID", value={"controller_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b", "led": 0, "color": "10, 10, 0"})를 실행하면 지정한 ID의 Neopixel LED Strip Controller에서 지정한 LED의 색상을 설정합니다. controller_id 값은 시스템에 실제로 존재하는 Controller ID로 바꾸는 것을 잊지 마세요.

    OptionTypeDescription
    ControllerSelect Device네오픽셀을 조절하는 컨트롤러를 선택하세요.
    LED PositionInteger스트립에서 LED의 위치
    RGB ColorText - Default Value: 10, 0, 0RGB 형식 색상, 각 값은 0~255(예: "10, 0, 0")

    LED: Neopixel: Flashing Off~

    • Manufacturer: AoT

    사용법: self.run_action("ACTION_ID")를 실행하면 선택한 LED를 선택한 색상으로 설정합니다. self.run_action("ACTION_ID", value={"controller_id": "959019d1-c1fa-41fe-a554-7be3366a9c5b", "led": 0})를 실행하면 지정한 ID의 Neopixel LED Strip Controller에서 지정한 LED의 깜빡임을 멈춥니다. controller_id 값은 시스템에 실제로 존재하는 Controller ID로 바꾸는 것을 잊지 마세요.

    OptionTypeDescription
    ControllerSelect Device네오픽셀을 조절하는 컨트롤러를 선택하세요.
    LED PositionInteger스트립에서 LED의 위치

    LED: Neopixel: Flashing On~

    • Manufacturer: AoT

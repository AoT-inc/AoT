    Data Viewing

    실시간 측정값~

    페이지: 데이터베이스 -> 실시간 측정값

    실시간 측정값 페이지는 AoT에 로그인한 후 사용자가 처음 보는 페이지입니다. 입력(Input)과 함수(Function) 컨트롤러에서 수집되는 현재 측정값을 표시합니다. 실시간 페이지에 아무것도 표시되지 않으면, 입력 또는 함수 컨트롤러가 올바르게 설정되고 활성화되어 있는지 확인하세요. 데이터는 측정 데이터베이스로부터 페이지에 자동으로 갱신됩니다.

    비동기 그래프~

    페이지: 데이터베이스 -> 비동기 그래프

    비교적 긴 기간(주/월/년)에 걸친 데이터를 볼 때 유용한 그래픽 데이터 표시 방식으로, 동기 그래프로 보면 데이터와 프로세서 부담이 매우 클 수 있는 경우에 적합합니다. 시간 범위를 선택하면 해당 기간에 데이터가 있을 경우 그 데이터가 로드됩니다. 처음에는 선택한 전체 데이터 집합이 표시됩니다. 매 조회/확대마다 700개의 데이터 포인트가 로드됩니다. 선택한 기간에 700개보다 많은 데이터 포인트가 기록되어 있으면, 해당 기간의 포인트를 평균 내어 700개의 포인트를 생성합니다. 이렇게 하면 훨씬 적은 데이터로 큰 데이터 집합을 탐색할 수 있습니다. 예를 들어 4개월치 데이터를 모두 내려받으면 10메가바이트일 수 있습니다. 하지만 4개월 범위를 볼 때 10메가바이트의 모든 데이터 포인트를 볼 수는 없으므로 포인트를 집계하는 것이 불가피합니다. 비동기 데이터 로딩을 사용하면 보이는 만큼만 내려받습니다. 그래서 그래프를 로드할 때마다 10메가바이트를 내려받는 대신, 새 확대 수준을 선택하기 전까지는 약 50kb만 내려받고, 새 확대 수준을 선택하면 다시 약 50kb만 내려받습니다.

    Note

    그래프에는 측정값이 필요하므로, 데이터를 표시하려면 최소 하나의 입력/출력/함수 등이 추가되고 활성화되어 있어야 합니다.

    대시보드~

    페이지: 데이터베이스 -> 대시보드

    대시보드는 다양한 대시보드 위젯 덕분에 데이터를 조회하는 동시에 시스템을 조작하는 데 사용할 수 있습니다. 여러 개의 대시보드를 만들 수 있으며, 배치가 바뀌지 않도록 잠글 수도 있습니다.

    위젯~

    위젯은 대시보드 상의 요소로, 데이터 조회(차트, 표시기, 게이지 등)나 시스템과의 상호작용(출력 조작, PWM 듀티 사이클 변경, 데이터베이스 조회·수정 등) 등 여러 용도로 쓰입니다. 위젯은 끌어다 놓기로 손쉽게 재배치하고 크기를 조절할 수 있습니다. 지원되는 위젯의 전체 목록은 지원 위젯을 참고하세요.

    사용자 정의 위젯~

    AoT에는 사용자가 만든 위젯을 시스템에서 사용할 수 있게 하는 사용자 정의 위젯 가져오기 기능이 있습니다. 사용자 정의 위젯은 [톱니바퀴 아이콘] -> Configure -> Custom Widgets 페이지에서 업로드할 수 있습니다. 가져온 후에는 Setup -> Widget 페이지에서 사용할 수 있습니다.

    동작하는 모듈을 개발했다면 새 GitHub 이슈 생성이나 풀 리퀘스트를 고려해 주세요. 내장 세트에 포함될 수 있습니다.

    올바른 형식의 예시는 AoT/aot/widgets 디렉터리의 내장 위젯 모듈들을 참고하세요. AoT/aot/widgets/examples 디렉터리에는 사용자 정의 위젯 예시도 있습니다.

    사용자 정의 위젯 모듈을 만들려면 대개 Javascript를 특정 위치에 배치하고 실행해야 합니다. 이를 위해 각 모듈에는 여러 변수가 만들어져 있으며, 여러 위젯이 표시될 때 생성되는 대시보드 페이지의 대략적인 구조는 다음과 같습니다.

    <html>
<head>
  <title>Title</title>
  <script>
    {{ widget_1_dashboard_head }}
    {{ widget_2_dashboard_head }}
  </script>
</head>
<body>

<div id="widget_1">
  <div id="widget_1_titlebar">{{ widget_dashboard_title_bar }}</div>
  {{ widget_1_dashboard_body }}
  <script>
    $(document).ready(function() {
      {{ widget_1_dashboard_js_ready_end }}
    });
  </script>
</div>

<div id="widget_2">
  <div id="widget_2_titlebar">{{ widget_dashboard_title_bar }}</div>
  {{ widget_2_dashboard_body }}
  <script>
    $(document).ready(function() {
      {{ widget_2_dashboard_js_ready_end }}
    });
  </script>
</div>

<script>
  {{ widget_1_dashboard_js }}
  {{ widget_2_dashboard_js }}

  $(document).ready(function() {
    {{ widget_1_dashboard_js_ready }}
    {{ widget_2_dashboard_js_ready }}
  });
</script>

</body>
</html>

    환경 제어 자동화~

    AoT의 env_coordinator는 온실 환경(VPD, CO₂, 온도, 습도)을 자동으로 제어하는 3계층 제어 시스템입니다.

    VPD (수증기압 포화차)~

    VPD는 작물의 증산·흡수를 결정하는 핵심 지표입니다.

    VPD = SVP × (1 - RH/100)
SVP = 0.6108 × exp(17.27T / (T + 237.3))  [kPa]
    범위 상태 권장 작물 단계
    < 0.4 kPa 너무 낮음 — 곰팡이 위험 —
    0.4 ~ 0.8 kPa 적정 발아·정식 초기
    0.8 ~ 1.2 kPa 적정 영양생장기
    1.2 ~ 1.8 kPa 적정 개화·착과기
    > 1.8 kPa 너무 높음 — 수분 스트레스 —

    env_coordinator 제어 계층~

    L1 — EnvTarget (목표값 설정)~

    Method 곡선 또는 고정값에서 VPD / CO₂ 목표를 읽습니다.

    • Method: 재배 단계에 따른 시간별 목표 곡선 (파종~수확)
    • 고정값: 단순 운영 시 고정 setpoint 사용

    L2 — SituationReport (상황 평가)~

    현재 편차, 제한 인자, 추세를 평가합니다.

    평가 항목 설명
    편차 현재값 - 목표값
    제한 인자 온도·습도·CO₂ 중 VPD 달성을 방해하는 인자
    추세 값이 목표 방향으로 이동 중인지 여부

    L3 — Coordinator (액추에이터 명령)~

    PI 제어 + 슬루율 제한 + 적분 와인드업 방지를 적용하여 액추에이터에 명령을 내립니다.

    e(t) = setpoint - measurement
u(t) = Kp × e(t) + Ki × ∫e dt
slew: |Δu| ≤ slew_rate_per_cycle
output → 난방기 / 환풍팬 / 가습기 / CO₂ 공급기

    Function 설정~

    AoT UI에서 Functions → env_coordinator 로 이동하여 설정합니다. 액추에이터 자체는 "환경 제어: 액추에이터 등록" Action으로 별도 등록하거나, 연동된 GeoFacility에서 자동으로 검색됩니다(아래 시설 참고) — 이 함수의 옵션은 목표값·타이밍·안전 임계값만 다룹니다.

    명령~

    명령 동작
    액추에이터 다시 불러오기 Actions 테이블을 다시 읽어 액추에이터 프로필을 재구성합니다.
    지금 실행 현재 센서 값을 사용해 조율 사이클을 즉시 1회 실행합니다.
    긴급 정지 모든 액추에이터를 즉시 safe_default 값으로 설정하고 60초간 제어를 일시정지합니다.
    작물 프리셋 목표값 적용 선택한 작물 프리셋의 값으로 VPD / CO₂ / 온도 / DLI / GDD 목표 필드를 강제로 채웁니다(현재값 덮어씀, 메서드를 사용하는 변수는 건너뜀). 작물 프리셋을 방금 바꿨다면 먼저 함수를 저장하세요.

    기본~

    항목 기본값 설명
    주기 (초) 60 조율 사이클 간격 — 감지·연산과(아래 구동 주기 설정에 따라) 디스패치가 이 주기로 실행됩니다. 권장값: 가장 느린 액추에이터 반응 시간 × 1.5.
    최대 센서 유효 시간 (초) 120 이 값보다 오래된 센서 값은 무시합니다. 0 = 제한 없음.

    구동 주기~

    측창·천창(개구부 액추에이터)이 평상시 얼마나 자주 움직일 수 있는지만 결정합니다 — 위 주기와는 별도의, 더 느린 주기로 환기창 모터 마모를 줄이기 위한 설정입니다. 감지·연산은 항상 매 주기마다 실행됩니다. 보온커튼·차광막은 영향받지 않습니다 (점진적 위치조정이 아니라 완전열림/완전닫힘 단일 단계로 개폐). 급격한 기상 변화와 안전 게이트(강풍·강우·폭염·한파)는 이 설정과 무관하게 항상 즉시 환기창을 움직입니다 — 아래 긴급 관련 항목 참고.

    항목 기본값 설명
    환기창 구동 프로파일 표준 (180초) 반응형(60초) / 표준(180초) / 완만(600초, 환기창 모터 수명 연장) / 직접 설정(아래 초 단위 필드 사용).
    직접 설정 구동 주기 (초) 0 환기창 구동 프로파일이 직접 설정일 때만 사용됩니다. 0 = 선택한 프로파일의 기본값을 사용합니다.
    긴급 시 최소 간격 (초) 60 긴급 상황에도 이 간격보다 자주 재명령하지 않습니다 — 연속 동작을 방지합니다.
    긴급 판정 편차 임계값 (허용오차 배수) 3.0 변수의 편차가 허용오차의 이 배수를 초과하면 이번 사이클을 긴급으로 간주해 즉시 환기창을 움직입니다(위 구동 주기는 무시됩니다).
    긴급 판정 변화율 임계값 (°C / 10분) 2.0 실내 온도가 이 속도보다 빠르게 변하면 이번 사이클을 긴급으로 간주해 즉시 환기창을 움직입니다.
    환기로 목표에 갈 수 없으면 창을 닫기 켜짐 환기는 실내를 실외 쪽으로만 끌어당길 수 있습니다. 목표가 실외 공기의 반대편에 있으면 아무리 열어도 목표에서 멀어집니다 — 대표적인 경우가 야간 제습으로, 실외가 실내보다 습한 밤에는 창을 열수록 더 습해집니다. 켜 두면 그런 상황에서 환기창과 배기·흡기팬이 어중간하게 열린 채 밤을 보내지 않고 닫힘으로 물러납니다. 야간 전용이 아니라 실외 공기로 목표를 맞출 수 없는 모든 경우에 적용됩니다. 안전 게이트와 온·습도 상하한은 이 설정보다 우선합니다.

    생육 일정~

    항목 기본값 설명
    일정 시작 (정식일) (없음) 정식/파종일. 장치/시설 로컬 시간대로 해석됩니다. 모든 메서드 곡선의 weeks_elapsed 계산에 사용됩니다. 비워두면 주차 기반 진행을 비활성화합니다(메서드는 일자만 사용).
    일정 종료 (수확일) (없음) 수확/사이클 종료일. 이 날짜까지는 메서드가 실제 경과 주차를 그대로 따르며, 지나면 제어가 정지됩니다 — 모든 액추에이터가 설정된 종료 동작으로 복귀하고 조율 사이클이 멈춥니다. 비워두면 종료일이 없습니다.
    주차 오프셋 0 경과 주차에 더해지는 직접 조정값입니다. 시스템이 사이클 중간에 시작한 경우 등 앞당기려면 양수, 다운타임을 보정하려면 음수를 사용하세요.

    시설 (선택사항)~

    항목 기본값 설명
    연동 시설 (없음) 설정하면 이 GeoFacility(외피, 측/천창, 커튼, 팬)에서 액추에이터가 자동으로 검색됩니다. GIS 메타데이터(방위, 면적, U값)가 각 액추에이터 프로필에 붙어 풍향과 시설 형상을 고려할 수 있습니다. 아래 수동 "환경 제어" Action도 계속 적용되며 시설 기반 목록과 병합됩니다. 비워두면 수동 Action만 사용합니다.
    구역(Bay) 범위 (선택사항) (없음) 이 코디네이터를 연동 시설의 특정 구역(Bay) 하나로 제한합니다(구역 ID, 예: bay_1). 해당 구역 내부의 센서/액추에이터만 사용되며, 시설 부피/면적이 구역 비율로 축소됩니다. 비워두면 시설 전체를 제어합니다 — 구역별로 독립 제어하려면 구역마다 코디네이터를 하나씩 만드세요.

    시간 제어~

    항목 기본값 설명
    시간대 제한 사용 꺼짐 사용하면 시작 시간과 종료 시간 사이에만 제어가 실행됩니다.
    시작 시간 (HH:MM) 06:00 제어 기간 시작 시간입니다(24시간 형식). 시간대 제한 사용이 켜져 있을 때만 적용됩니다.
    종료 시간 (HH:MM) 20:00 제어 기간 종료 시간입니다. 액추에이터별 종료 동작은 각 Action에서 설정합니다. 광주기 메서드가 설정된 경우 무시됩니다.
    광주기 메서드 (없음) 선택사항. 광주기 길이(시간)를 반환하는 AoT 메서드입니다(예: 14.0 = 14시간 점등). 앵커 시각을 중심으로 대칭적으로 time_start/end를 계산해 위의 고정 시작/종료 시간을 대체합니다.
    광주기 기준 시각 (HH:MM) 12:00 남중시(태양 정오)에 해당하는 시각 — 광주기 구간이 이 시각을 중심으로 설정됩니다. 위도/계절에 맞게 조정하세요.

    VPD (주 제어 목표)~

    항목 기본값 설명
    목표값 유형 고정 목표값 고정: 아래 고정 목표값 사용. 메서드: AoT 메서드 곡선을 따름.
    목표 VPD (kPa) 0.8 목표값 유형이 고정일 때 사용됩니다. 0 = VPD 제어 비활성화.
    메서드 (없음) 목표값 유형이 메서드일 때 사용됩니다. VPD 목표값(kPa)을 반환하는 AoT 메서드.
    VPD 중요도 1.2 값이 클수록 먼저 처리됩니다.
    VPD 허용 오차 (kPa) 0.1 VPD 목표값을 중심으로 한 데드밴드 반폭 — 편차가 이 범위 이내이면 조정을 건너뛰어 불필요한 액추에이터 동작을 줄입니다. 일반적인 값: 0.05~0.15 kPa.

    광량~

    항목 기본값 설명
    최대 광량 임계값 800 광량이 이 값을 초과하면 차광 스크린을 작동시킵니다. 0 = 비활성화.
    최소 광량 임계값 (보광) 0 광량이 이 값 아래로 떨어지면 보광 조명을 작동시킵니다. 0 = 비활성화(대부분의 시설 — 자연광만 사용).

    CO₂~

    항목 기본값 설명
    CO₂ 목표값 유형 고정 목표값 고정: 아래 고정 목표값 사용. 메서드: AoT 메서드 곡선(시간대/생육 주차별 ppm).
    목표 CO₂ (ppm) 1000 CO₂ 목표값 유형이 고정일 때 사용됩니다.
    CO₂ 메서드 (없음) CO₂ 목표값 유형이 메서드일 때 사용됩니다. CO₂ 목표값(ppm)을 반환하는 AoT 메서드.
    CO₂ 중요도 0.8 다른 제어 변수 대비 처리 순서 가중치 — 값이 클수록 먼저 처리됩니다. VPD(1.2)보다 낮은 이유는 CO₂ 보충이 부차적이기 때문입니다.
    CO₂ 허용 오차 (ppm) 100 CO₂ 목표값을 중심으로 한 데드밴드 반폭. 일반적인 값: 50~150 ppm.

    온도 (절대 제약 — 주 목표 아님)~

    항목 기본값 설명
    최대 온도 (°C) 35 절대 상한값 — VPD 목표와 무관하게 초과 시 냉방을 강제로 실행합니다.
    최소 온도 (°C) 5 절대 하한값 — VPD 목표와 무관하게 미달 시 난방을 강제로 실행합니다.

    습도 (절대 제약 — 주 목표 아님)~

    항목 기본값 설명
    최대 습도 (%) 90 절대 상한값 — 극단적인 고습으로 인한 VPD 우회를 방지합니다.
    최소 습도 (%) 30 절대 하한값 — 극단적인 건조로 인한 VPD 우회를 방지합니다.

    VPD 분해~

    항목 기본값 설명
    온도 가중치 (0-1) 0.6 VPD 조정 중 온도를 통해 이뤄지는 비율입니다(나머지는 습도). 0.6 = 온도 조정 우선.

    광합성 모델 (선택사항)~

    항목 기본값 설명
    광합성 지향 제어 사용 꺼짐 매 사이클마다 Big-Leaf 광합성 모델이 현재 제한 요인(광량/CO₂/온도/VPD)을 식별하고 해당 변수의 중요도를 동적으로 높입니다. 광량 센서가 필요하며, 활성 액추에이터 종류가 3개 이상일 때 권장합니다.
    작물 프리셋 토마토 토마토 / 상추·엽채류 / 오이 / 딸기 / 고추·파프리카. 저장 시 이 프리셋의 값으로 VPD/CO₂/온도 최소·최대/DLI/GDD를 채웁니다(값을 바꿨거나 메서드를 사용 중인 변수는 제외 — 사용자 설정이 우선). 강제로 덮어쓰려면 "작물 프리셋 목표값 적용" 명령을 사용하세요. Big-Leaf 모델 파라미터(A_max, K_L, K_C, T_opt, VPD_half)도 함께 선택되며, 광합성 지향 제어가 켜져 있을 때만 사용됩니다.

    권장 범위 (온도/습도)~

    항목 기본값 설명
    권장 최소 온도 (°C) 12 온도의 권장 하한값 — 미달 시 강제 난방을 유발합니다.
    권장 최대 온도 (°C) 32 온도의 권장 상한값입니다.
    권장 최소 습도 (%) 40 상대습도의 권장 하한값입니다.
    권장 최대 습도 (%) 85 상대습도의 권장 상한값입니다.

    누적 목표 트래커~

    항목 기본값 설명
    DLI / GDD 트래커 사용 꺼짐 일일 광적산량(DLI)과 유효적산온도(GDD)를 추적하며, 시설 로컬 자정에 초기화됩니다. DLI 추적에는 광량 센서가 필요합니다.
    DLI 목표값 (mol/m²/day) 0 0 = 선택한 작물 프리셋 기본값 사용(엽채류 약 14, 토마토/오이/고추 약 22, 딸기 약 17).
    GDD 목표값 (°C·day/day) 0 0 = 선택한 작물 프리셋 기본값 사용(≈ T_opt − T_base). 사이클마다 max(0, T_mean − T_base)로 계산됩니다.

    바람~

    항목 기본값 설명
    강풍 임계값 (m/s) 12 이 풍속을 초과하면 개폐부(환기창, 측벽)를 강제로 닫습니다.

    효과 캘리브레이션~

    항목 기본값 설명
    효과 엔진 레거시 레거시: 내장 K_* 상수 사용(기본값, 안전). 섀도: KPI 로깅만을 위해 그레이박스 모델을 병렬 실행하며 제어는 바꾸지 않음. 그레이박스: 물리 모델 제어(예보가 있으면 MPC 예측 포함) — 섀도 KPI 통과 및 파라미터 수렴 이후에만 활성화되며, 그 전까지는 자동으로 레거시 제어로 폴백. 권장 순서: 먼저 섀도, 이후 그레이박스로 전환.
    RLS 캘리브레이션 사용 꺼짐 센서 반응으로부터 액추에이터별 효과 계수(K_*)를 학습합니다. 수렴까지 며칠간의 데이터가 필요하며, 그 전까지는 내장 기본값을 사용합니다.
    능동 프로빙 사용 꺼짐 캘리브레이션 식별성을 높이기 위해 주기적으로 액추에이터 하나를 ±10% 교란시킵니다. 부하가 낮고 안전 게이트가 작동하지 않을 때만 실행됩니다. RLS 캘리브레이션 사용이 필요합니다.
    프로빙 간격 (초) 3600 능동 프로빙 이벤트 사이의 최소 간격입니다.

    예보 피드포워드~

    항목 기본값 설명
    예보 피드포워드 사용 꺼짐 기상청 단기예보를 활용해 악천후가 도래하기 전에 온도/습도 목표값을 선제적으로 조정하고 환기를 억제합니다.
    예보 선행 시간 (시간) 3 다가오는 악천후를 몇 시간 앞서 확인할지 설정합니다(1~6시간). 길수록 더 일찍 경고하지만 과잉 보정될 수 있습니다.

    진단~

    항목 기본값 설명
    디버그 로깅 활성화 꺼짐 사이클마다 판단 데이터(목표값, 편차, 모드, 사이클 지표, 액추에이터 불일치 횟수, 학습 상태)를 InfluxDB에 기록하고 DEBUG 로그를 출력합니다. 운영 환경에서는 꺼두세요 — 심각 이벤트(안전 게이트, 디스패치 실패, 런타임 상태 오류)는 이 설정과 무관하게 항상 기록됩니다.

    Method (제어 곡선)~

    Method는 시간에 따른 setpoint 변화를 정의합니다.

    재배 단계 예시 (토마토):

    날짜 VPD 목표 CO₂ 목표
    파종~7일 0.6 kPa 800 ppm
    8~21일 0.8 kPa 900 ppm
    22~42일 1.0 kPa 1000 ppm
    43일~ 1.3 kPa 1000 ppm

    SEED: 로 시작하는 Method는 시드 프리셋으로 읽기 전용입니다. 수정이 필요하면 복제 후 편집하세요.

    안전 게이트~

    안전 검사는 L1~L3 조율 알고리즘 바깥에서 동작합니다 — L1~L3 진입 전 매 사이클 평가하는 Pre-Gate와, L3 결과를 디스패치 직전에 검증·보정하는 Post-Gate로 나뉩니다. Pre-Gate는 한 번 발동하면 마지막 발동 시점으로부터 최소 300초간 유지됩니다(빈번한 on/off 반복 방지).

    Pre-Gate (L1~L3 진입 전 평가)~

    게이트 발동 조건 동작
    강우 강우량 ≥ 0.5 mm/hr (고정값, 사용자 설정 불가) 측창·천창(개구부 액추에이터)을 닫습니다. 보온커튼·차광막은 실내 설비라 손대지 않습니다.
    강풍 풍속 ≥ 강풍 임계값 옵션(기본 12 m/s, 위 바람 참고) 환기창을 닫습니다. 강풍이 유일하게 발동된 게이트이고 풍향과 환기창 방위가 모두 알려진 경우, 풍상측(±60° 이내) 환기창만 강제로 닫고 풍하측은 정상 제어를 유지합니다.
    폭염 외부 온도 ≥ 45°C 그리고 내부 온도 ≥ 35°C (둘 다 고정값) 환기창을 완전 개방하고, 차광막을 닫고, 냉방기를 100%로 강제 가동합니다.
    한파 외부 온도 ≤ −5°C 그리고 내부 온도 ≤ 5°C (둘 다 고정값) 환기창을 닫고, 보온커튼을 닫고, 난방기를 100%로 강제 가동합니다.
    내부 센서 만료 내부 센서값이 120초 넘게 갱신되지 않음 (고정값) 모든 액추에이터가 설정된 safe_default 값으로 복귀합니다 — 실내 데이터 없이는 제어가 불가능합니다.
    외부 센서 만료 (단독) 외부 센서값이 300초 넘게 갱신되지 않고, 다른 게이트가 발동하지 않은 경우 부분 발동: 환기창·차광막만 보수적으로 닫고, 난방기/냉방기/가습기/CO₂/보온커튼은 평소대로 L1~L3 제어를 계속합니다.

    강우·폭염·한파 임계값은 코드에 고정돼 있으며, 바람 임계값만 함수 옵션으로 노출됩니다. 여러 게이트가 동시에 발동할 수 있습니다(예: 강우 + 강풍) — 이 경우 풍향과 무관하게 환기창을 무조건 닫습니다.

    Post-Gate (L3 이후, 디스패치 직전 검증)~

    검사 항목 동작
    비정상 명령값 (NaN/Inf) 해당 액추에이터가 safe_default 값으로 대체됩니다.
    범위를 벗어난 명령값 [0, 100]으로 클램프됩니다.
    수동 락(Manual Lock) 활성 잠긴 값으로 덮어씁니다.
    냉방기·난방기 동시 ON 동시 가동을 허용하지 않습니다 — 비용(cost_fn)이 더 낮은 쪽만 유지하고 나머지는 0으로 강제합니다.

    AI와의 연동~

    AI 에이전트가 analyze_control_performance로 제어 성능을 진단합니다.

    vpd_rmse         → VPD 목표 추종 오차 (낮을수록 좋음)
oscillation_index → 제어 진동 지수 (낮을수록 안정)
assessment       → "good" / "moderate" / "poor"

    진단 결과에 따라 suggest_setpoint_adjustment로 목표값 조정을 제안하며, 사용자 승인 후 set_vpd_target으로 실제 적용됩니다.
